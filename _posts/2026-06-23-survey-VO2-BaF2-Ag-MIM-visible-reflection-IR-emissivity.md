# [专题调研] VO₂/BaF₂/Ag MIM 超表面：可见光高反射与中红外动态发射率兼容方案

> 调研日期：2026-06-23

---

## 1. 问题诊断：为什么你的器件在可见光波段吸收率高

你目前的 VO₂/BaF₂/Ag 三层 MIM 结构在 8–13 μm 实现了优异的高低温发射率切换（高温高发射、低温低发射），但可见光波段吸收严重。物理根源有三：

| 来源 | 机制 | 对可见光的影响 |
|------|------|---------------|
| **VO₂本征吸收** | VO₂带隙 ~0.6–0.7 eV（相当于 λ ~1.8–2.1 μm），所有波长 <2 μm 的入射光子均可激发带间跃迁 | 400–750 nm 波段消光系数 k ≈ 0.5–1.5 |
| **Ag底层二次反射** | Ag底镜将透过的可见光反射回VO₂层，形成双程吸收 | 吸收量翻倍 |
| **MIM腔可见光共振** | MIM结构的F-P腔在薄介质层时可能在可见-近红外产生寄生吸收峰 | 部分波长额外增强吸收 |

**核心矛盾**：VO₂是热致变色材料，其可见光吸收是**物理本质**，不能通过直接改变VO₂自身来消除 —— 所以解决思路必然是 **"在可见光到达VO₂之前就把它反射走"**。

---

## 2. 已有方案综述

根据公开文献，目前实现 "可见光高反射 + 中红外动态发射率" 兼容的方案主要分为三大类：

```
方案 A：顶层DBR太阳反射器        —— 成熟度高，实验验证充分
方案 B：高对比度光栅(HCG)顶层     —— 性能好，但工艺复杂
方案 C：超表面图案化优化           —— 不增加新层，但改善有限
```

---

## 3. 方案A：顶层DBR太阳反射器（**首推方案**）

### 3.1 核心思路

在现有MIM结构（VO₂/BaF₂/Ag）的**上方**额外沉积一组分布式布拉格反射器（DBR），**在可见光进入VO₂之前**将其反射回空气。DBR材料需同时满足：
- 可见/近红外波段：高折射率差 → 宽禁带高反射
- 中红外大气窗口（8–13 μm）：**高透过率** → 不影响下方MIM的工作

### 3.2 代表性工作

#### (a) YF₃/ZnS DBR + W:VO₂超表面 — 航天级Smart Meta-OSR（Kim & John et al., *Nano Select*, 2026）

| 参数 | 值 |
|------|-----|
| DBR材料 | YF₃（低折射率）/ ZnS（高折射率）|
| DBR层数 | 33层，总厚度 ~2.45 μm |
| 器件的太阳吸收率 α | **0.22**（无DBR时>0.4） |
| 热态红外发射率 ε_hot | 0.80 |
| 发射率可调量 Δε | 0.33 |
| 基底 | 聚酰亚胺柔性箔，10×10 cm² |
| 制造方法 | 纳米压印光刻 + 离子束蒸发 |
| 空间验证 | 通过ESA全套鉴定测试（热真空105次循环、质子/电子辐照等） |

**关键参数与权衡**：
- DBR总厚度 1980 nm → α≈0.26, Δε≈0.48
- DBR总厚度 2450 nm → α≈**0.22**, Δε≈0.33
- 更厚的DBR更好反射太阳光，但牺牲部分红外发射率对比度

#### (b) BaF₂/ZnSe DBR + 超叠FP VO₂谐振器 — 航天器智能辐射器（Liu et al., *Appl. Therm. Eng.*, 2024）

| 参数 | 值 |
|------|-----|
| DBR材料 | BaF₂（低）/ ZnSe（高） |
| DBR层数 | 未明确（多层交替堆叠）|
| 太阳吸收率 | **0.121**（接近传统OSR的~0.125） |
| 发射率可调量 Δε | **0.825** |
| FP腔结构 | 3层VO₂ + 4层BaF₂的超叠FP腔，Al基底 |
| 净散热调节范围 | 0 – 494.6 W/m²（vs. 传统OSR: 146.5 – 463.9）|

**亮点**：太阳吸收率仅0.121是目前所有VO₂基热辐射器的最低水平，同时保持了0.825的超大发射率调制幅度。

### 3.3 如何适配你的VO₂/BaF₂/Ag结构

```
              入射太阳光
                  │
                  ▼
   ┌──────────────────────────────┐
   │   DBR太阳反射器              │  ← 新增层
   │   材料: ZnS/YF₃ 或 TiO₂/SiO₂ │     反射 400–800 nm
   │   层数: 10–20对              │     透过 8–13 μm
   └──────────────────────────────┘
                  │
   ┌──────────────────────────────┐
   │   VO₂ 超表面结构 (图案化)     │  ← 保留你的原有MIM
   ├──────────────────────────────┤
   │   BaF₂ 间隔层               │
   ├──────────────────────────────┤
   │   Ag 金属底层               │
   └──────────────────────────────┘
```

**材料选择建议**：

| DBR材料组合 | 优点 | 缺点 |
|------------|------|------|
| **YF₃/ZnS** | 航天级验证，文献数据丰富 | YF₃易潮解需钝化保护 |
| **TiO₂/SiO₂** | 常见材料，折射率差大 | TiO₂在近红外有微弱k |
| **BaF₂/ZnSe** | 与你的BaF₂间隔层同种材料，IR透明性好 | ZnSe折射率 ~2.4（不如ZnS的2.36），差稍小 |
| **HfO₂/SiO₂** | HfO₂高透明，钝化层兼容 | 需要更多层数 |

**设计原则**：
1. DBR的中心波长选在可见光波段（~550 nm），周期满足 λ/4 条件
2. 利用高/低折射率材料的大折射率差（Δn > 0.4），用较少层数获得较宽反射带
3. **关键约束**：DBR整体在8–13 μm的透过率需 >80%，以确保下方MIM结构的中红外性能不被显著削弱
4. 每层厚度 ~100–200 nm（可见光λ/4），总厚 ~2–3 μm

## 4. 方案B：高对比度光栅（HCG）顶层

### 4.1 核心思路

在VO₂层上方刻蚀一层高折射率介质材料（Si或Ge）形成亚波长光栅，利用**法布里-珀罗往返共振**产生宽带可见光反射。这些材料在中红外波段是透明的，因此不影响下方MIM结构。

### 4.2 代表性工作

**Si/Ge HCG + VO₂双FP腔**（Hailu et al., *AIP Advances*, 2022）

```
      ┌────────────────────────────────┐
      │  Si 或 Ge 亚波长光栅 (HCG)      │  ← 反射0.3–2.0 μm
      │  Λ=0.42μm(Si) / 0.58μm(Ge)    │     填充比 0.7
      ├────────────────────────────────┤
      │  BaF₂ 底层 (0.14–0.24 μm)      │  ← 低n间隔层
      ├────────────────────────────────┤
      │  VO₂ (35 nm)                   │
      ├────────────────────────────────┤
      │  BaF₂ F-P腔 (1.385 μm)         │
      ├────────────────────────────────┤
      │  VO₂ (450 nm)                  │
      ├────────────────────────────────┤
      │  Ag 基底                       │
      └────────────────────────────────┘
```

**性能对比**：

| 配置 | 太阳吸收率 α | 热态辐射功率 P_350K | 发射率可调量 Δε |
|------|------------|-------------------|---------------|
| 纯VO₂无反射器 | 0.753 | 667 W/m² | 0.681 |
| **Si 1D HCG** | **0.500** | 693 W/m² | 0.695 |
| Si 棱镜阵列 | 0.582 | 690 W/m² | 0.682 |
| Ge 1D HCG | 0.558 | 671 W/m² | 0.660 |

- Si 1D HCG效果最佳：太阳吸收率从0.753降至0.500（降低34%），红外调制能力完全保持
- 1D HCG优于2D HCG（2D的额外模式压缩了双模区域），优于棱镜阵列（偏振依赖）

### 4.3 HCG方案的优缺点

| 优点 | 缺点 |
|------|------|
| 红外性能几乎不受影响（Si/Ge在8–13μm高度透明） | 需要亚波长级光刻（周期~0.5–0.6 μm），工艺复杂 |
| 总厚度小（HCG仅 ~0.2–0.3 μm高） | Si在 λ<0.6 μm 有吸收，无法反射蓝紫光 |
| 角度特性可通过设计优化 | Ge在 λ<1.1 μm 有吸收，不能反射近红外 |

## 5. 方案C：超表面图案化优化（不增加新层）

### 5.1 核心思路

如果你已经在做VO₂超表面图案化（即VO₂不是连续薄膜，而是周期性孔洞或方阵），那么**VO₂图案之间的裸露BaF₂区域**会让下方的Ag底镜显露出来。Ag在可见光波段的反射率很高（>90%），因此增大VO₂之间的间隙面积就能提高整体可见光反射率。

但这里有**两个矛盾**：
1. 间隙越大 → 可见光反射越高 → VO₂覆盖面积越小 → IR发射率（热态）可能下降
2. 好在VO₂金属态时存在**等离激元共振增强**效应，部分补偿了面积减少导致的IR性能损失

### 5.2 实验验证

2026年Smart Meta-OSR论文实验表明（Kim & John）：
- 方形尺寸从1.5→4.7 μm，间隙从1→4 μm的63种组合
- 热态IR发射率在 4.7μm/1μm 时达到峰值 0.85（等离子体增强）
- 太阳吸收率随间隙增大而降低，与方形尺寸关系不大
- **最优折衷**：方形2.7 μm / 间隙1.0 μm（Δε=0.46，α_hot=0.41，无DBR时）

### 5.3 对你的建议

如果你的VO₂超表面是图案化的，可以考虑：
- **适当增大VO₂间隙** → 让Ag底镜透过BaF2间隙反射可见光
- **但需通过FDTD/RCWA仿真优化** → 在可见光反射和IR发射率之间找到最优间隙大小
- 单独依靠此方案改善有限（α_hot最多可能从~0.7降至~0.4–0.5，仍不理想）

## 6. 方案D：透明导电氧化物（TCO）频率选择性背反射器（备选思路）

### 6.1 核心思路

与方案A相反：不是"加顶层反射可见光"，而是"把底层的宽带金属反射镜换成频率选择性的TCO层"。

TCO（如AZO：Al掺杂ZnO，载流子浓度5.8×10²⁰ cm⁻³）的独特性质：
- **可见光波段**：介电态 → 太阳光透过，不产生二次反射
- **中红外波段（>3 μm）**：金属态 → 高反射率，作IR背反射器

### 6.2 代表性工作

**AZO背反射器 + SiO₂间隔 + VO₂超表面**（John et al., *Nanophotonics*, 2022）

| 参数 | 值 |
|------|-----|
| 结构 | VO₂方阵(40nm) / SiO₂(1200nm) / AZO(300nm) / CaF₂基底 |
| 可见光透过率 | **60–62%** |
| 太阳吸收率 α | ~0.32 |
| 热态IR发射率 ε_hot | 0.81 |
| 冷态IR发射率 ε_cold | ~0.55 |
| 发射率可调量 Δε | 0.26 |
| 物理机制 | Salisbury Screen干涉 + 等离激元共振 + VO₂相变 |

### 6.3 对你的适应性

此方案更适用于**可见光透明**的应用场景（如智能窗），而不是**可见光高反射**。但你可以借鉴TCO的频率选择性思想：在你的Ag之上加一层薄TCO来调整底部反射镜的特性。

## 7. 方案E：级联多腔体独立设计

### 7.1 核心思路

采用"选择性透明层"将不同波段的功能腔体纵向分离，每个腔体只在其目标波段工作。（Yao et al., *Light Sci. Appl.*, 2024, "Tunable VO₂ cavity enables multispectral manipulation"）

### 7.2 对你的启示

论文中使用的关键材料 **Si** 在可见光波段不透明（高吸收/高折射），但在中红外波段完全透明。利用这个性质可以在结构中插入一层Si作为"光谱分界层"：
- 上腔体负责可见光（在Si以上）
- 下腔体负责中红外（在Si以下）

这一思路可以与方案A结合：**DBR + Si分隔层 + 你的MIM结构**，实现更彻底的光谱解耦。

## 8. 综合建议：三条推荐技术路线

| 路线 | 方案组合 | 预期α | 预期Δε | 工艺复杂度 | 推荐场景 |
|------|---------|-------|--------|-----------|---------|
| **路线1** | 方案A：顶层TiO₂/SiO₂/ZnS DBR + 你的现有MIM | 0.15–0.30 | 0.30–0.50 | ⭐⭐ 中等 | **最推荐**，风险低，文献验证丰富 |
| **路线2** | 方案A + 方案C：DBR + 优化VO₂间隙比 | 0.12–0.25 | 0.35–0.55 | ⭐⭐⭐ | 追求最高可见光反射率 |
| **路线3** | 方案B：Si HCG + 双VO₂ FP腔 | 0.35–0.50 | 0.55–0.70 | ⭐⭐⭐⭐ 高 | 追求最大IR调制，可见光反射中等 |

## 9. 方案A的工程实现要点（以路线1为例）

### 9.1 DBR设计参数

以 **TiO₂/SiO₂** 为例（最常见的镀膜材料组合）：

```
TiO₂: n ≈ 2.3  @ 550 nm,   n ≈ 2.1  @ 10 μm,  k_IR ≈ 0（IR透明）
SiO₂: n ≈ 1.45 @ 550 nm,   n ≈ 1.4  @ 10 μm,  k_IR ≈ 0

λ/4 厚度: TiO₂ = 60 nm, SiO₂ = 95 nm  (参考波长 550 nm)
```

- 10对 → R_vis ≈ 90%，T_IR ≈ 90%
- 15对 → R_vis ≈ 97%，T_IR ≈ 85%
- 20对 → R_vis ≈ 99%，T_IR ≈ 80%

### 9.2 仿真流程建议

1. **FDTD/RCWA仿真**：在你的现有MIM结构上叠加DBR，扫描DBR层数（5–20对）和参考波长（450–650 nm）
2. **优化目标**：最小化 0.3–2.5 μm 的积分太阳吸收率，同时最大化 8–13 μm 的 ε_hot – ε_cold
3. **多目标权衡**：用帕累托前沿分析，找到太阳吸收率和IR可调量之间的最佳折衷点

### 9.3 制造注意事项

- DBR镀膜过程中**基底温度**需控制 <350°C（如你之前使用了VO₂，避免其预氧化或相分离）
- 镀膜方法：电子束蒸发或离子束溅射（离子束辅助沉积可提高膜层致密性）
- 顶层需增加**钝化保护层**（如~50 nm SiO₂或Al₂O₃），防止环境退化

## 11. 总结

**核心结论**：在现有VO₂/BaF₂/Ag MIM超表面上叠加一个 **DBR太阳反射器**（YF₃/ZnS或TiO₂/SiO₂材料组合）是目前最成熟、文献验证最充分的方案。这个DBR利用材料在可见光/中红外的折射率差异，实现了"反射太阳光、透过中红外"的光谱选择性。

**下一步建议**：
1. 先用FDTD仿真在你的具体结构上验证DBR方案效果
2. 扫描DBR层数（10–20对）和中心波长，同时监测8–13μm IR性能变化
3. 在最优DBR参数下，回来再微调你的VO₂超表面几何参数，形成联合优化
