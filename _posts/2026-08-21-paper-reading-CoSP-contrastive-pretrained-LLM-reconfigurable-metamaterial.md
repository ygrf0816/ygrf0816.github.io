## 一、研究问题与动机

### 1.1 背景
超材料（metamaterials）通过亚波长结构实现对光的任意操控，但传统设计依赖 FDTD/FEM 参数扫描与启发式搜索，在高维设计空间下计算开销巨大、且经验驱动的方法缺乏跨项目/跨学科的可迁移性。AI 逆向设计（inverse design）应运而生。

### 1.2 核心痛点：可重构超材料（RMM）的逆向设计空白
**可重构超材料（Reconfigurable Metamaterials, RMM）** 在外界刺激（电、热、湿度、机械力）下，光学特性可在不同态之间切换，对智能窗口、自适应辐射制冷、红外隐身、光计算等极具价值。

但**现有 AI 逆向设计方法全部无法有效处理 RMM**，原因有二：

1. **设计自由度受限**：模型被固定材料集合、预设层配置束缚；
2. **迁移性差**：设计目标或材料组分一变，就要大规模重训或任务级重新配置。

RMM 的根本难点在于：**单一结构必须同时满足多个态（multi-state）的目标响应**，即"一个器件、一对状态相关光谱"，这比静态超材料的单目标设计难得多。论文通过 Table 1 逐项对比指出，**此前没有任何方法能同时做到**多波段 + 自由材料 + 动态层数 + 迁移性 + 通用性 + 多态 + 自然语言可解释这七项能力（CoSP 是首个全项 ✓ 的）。

## 二、方法（CoSP 框架）

CoSP = **Co**ntrastive multi-**S**tate **P**retrain。核心是一个**两阶段**架构（Figure 2）：

```
阶段1：对比式多态光谱预训练（contrastive multi-state spectrum pretraining）
      → 得到一个"会区分态、又保持同一样本两态关联"的光谱编码器
阶段2：材料结构生成（GPT-style decoder，端到端从零训练）
      → 以冻结的光谱编码器输出为条件，自回归生成自然语言光谱描述 + 材料结构序列
```

### 2.1 光谱编码器 + 对比预训练（阶段1）

- **骨干**：Transformer encoder（含波长嵌入、位置编码、多头自注意力、前馈网络）。
- **关键设计 —— 用"波长编码 WavEncoding"替代"token embedding"**：
  光谱在波长域是**连续**的，而文本 token 是离散的。若照搬 CLIP 的 token embedding，会破坏物理决定的连续性、造成光谱被"分段解释"，损害逆向设计性能。因此 CoSP 采用**绝对位置编码作用于序列方向的波长编码**。
- **前向流程**：
  1. 对同一超材料 i 的不同态 j 的光谱 Sⱼⁱ，先经线性投影层 Proj 投影；
  2. 施加波长编码 WavEncoding（绝对位置编码）；
  3. 过 N 层 Transformer encoder 块 H；
  4. 接一个**非线性的全连接分类头 ClsHead**（仅在预训练阶段使用；SimCLR 结论表明非线性头比线性头表征更好）。
- **对比损失（InfoNCE）**：
  ```
  Lⱼ = -(1/n) Σᵢ log [ exp(cos(sⱼⁱ, sⱼ*ⁱ)/τ) / Σₖ exp(cos(sⱼⁱ, sⱼₖ*)/τ) ]
  L  = (1/2)(L₁ + L₂)
  ```
  即**最大化同一超材料不同态之间光谱表示的余弦相似度**，n 为 batch size，j* 为与 j 不同的另一态，τ 为温度参数。以自监督方式训练光谱编码器。

> 核心思想：把"同一器件两个态"视作对比学习中的**正样本对**，让编码器学到"态可分离 + 样本一致"的表征（state-discriminative 且 sample-consistent）。

### 2.2 光谱描述（Spectrum Description）

由于"光谱 → 结构"是**一对多映射**（不同结构可有相似光谱），直接回归会坍缩多解。CoSP 额外加入一个 **LLM 驱动的光谱描述阶段**：用自然语言描绘目标多态光谱，涵盖各态、各波段的**峰/谷（局部极大/极小值）**。把光谱转成人类可读描述，能让模型识别相似光谱、避免重训，同时提高泛化能力与可解释性。

### 2.3 GPT 解码器 + 材料结构生成（阶段2）

- **解码器**：采用 GPT-2（openai-community/gpt2，124M，hidden=768）的 text embedding、self-attention、language modeling head 初始化，**从零端到端训练**。选 GPT-2 的理由：
  1. tokenizer/隐藏态/decoder 块完全可访问可修改，便于端到端集成 cross-attention；
  2. 模型规模适中、计算经济；
  3. （并指出未来换更大的开源 LLM 有望更好）。
- **光谱注入方式**：将预训练光谱编码器得到的表示 s，经 **multi-head cross-attention** 注入 decoder（Q=W_q·q 来自文本嵌入，K=W_k·s、V=W_v·s 来自光谱表示），实现"以光谱为条件的文本生成"。
- **训练目标**：Causal Language Modeling（CLM），自回归预测下一 token：
  ```
  L_CLM = -Σᵢ log P(xᵢ | x₁, x₂, ..., xᵢ₋₁)
  ```
  单向自回归生成天然契合 RMM 的层次化（逐层）结构。
- **输出**：同时生成①目标光谱的自然语言描述 + ②材料组分与结构配置序列（层数、各层材料、厚度）。

## 三、数据集构建（来源与流程）

> 正文未详述，细节在 SI Section S3；以下依据作者开源代码（`tmm_utils.py` / `data_loader.py` / 仓库 Data 目录）还原。

### 3.1 数据来源
- **自建合成数据集**（非实验测量、非公开第三方库）：作者用**随机结构采样 + TMM 正向仿真**生成，共 **10 万条**（文件名 `processed_0101_text_10w_with_descriptions.csv`），划分为 train / eval / test 三份 CSV 开源。
- 每条样本 = 一个 **1D 多层膜 RMM**，含 VO₂ 相变层，具有绝缘态（State I）与金属态（State M）双态光谱。

### 3.2 建立流程（代码级还原）

**① 随机生成结构**（`generate_random_vector`）：
- 层数：`random.randint(3, max_length-1)`（3 层到某上限之间随机；示例结构为 10 层）；
- 材料：从 **13 种材料**中随机选取（相邻层材料不允许相同）：
  `Ge, VO₂, BaF₂, ZnS, Al₂O₃, PE, PDMS, SiO₂, PEI, SiN, TiO₂, Al, W`（含 2 种金属 Al/W + 10 种介质/半导体 + 相变材料 VO₂）；
- 厚度：**3–500 nm 随机整数**；
- **强制含 VO₂**：若随机结果未出现 VO₂（编码 4），则在随机位置插入一层 VO₂（厚度 3–250 nm），确保每个 RMM 都有两态响应。

**② TMM 正向仿真**（`calculate_reflectance_I/M`）：
- 波长：**400–14000 nm（0.4–14 μm），100 个点**；
- 用 Python `tmm` 库 `coh_tmm`（**s 偏振、相干模型、air/stack/air 半无限**）逐波长计算；
- 吸收率 A(λ) = 1 − R(λ) − T(λ)；
- **双态区分靠 VO₂ 折射率**：State I 用 `Data/VO_2 I.csv`（绝缘相 nk），State M 用 `Data/VO_2 M.csv`（金属相 nk），其余 12 种材料两态共用同一 nk；
- 材料 nk 数据：仓库 `Data/` 目录下每种材料一个 CSV（波长, n, k），代码中线性插值 + 外推。

**③ LLM 光谱描述**（论文正文与 arXiv 版均称："a depiction of the target multi-state spectra generated by an LLM. It encompasses the local maxima and minima (i.e., peaks and troughs) of the spectra across various states and wavelength bands"，具体生成过程与 prompt 见 SI Section S3）：
- 用 LLM 为每条光谱生成自然语言描述，内容覆盖**各态、各波段的峰/谷（局部极值）**；
- 描述文本作为训练标签的一部分（见 §5.6），消融实验（SI S2）证明其有助于性能；
- **生成机制未公开**：SI S3 未随正文 PDF 提供，Wiley SI 下载页被 Cloudflare 拦截、Google Drive 数据集无法直接访问——具体用了哪个 LLM、什么 prompt 作者没有公开（通过历史 commit 拿到真实数据集文件后可确认描述的**形态**，见 §3.3）。

**④ 数据 CSV 列结构**：`Sample Index | Material Structure | Absorption_I (100维) | Absorption_M (100维) | Reflection_I (100维) | Reflection_M (100维) | description (文本)`（7 列；**论文未提及 Reflection 两列**，数据集中实际存在）。

> 注：正文对基线对比（Table 2）做了"理论一致适配"（双态误差聚合、合法结构参数约束等），适配协议见 SI S5。

### 3.3 真实数据集实证（description 列形态）

> 从仓库历史 commit（254bd68 "Upload dataset"，后因体积超限移出仓库）通过 Git LFS 取回评估集 `processed_0101_text_1w_with_descriptions.csv`（真实 9870 条），直接观察 description 原始格式。

**description 真实示例**（原文）：
> ① "In State I, absorption is notably high across the mid-infrared range (3-14 microns) with peaks around 3, 6, 9, and 14 microns, while it is relatively low in the near-infrared range (0.4-2 microns). In contrast, State M shows lower overall absorption rates, with significant absorption only observed at 9, 10, and 14 microns, and very low absorption in most of the mid-infrared range."
>
> ② "State I shows significant absorption in the mid-infrared range (3-5 microns) with values around 0.6-0.8, while State M exhibits high absorption only in the near-infrared (0.4-1 micron) range, with values peaking at around 0.8 and dropping sharply beyond 2 microns."

**形态统计**（9870 条全量统计）：
- 平均长度 ~331 字符；固定句式高度模板化：53.6% 含 "In contrast"、47.1% 含 "notably high"、39.1% 以 "In State I" 开头、37.8%/40.0% 用 "State I shows"/"State M exhibits"、99.8% 含波段描述（"microns"）；
- 描述内容结构 = **逐态（State I / State M）+ 逐波段（0.4-2 / 3-5 / 8-14 μm 等）的峰谷与数值高低描述**，与论文"encompasses local maxima and minima across various states and wavelength bands"完全对应；
- 波段命名："near-infrared (0.4-2/1 μm)"、"mid-infrared (3-5, 3-14 μm)"等，属自然语言波段划分而非等宽分箱。

**推断**：如此高的句式一致性（同一批模板短语反复出现）强烈表明 description 是由 **LLM（固定 prompt）+ 程序化峰谷特征提取**批量生成的（典型做法：对每条光谱做局部极值检测 → 提取峰位/谷位/波段吸收高低 → 灌入固定 prompt 让 LLM 润色成句），而非人工逐条撰写。但具体模型与 prompt 未公开，此为基于数据形态的合理推断。

**勘误（仓库代码 vs 实际数据集不一致）**：
- `generate_random_vector` 中厚度为 3–500 nm 随机，但实际数据集结构如 `PE_4730 nm, SiO2_4550 nm, VO2_1060 nm, ...`——厚度达数百至数千 nm，**两者参数不匹配**，说明公开的生成函数是早期版本，最终数据集用另一套参数（或演化版本）生成；
- 评估集样本索引不连续（1, 2, 1667, ...），说明 1w 评估集是从 10w 训练集中抽样得到（保留原索引）；

## 四、实验与结果

### 4.1 实验设定
- 聚焦 **1D RMM（堆叠多层薄膜）**，集成相变材料 **VO₂** 作为多态器件示例。
- VO₂ 在 >68 °C 发生快速可逆固-固相变：绝缘态（I-phase）→ 金属态（M-phase），带来显著光学反差。
- 关注的响应量为**吸收率（absorptivity）**；透射率由 T(λ)=1−R(λ)−A(λ) 计算。
- VO₂ 折射率取自 Ref [56]；验证时用 **TMM** 计算生成结构的多态吸收率并与目标对比。

### 4.2 与基线对比（Table 2）
对比覆盖四类方法：经典优化（GA、BO）、强化学习（DQN、PPO）、判别式深度学习（MLP/CNN/ResNet/Transformer Encoder）、生成式（cGAN、cVAE、OptoGPT）。这些基线**原设计都不面向多态 RMM**，作者为公平性给每个基线做了理论一致的适配。

| 指标 | 最强基线 cVAE | **CoSP** | 提升 |
|------|------------|---------|------|
| MSE ↓ | 0.0678 | **0.0342** | +49.6% |
| MAE ↓ | 0.1876 | **0.1181** | +37.0% |
| RMSE ↓ | 0.2370 | **0.1585** | +33.1% |
| R² ↑ | −0.1720 | **+0.4290** | 唯一正值 |
| Corr ↑ | 0.5320 | **0.7216** | +35.6% |
| SID ↓ | 1.3100 | **0.3686** | +71.9% |

**关键洞察**：
- SID（Spectral Integral Difference，光谱积分差）大幅下降（+71.9%），说明 CoSP 在**全局光谱形状**上更贴合，而非仅局部幅度拟合。
- CoSP 是**唯一 R² 为正**的方法（0.4290），所有基线 R² 为负——基线均未学到数据分布。
- 判别式回归（MLP/CNN/ResNet/Transformer）R² 为负、SID 差，本质是**一对多映射下确定性回归坍缩多解**。
- cGAN/cVAE 显式建模条件分布、较好应对一对多，但受限于**定长结构向量 + 噪声采样**、缺乏显式多态表征。
- RL（DQN/PPO）因 reward 需同时捕获双态光谱一致性，出现显著不稳定与 reward-目标失配。

### 4.3 逆向设计实例（Figure 3）
从测试集选两样本，输入双态吸收率光谱对，CoSP 生成光谱描述 + 材料结构，TMM 复算验证。结论：①光谱描述准确刻画输入双态光谱特征；②生成结构的光谱对与目标基本一致，**首次实现 RMM 的准确高效逆向设计**。

### 4.4 假设光谱探索（Figure 4）—— 超出训练分布
以**红外隐身（IR camouflage）**为例（目标模式 `'camouflage'`，代码中 State I 目标：3–5 μm 与 >8 μm 波段吸收率 0.9、5–8 μm 波段 0.05；State M 目标：5–8 μm 波段 0.9、其余 0.05；高斯滤波平滑 sigma=2）：
- 红外探测器工作于 2–5 μm 与 8–14 μm 波段；5–8 μm 波段（探测器不可见）用于辐射散热；
- 高温时（State M）5–8 μm 高发射率 → 强辐射制冷、降低总热辐射；低温时（State I）5–8 μm 低发射率 → 保温。

结果：即便目标是分段常数理想谱，CoSP 仍给出物理可行、光谱贴合目标、带连贯自然语言描述的 RMM 候选，**体现训练分布之外的泛化能力**。

### 4.5 光谱表示质量（Figure 5）
- **UMAP 可视化**：原始光谱空间两态大量重叠；学习表征形成**两个无重叠清晰簇**，且保留样本间邻域结构——编码器**增强态可分性、保留本征流形**。
- **跨态相似度矩阵**（X = S_I·(S_M)ᵀ）：CoSP 强对角占优（正确跨态配对），同法预训练的 CLIP 文本编码器无此对比度。

### 4.6 消融实验（Figure 6）
去掉对比式多态光谱预训练后，设计谱严重偏离目标，MSE 从 **0.152（完整 CoSP）恶化到 0.328（无对比预训练）**，验证对比预训练的必要性。（注：与 Table 2 的 MSE 差异源于评估子集/口径不同。）

## 五、网络设计深度解析（代码级）

> 本节依据开源代码（`model/Model.py`、`train_enc.py`、`dataset/data_loader.py`、`inference.py`）逐项还原。

### 5.1 光谱编码器（Encoder）结构与超参数
- 输入：100 维光谱（0.4–14 μm，100 点）；
- `projection = nn.Linear(100, 768)`：光谱 → GPT-2 隐藏维 768；
- 位置编码（即论文的 WavEncoding，见 §5.3）；
- `nn.TransformerEncoder`：**6 层、4 头**（`encoder_n_layers=6, encoder_n_heads=4`）；
- 投影头 `fc = Linear(768,768) → ReLU → Linear(768, 1024)`（即论文的 ClsHead）；
- 预训练：batch=256、lr=3e-4、weight_decay=1e-5、CosineAnnealing、温度默认 0.07、最多 1000 epochs。
- **阶段2 时**：`encoder.fc = nn.Identity()`（摘掉投影头）、`requires_grad_(False)`（冻结），编码器直接输出 768 维表征给解码器。

### 5.2 传统 CLIP token embedding 流程 & 为何破坏物理连续性
- **CLIP 文本编码器流程**：文本 → BPE 分词器切成离散 token → 查词表 `nn.Embedding` 得到离散 token 向量序列 → 叠加位置编码 → Transformer → 池化得到文本表征。
- **破坏连续性的原因**：光谱是波长 λ 上的**连续物理量**，相邻波长点强相关、峰谷具有物理意义；token embedding 把 100 个波长点当作 100 个"离散词"独立查表，丢弃了"波长坐标/邻域关系"这一物理信息，等价于把连续谱**分段、割裂地解释**（segmented interpretation），谱形信息受损，逆设计性能下降。因此 CoSP 用波长编码（绝对位置编码）直接把"波长位置"信息注入网络，而不用词表查找。

### 5.3 WavEncoding（波长绝对位置编码）实现
- 论文表述：**在序列方向施加的绝对位置编码**，替代 token embedding。
- 代码实现（`positional_encoding` 函数）：标准 Transformer 正弦-余弦位置编码表：
  ```python
  pe[:, 0::2] = sin(position * exp(-(log(10000)/d) * arange(0, d, 2)))
  pe[:, 1::2] = cos(position * exp(-(log(10000)/d) * arange(0, d, 2)))
  ```
  即 PE(pos,2i)=sin(pos/10000^(2i/d))、PE(pos,2i+1)=cos(pos/10000^(2i/d))，生成后为**可学习参数**（`nn.Parameter(..., requires_grad=True)`），并做归一化（减均值除标准差）。
- **实现细节**（与论文表述的对应）：代码中整条 100 维光谱先被线性层压缩为单个 768 维向量（序列长度=1），位置编码形状为 (1, 768)，**叠加在特征维度上**广播相加（`src = src + positional_encoding`）。即"波长信息"以可学习的绝对位置编码形式注入，而非离散词表。
- 编码器 forward：`projection(100→768) → +位置编码 → 6层Transformer → fc投影头 → 1024维表征`。

### 5.4 ClsHead（非线性全连接分类头）
- 论文：编码器后接全连接层 ClsHead，**仅在对比预训练阶段使用**；依据 **SimCLR** 结论——**非线性**（含激活函数）投影头比线性头产生更有效的表征。
- 代码实现：`self.fc = nn.Sequential(nn.Linear(768, 768), nn.ReLU(), nn.Linear(768, 1024))`（Linear→ReLU→Linear，输出 1024 维，用于 InfoNCE/CLIP 对比）。
- 本质是 **SimCLR 式非线性投影头（projection head）**，论文称"分类头"，命名略有出入；下游生成阶段被摘除（`nn.Identity()`）。

### 5.5 InfoNCE 对比损失的设计思路
- **出发点**：RMM 的两态光谱必须"既分得开、又对得上"——不同器件要区分（state-discriminative），同一器件两态要关联（sample-consistent）。对比学习天然适配：把"同一器件不同态"构成**正样本对**。
- **形式**（论文式 2）：对每个 anchor 态 j 样本 i，正样本为另一态 j* 的同一样本 i 的表征，负样本为 batch 内其他样本的对应态；InfoNCE 等价于"在 n 个候选里找出正样本"的 n 分类交叉熵：
  ```
  Lⱼ = -(1/n) Σᵢ log [ exp(cos(sⱼⁱ, sⱼ*ⁱ)/τ) / Σₖ exp(cos(sⱼⁱ, sⱼₖ*)/τ) ]
  ```
  τ 为温度参数，控制相似度分布锐度（论文称可学习；代码默认 0.07，CLIP 模式下 logit_scale 为可学习参数）。
- **代码实现**（`ConEnc`）：batch 前半为 State I、后半为 State M（n_views=2）；特征 L2 归一化后计算全相似度矩阵，mask 掉对角线（自身），正对/负对拼成 logits 除以温度后做交叉熵。默认使用 CLIP 对称损失（两个方向的交叉熵平均）。

### 5.6 GPT-2 解码器输出 & 结构文本的固定与解析
- **输出格式**（真实推理示例，`target='camouflage'`，seed=2025）：
  ```
  <|endoftext|>In State I, absorption is notably high around 3-5 microns and again at 10-12 microns, while it is very low below 2 microns and above 8 microns. In contrast, State M shows a gradual increase in absorption from 1 micron to 14 microns, ... The material structure is Ge_100 nm, PEI_240 nm, VO2_1370 nm, SiO2_1370 nm, Al2O3_1370 nm, SiO2_1370 nm, Al_1370 nm, SiN_1370 nm, Al2O3_1370 nm, SiO2_1370 nm<|endoftext|>
  ```
  即 **[光谱描述文本（两态峰谷的英文描述）] + " The material structure is " + [材料_厚度nm 逗号分隔列表] + <|endoftext|>**。
- **"固定格式"是如何保证的 —— 没有硬性语法约束，靠三层机制**：
  1. **训练模板统一**（`data_loader.py`）：所有样本的标签文本都构造成 `description + ' The material structure is ' + Material Structure + <eos>`，CLM 自回归目标学到该固定句式；
  2. **tokenizer 处理**：add_special_tokens、truncation 到 block_size、padding='max_length'；labels 中 pad 位置置 −100（不参与损失）；
  3. **推理规则解析**（`inference.py`）：贪心解码（argmax，max_length=1000，遇 EOS 停止）→ `output_text.split("The material structure is ")[1]` → 按 `", "` 切分得到每层 → 每项再按 `"_"` 切分得材料名与厚度串。
  - **风险点**：这是"数据模板约束下的自由文本生成 + 字符串规则解析"，并非结构化输出（无 schema 约束）；若生成偏离模板（如漏掉 "The material structure is"、层分隔符异常），解析会失败——代码中没有兜底/校验逻辑。
- **文本 → 材料组分序列的转换**：
  - 每层 `Ge_100 nm`：`split("_")` → 材料名 `Ge`、厚度串 `100 nm`；
  - 厚度：`''.join(filter(str.isdigit, thickness))` 提取数字 → `int`；
  - 材料：通过 `material_mapping`（编码→材料名）反查（`list(keys)[list(values).index(material_name)]`），如 Ge=3、VO2=4、BaF2=5、ZnS=6、Al2O3=7、PE=8、PDMS=9、SiO2=10、PEI=11、SiN=12、TiO2=13、Al=14、W=15；
  - 得到 `material_vector`（编码列表）+ `thickness_vector` → 调用 TMM `calculate_reflectance_I/M` 计算双态吸收率与目标比对（Figure 3 / 4 验证流程）。

### 5.7 模型关键超参汇总
| 项目 | 值 |
|------|-----|
| 光谱输入 | 100 维（0.4–14 μm） |
| Encoder | 6 层 Transformer、4 头、hidden=768（对齐 GPT-2） |

## 六、创新点总结

1. **首个面向可重构超材料（RMM）多态逆向设计的框架**：一个结构同时满足一对状态相关光谱。
2. **对比式多态光谱预训练**：把"同一器件两态"作为正样本对，用 InfoNCE 学出"态可分离、样本一致"的光谱表征；并针对光谱连续性用**波长编码替代 token embedding**。
3. **LLM 生成能力 + 物理理解的融合**：GPT-2 解码器经 cross-attention 条件化于光谱表示，端到端同时输出**自然语言光谱描述 + 材料结构序列**，可解释、人类可读。
4. **远超训练分布的泛化**：能对理想方波（红外隐身）等自然界几乎不存在的假设光谱给出物理可行方案。
5. **全面能力覆盖**（Table 1）：多波段、自由材料、动态层数、迁移性、通用性、多态、语言可解释性七项能力首次集于一体。

## 七、局限与思考（批判性阅读）

1. **仅验证 1D 多层膜堆叠**：正文聚焦 VO₂ 1D RMM；2D 超表面/3D 超材料仅在结论作为展望（"seamlessly extended to ... 2D metasurfaces and 3D metamaterials"），未实现。**框架本身不依赖维度**（光谱输入是 100 维向量、结构用文本表示），迁移障碍在于结构→文本的表示能力、训练数据生成的正向求解器、以及 token 长度限制。
2. **VO₂ 光学常数外源**：依赖 Ref [56] 的 VO₂ 折射率数据（代码中 `Data/VO_2 I.csv` / `VO_2 M.csv`），未讨论材料数据不确定性。
3. **"假设光谱"结果偏定性**：Figure 4 的方波目标本身不可物理实现，正文未给该场景定量误差。
4. **R² 绝对值仍偏低（0.429）**：显著优于基线，但多态逆设计精度上限尚待提升。
5. **GPT-2 规模较小**：作者自述换更大开源 LLM 有望更好，未实测。
6. **可制造性/加工约束未纳入**：生成结构未显式考虑层厚工艺极限、材料兼容性等制造约束。
7. **生成输出的鲁棒性**：结构文本靠"模板一致 + 规则解析"，无 schema 强制；格式漂移即解析失败。
8. **数据集为纯合成数据**：10 万条 TMM 合成样本，光谱经取整量化（round 到 2 位小数），与真实测量谱的分布偏移（sim-to-real gap）未讨论。
