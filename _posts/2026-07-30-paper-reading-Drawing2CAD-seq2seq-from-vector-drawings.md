## 一、研究目的与动机

### 1.1 问题定位
参数化 CAD 生成已有多种输入形式（点云、网格、体素、图像、文本），但都**偏离了工业设计的真实工作流**——工业界的设计起点是 **2D 工程图纸**，设计师再根据图纸手动建 3D 模型，耗时且依赖经验。

现有路线的痛点：
- **Text-to-CAD**: 文本难以表达精确尺寸与空间关系，存在固有歧义；
- **草图/图像→CAD**: 多基于**栅格图像**（像素），受限于尺度变化、线宽差异、栅格化伪影，几何精度损失严重；
- **矢量格式（SVG）天然编码精确几何图元**，与工程设计意图对齐，但此前**无人探索**从 SVG 工程图直接生成参数化 CAD 序列。

### 1.2 三大挑战
1. SVG 文件的预处理与解析（提取有意义的几何信息）；
2. 2D 矢量草图 → 3D 参数化模型的**跨模态维度跨越**；
3. 缺乏标准化的 SVG-to-CAD 配对数据集。

### 1.3 核心洞察（Key Insight）
SVG 绘图过程与 CAD 建模过程**在形式上同构**：两者都是"参数化命令序列"（Figure 1）。因此可将 CAD 生成重新定义为 **sequence-to-sequence 学习问题**——矢量图元序列直接"翻译"为 CAD 操作序列，全程保留几何精度与设计意图。

## 二、方法

### 2.1 总体框架（四阶段）
1. **矢量输入处理**: 网络友好的工程图表示 + 嵌入；
2. **CAD 编码**: Transformer 编码器输出潜在向量 z；
3. **双解码**: Command Decoder 生成命令类型，Argument Decoder 在命令引导下生成参数；
4. **CAD 生成**: 命令+参数合并为完整操作序列，经 OpenCASCADE (PythonOCC) 内核构建 3D 模型。

支持**三种输入配置**: 单等轴测视图(1x) / 三正交视图(3x) / 四视图组合(4x)。

### 2.2 CAD-VGDrawing 数据集（重要贡献）
- **来源**: DeepCAD 数据集约 176,000 个 CAD 模型；
- **生成管线**: 自写 FreeCAD Python 脚本，用 **TechDraw 模块**自动将 STEP → 工程图 → 导出 SVG；每模型生成 4 个标准视图（前/俯/右 + 等轴测 front-top-right）；再用 **CairoSVG** 栅格化为 PNG（供栅格对照实验）；
- **预处理**:
  - 贝塞尔曲线段简化（对比后保留 FreeCAD 原生分段，未额外处理）；
  - **路径重排序**: FreeCAD 输出的 SVG 路径顺序不规则 → 以画布左上角为原点，用图论算法（NetworkX）识别所有轮廓，按到原点距离递增排序，每个轮廓顺时针绘制；
  - SVG 归一化到 **200×200 viewbox**；PNG 统一 resize 到 224×224；
- **筛选**: FreeCAD 处理部分复杂模型失败 → 过滤后剩 **161,407** 模型；再按 SVG 序列长度 ≤100 筛选 → **最终 157,591 对 SVG-to-CAD 样本**，按 90%/5%/5% 划分训练/验证/测试。

### 2.3 矢量工程图表示（Network-friendly Representation）
- 只保留核心几何信息，剔除可见性、颜色、填充等非本质路径属性；
- 命令集仅 **LineTo (L)** 和 **CubicBézier (C)** 两类，每条命令统一为 **8 维参数列表**:
  - X = (x₁, y₁, cx₁, cy₁, cx₂, cy₂, x₂, y₂) ∈ ℝ⁸
  - LineTo 只用起止点，控制点参数置 **-1**；CubicBézier 用满 8 个参数；
- 每张工程图为有序序列 Dᵢ = {S₁,...,S_N}（N=100），子序列 Sᵢ = (vᵢ, Cᵢ)，其中 vᵢ ∈ {Front, Top, Right, Isometric} 为**视图标签**，Cᵢ = (c, X) 为命令+参数；
- 参数量化为 **8-bit 整数**（one-hot 维度 2⁸+1 = 257，多一维容纳未用参数）。

### 2.4 网络架构

**嵌入层（拼接式融合，关键设计）**:
- 与 DeepSVG/DeepCAD 等"直接线性相加"不同，本文将 view/cmd/param 三类嵌入**拼接后过 MLP**，显式建模跨字段交互：
  - E_D(i) = MLP(CONCAT(e_view, e_cmd, e_param)) + e_pos ∈ ℝ^256
- 参数嵌入：共享矩阵 W_b^param ∈ ℝ^(d_e×257) 按列嵌入 8 个参数 → flatten → W_a^param ∈ ℝ^(d_e×8d_e) 投影；
- 单视图输入时视图嵌入冗余，退化为 MLP(CONCAT(e_cmd, e_param)) + e_pos；
- d_E = 256；多视图按固定顺序堆叠（前/俯/右/等轴测）。

**编码器**: 4 个 Transformer block，8 头注意力，FFN 维度 512；输出序列取平均得到潜在向量 z（256 维）。

**双解码器（Dual Decoder）**:
- 两个独立 Transformer 解码器（超参与编码器相同），输入为可学习常量嵌入，交叉注意 z；
- **Command Decoder** 预测命令类型 t̂ᵢ（Line/Circle/Arc/Extrude 等 DeepCAD 命令体系）；
- **Argument Decoder** 生成参数向量 p̂ᵢ = [x, y, α, f, r, θ, γ, p_x, p_y, p_s, s, e₁, e₂, b, μ]（15 维）；
- **命令引导生成（command-guided）**: 将 Command Decoder 的输出**加到** Argument Decoder 的输出上，把命令语义注入参数生成，保证参数与命令类型上下文一致。

### 2.5 软目标分布损失（Soft Target Distribution Loss）
- 总损失 = 命令损失 L_cmd + 参数损失 L_args；
- **动机**: CAD 参数本身容忍微小变化而不破坏设计意图，硬 one-hot 分类过于苛刻；
- 参数损失用**平滑目标分布**替代 one-hot：
  - L_args = −ΣᵢΣⱼΣ_k ỹ_k · log(ŷ_k)
  - ỹ_k = e^(−α|k−y|) / Z（指数衰减，Z 归一化）
  - 仅在 [y−tolerance, y+tolerance] 窗口内赋非零权重；
  - 实际 **α = 2.0, tolerance = 3**；
- 效果：减轻对"轻微偏差但可接受"预测的过度惩罚，提升泛化（消融验证）。

### 2.6 评估指标
- **ACC_cmd**: 命令类型准确率（指示函数精确匹配）；
- **ACC_param**: 仅对命令预测正确的样本，参数误差 |p−p̂| < η 的比例，**η = 3**（与损失容差一致）；
- **MCD**: 生成模型表面采样 K=2000 点云的平均 Chamfer Distance（×10²）；
- **IR (Invalidity Ratio)**: 无法构建有效 3D 形状的序列比例（×100%）。

## 三、实验与结果

### 3.1 设置
- 单卡 RTX 4090，batch 256，200 epochs；
- Adam，lr = 0.001，前 2000 步线性 warm-up；dropout 0.1；梯度裁剪 1.0；
- 该任务无现成可比方法，作者构造两个基线：
  - **DeepCAD-vector**: DeepCAD 的命令输入换成 SVG 命令输入，其余不变；
  - **DeepCAD-raster**: 编码器换成 DINOv2 预训练 ViT 特征提取器，吃 PNG。

### 3.2 矢量 vs 栅格输入（Table 1，DeepCAD 改造基线）

| 输入 | 方法 | ACC_cmd↑ | ACC_param↑ | IR↓ | MCD↓ |
|------|------|---------|-----------|-----|------|
| 1x 等轴测 | raster | 75.60 | 69.44 | 30.54 | 17.67 |
| | **vector** | **80.78** | **73.73** | **23.29** | **11.52** |
| 3x 正交 | raster | 76.81 | 70.74 | 30.38 | 18.73 |
| | **vector** | **81.39** | **74.76** | **22.97** | **12.15** |
| 4x 组合 | raster | 77.69 | 70.49 | 29.79 | 18.16 |
| | **vector** | **81.51** | **75.14** | **23.40** | **11.37** |

**结论**: 三种配置下矢量输入全面大幅优于栅格输入（ACC_cmd +4~5 pp，IR −7 pp 左右，MCD −6~7），证明 SVG 图元提供更精确、语义更丰富的结构信息。

### 3.3 与基线对比（Table 2，矢量输入）

| 输入 | 方法 | ACC_cmd↑ | ACC_param↑ | IR↓ | MCD↓ |
|------|------|---------|-----------|-----|------|
| 1x | DeepCAD-vector | 80.78 | 73.73 | 23.29 | 11.52 |
| | **Drawing2CAD** | **81.81** | **74.35** | **21.40** | 12.10 |
| 3x | DeepCAD-vector | 81.39 | 74.76 | 22.97 | 12.15 |
| | **Drawing2CAD** | **82.12** | **75.43** | **20.99** | **11.98** |
| 4x | DeepCAD-vector | 81.51 | 75.14 | 23.40 | 11.37 |
| | **Drawing2CAD** | **82.43** | **76.09** | **20.31** | **10.88** |

- 4x 配置下全面最优；1x 时 MCD 略高（12.10 vs 11.52），但 IR 显著更低（CD 只对成功生成的模型计算，需联合解读）；
- 定性对比：优于传统规则法 **Photo2CAD**（OpenCV 提特征+布尔运算），后者对复杂几何失效。

### 3.4 消融实验（Table 3）
逐步加入：双解码器 → 软目标损失 → 命令引导 → 拼接式嵌入。
- 双解码器+软损失：参数精度提升（如 3x: 74.76→75.17）；
- +命令引导：IR 下降（3x: 22.59→21.52）；
- +拼接嵌入（完整模型）：全面最优（3x: ACC_cmd 82.12 / IR 20.99 / MCD 11.98）；
- **拼接式嵌入 vs 线性相加**：替换后提升显著，验证"拼接更能捕捉 view/cmd/param 间依赖"的假设；
- 1x 单视图下完整模型 IR 最低，体现有限视图下的鲁棒性权衡。

### 3.5 局限性（Figure 6 + 附录）
1. **参数精度问题**: 软损失容差设计稳定优化但牺牲参数级精度——整体形状对但尺寸偏差（更厚/孔更小/更薄）→ 需不确定性感知建模；
2. **视图信息权衡**: 正交视图保对称/布局但缺深度；等轴测补深度但平面对齐差；
3. **多视图融合冲突**: 视图间线索不一致（如正交图显示凸台而等轴测图省略）会产生歧义 → 需鲁棒多视图融合；
4. **视图信息依赖**: 所有视图都不可见的特征（如被遮挡的侧孔）无法恢复 → 半监督学习/隐式先验可能帮助推断遮挡几何。

## 四、创新点总结

1. **任务开创性**: 首次提出从**矢量工程图（SVG）**直接生成参数化 CAD 操作序列，把 CAD 生成重新定义为 seq2seq 学习问题，与工业设计工作流天然对齐；
2. **网络友好的矢量图表示**: 统一 8 维参数化（LineTo/CubicBézier），视图标签 + 轮廓重排序 + 归一化的系统预处理管线；
3. **双解码器架构**: 命令/参数解耦生成 + **命令引导**机制保证语义一致；
4. **软目标分布损失**: 承认 CAD 参数固有容差（α=2.0, tol=3），缓解硬分类过罚；
5. **CAD-VGDrawing 数据集**: 157,591 对 SVG-CAD 配对（源自 DeepCAD，FreeCAD TechDraw 自动生成），含矢量+栅格双格式，已开源。

## 五、个人思考与关联

- **与 DeepCAD 的关系**: 本文本质是 DeepCAD 框架在"SVG 工程图条件生成"场景下的扩展——编码器输入从自回归 CAD 序列换成 SVG 序列，解码侧做了命令/参数解耦。基线对比也是公平改造（DeepCAD-vector），消融设计规范。
- **"SVG≈CAD 序列同构"的洞察**是全文最核心的卖点：两者都是参数化命令流，seq2seq 翻译的归纳偏置比"图像→序列"合理得多，Table 1 的栅格/矢量对比（IR 30% vs 23%）是这个论点最有力的证据。
- **工程图生成依赖 FreeCAD TechDraw**: 数据质量受限于 FreeCAD 对复杂模型的支持（176k→161k 损耗 ~8%）；且自动生成的工程图不含**尺寸标注、公差、隐藏线**等真实工程图要素——与真实工业图纸仍有差距，这是数据集向实际应用迁移的主要 gap。
- **命令体系仅 4 类**（Line/Circle/Arc/Extrude），限于 DeepCAD 的单拉伸体；真实 CAD 含旋转、扫掠、放样、多体布尔等，泛化空间有限。
- **软目标损失可迁移**: "参数容差感知"的指数衰减平滑标签思想简单有效，可借鉴到任何"量回归被离散化为分类"的任务（如我们光谱反演中厚度/折射率的离散化预测）。
- **评价仍偏几何**: ACC/MCD/IR 衡量重建保真度，但未评估"参数化可编辑性"（生成序列是否接近人类建模习惯、是否方便后续参数修改）——恰是参数化 CAD 相对直接网格生成的核心价值。
- **多视图输入是浅层融合**（固定顺序拼接序列），失败案例显示视图冲突时无显式对齐机制；交叉注意力/视图级 transformer 可能是改进方向。
