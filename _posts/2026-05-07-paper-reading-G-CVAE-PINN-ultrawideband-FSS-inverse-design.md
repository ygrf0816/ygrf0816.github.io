## 一、研究背景与动机

### 1.1 频率选择表面（FSS）概述

频率选择表面是由**周期性亚波长微结构**组成的平面阵列，能够对电磁波实现选频透射/反射控制，广泛应用于：
- 雷达天线罩（Radome）
- 电磁干扰（EMI）屏蔽
- 极化转换器
- 吸波体

### 1.2 传统设计方法的局限

| 方法 | 局限性 |
|------|--------|
| 等效电路模型（ECM） | 难以处理复杂几何和高阶模式 |
| 特征模分析（CMA） | 仅适用于线性、时不变结构，无法处理可调或各向异性材料 |
| 全波仿真 | 依赖大量参数扫描，设计周期长 |
| 像素/参数化神经网络 | 数据集依赖强、参数选取受限，忽略极化灵敏性 |
| 矢量图特征提取（VGFE） | 忽略微小几何变化，误差增大 |
| Fourier子空间模型 | 无法捕获局部化特征 |
| 逆拓扑设计（ITDM） | 可能产生不可制造的方案 |

> **核心矛盾**：现有方法要么精度不够，要么缺乏物理约束，导致生成的设计不满足电磁物理可行性。

### 1.3 本文解决思路

将**图神经网络（GCN）+ 条件变分自编码器（CVAE）+ 物理信息神经网络（PINN）** 三者融合，提出 G-CVAE-PINN 框架，在保持设计多样性的同时，通过物理约束确保生成结构的电磁真实性。

---

## 二、主要创新点

1. **G-CVAE 与 PINN 的首次集成**：将图学习、条件生成建模与物理定律约束统一在一个框架中，针对 FSS 精确设计的全新尝试。

2. **克服矢量法几何细节丢失 + PINN 收敛慢的双重挑战**：引入 G-CVAE-PINN 框架，协同解决这两个痛点。

3. **图表征捕获复杂拓扑关系**：相较于像素或矢量格式，图结构天然编码 FSS 单元格内的空间与拓扑关系，更适合不规则/互连结构。

4. **高效训练策略**：平衡数据驱动损失与物理约束损失，实现稳定高效的端到端训练。

5. **增强泛化与精度**：特别是在多频段和极化不敏感条件下，实现更快收敛和更高预测精度。

## 三、模型架构：G-CVAE-PINN

### 3.1 总体流程

```
FSS 几何图结构 (Graph) + S₂₁参数
        ↓
   图卷积网络 (GCN) 编码器
        ↓
   潜在空间 (μ, σ)
        ↓
   重参数化采样 z = μ + σ·ε
        ↓
   解码器 (全连接层)
    ├── 重建 FSS 几何图结构
    └── 预测 S₂₁(f) 频响
        ↓
   PINN 约束（等效电路模型 ECM）
        ↓
   混合损失函数优化
```

### 3.2 数据集构建

- **样本数量**：3300 个 FSS 单元格设计
- **仿真工具**：ANSYS HFSS V.2024R1
- **频率范围**：8–28 GHz，步长 0.05 GHz，共 **401 个频率点**
- **数据维度**：3300 × 401
- **数据集划分**：70% 训练（2310）/ 20% 验证（660）/ 10% 测试（330）
- **数据增强**：旋转、缩放、特征修改几何变换，扩充设计空间多样性
- **硬件**：Intel Xeon 32核 CPU + 128GB RAM，每样本仿真约 3 分钟

### 3.3 编码器：GCN 图特征提取

FSS 结构被表示为图（节点 = 结构元素，边 = 空间关系）。GCN 通过**消息传递机制**逐层聚合邻域信息：

$$h_i^{(\ell+1)} \leftarrow \sigma\!\left(W^{(\ell)} \sum_{j \in \mathcal{N}(i)} h_j^{(\ell)} + b^{(\ell)}\right)$$

经多层 GCN 后，FSS 结构被压缩为单一向量，融合了结构和材料属性。

再将该图嵌入与 S₂₁ 参数拼接，形成**联合特征向量**：

$$Z = f_{\text{enc}}(\text{Graph features}, S_{21})$$

全连接层进一步映射为潜在空间的均值与方差：

$$\mu = f_{\text{mean}}(Z), \quad \sigma = f_{\text{var}}(Z)$$

### 3.4 重参数化技巧

$$z = \mu + \sigma \cdot \varepsilon, \quad \varepsilon \sim \mathcal{N}(0, I)$$

- 允许梯度反传（可微采样）
- 维持随机性，保留设计多样性
- 通过正则化约束潜在空间接近标准正态分布

### 3.5 解码器：FSS 几何重建

采样的潜在向量 $z$ 与目标频响拼接后输入解码器：
- 全连接层扩展潜在向量为结构化 FSS 表示
- GNN 解码器重建节点连接和边特征，生成有效 FSS 拓扑

## 四、PINN 部分（重点）

### 4.1 PINN 在本文中的定位

PINN 作为 G-CVAE 框架的**物理约束模块**，与解码器通过等效电路模型（ECM）深度集成。其核心作用是：

> **确保生成的 FSS 设计在电磁物理上是可行的，而非仅仅是数据统计层面的合理预测。**

### 4.2 物理约束的来源：等效电路模型（ECM）

解码器预测的不仅仅是 FSS 图结构，还预测等效电路的 R、L、C 参数，通过 ECM 计算出物理解析频响 $S_{21}^{\text{ECM}}(f)$：

$$S_{21}^{\text{ECM}}(f) = \frac{2Z_0}{2Z_0 + Z_{\text{eq}}(f)}, \quad Z_{\text{eq}}(f) = \frac{R}{1 + j\omega C} + j\omega L$$

其中感抗和容纳通过以下 ECM 公式计算（考虑角度和极化效应）：

$$\frac{X_{L_i}(w)}{Z_0} = F(p, w, \lambda, \theta) = \frac{p\cos\theta}{\lambda} \left[\ln\csc\frac{\pi w}{2p} + G(p, w, \lambda)\right]$$

$$\frac{B_{c1}}{Y_0} = F(p, a, \lambda, \phi)$$

有效介电常数随基底参数修正：

$$\varepsilon_{\text{eff}} = \varepsilon_r - (\varepsilon_r - 1)e^{-M(y)}, \quad y = \frac{10h}{p}$$

### 4.3 PINN 损失函数

PINN 损失 $L_{\text{PINN}}$ 定义为 G-CVAE 预测频响与 ECM 物理解析频响之间的**相位与幅度双重差异**：

$$L_{\text{PINN}} = \frac{1}{N_f} \sum_{k=1}^{N_f} \left[\left(|\hat{S}_{21}(f_k)| - |S_{21}^{\text{ECM}}(f_k)|\right)^2 + \left(\angle\hat{S}_{21}(f_k) - \angle S_{21}^{\text{ECM}}(f_k)\right)^2\right]$$

> 同时约束**幅度**（传输系数量级）和**相位**（谐振行为），全面强化物理一致性。

### 4.4 混合损失函数总览

$$\mathcal{L} = \lambda_1 L_{\text{RL}} + \lambda_2 L_{\text{KL}} + \lambda_3(t) L_{\text{PINN}}$$

| 损失项 | 公式 | 作用 |
|--------|------|------|
| **重建损失 $L_{\text{RL}}$** | $\alpha \cdot \text{MSE}_{\text{SPEC}} + (1-\alpha) \cdot \text{PerceptualLoss}$ | 确保生成 FSS 具有期望频响 |
| **KL散度损失 $L_{\text{KL}}$** | $\frac{1}{2}\sum_d(\mu_d^2 + \sigma_d^2 - \log\sigma_d^2 - 1)$ | 正则化潜在空间为高斯先验 |
| **PINN 物理损失 $L_{\text{PINN}}$** | 见上节公式 | 物理约束，确保 ECM 一致性 |

其中：
- $\text{MSE}_{\text{SPEC}} = \frac{1}{N_f}\sum_k\left(|S_{21}^{\text{sim}}(f_k)| - |\hat{S}_{21}(f_k)|\right)^2$
- $\text{PerceptualLoss} = \frac{1}{N_l}\sum_{l \in L}\|\phi_l(\text{img}_{\text{in}}) - \phi_l(\text{img}_{\text{pred}})\|_2^2$（CNN 多层特征图差异）
- $\alpha = 0.8$（通过验证实验确定，平衡谱精度与结构保真度）

### 4.5 余弦退火调度 $\lambda_3(t)$

PINN 权重采用**余弦退火调度**，避免早期训练被物理约束主导：

$$\lambda_3(t) = \lambda_{\min} + \frac{1}{2}(\lambda_{\max} - \lambda_{\min})\left[1 - \cos\left(\frac{\pi t}{T_{\text{ramp}}}\right)\right]$$

- 训练初期 $\lambda_3$ 较小 → 让数据驱动模块先学习基本映射
- 随训练深入 $\lambda_3$ 逐渐增大 → 物理约束渐进式加强

### 4.6 PINN 的不确定性量化（UQ）

定义基于 PINN 的**不确定性量化指标**：

$$\text{UQ}(f_k) = \left|\hat{S}_{21}(f_k) - S_{21}^{\text{ECM}}(f_k)\right|^2$$

含义：预测频响与 ECM 物理频响的偏差越大，意味着该频点处的预测置信度越低。

**UQ 分析结论**：
- 谐振频率处 UQ 和 MSE 峰值较高（谐振点附近预测挑战大）
- UQ 和 MSE 并不总是同步变化：某些情况下 UQ 较宽而误差较低，说明模型在敏感频段对潜在变异性有预判
- 通带内模型可靠性高，谐振凹陷附近需谨慎解读预测结果

### 4.7 PINN 在本文中的作用总结

```
物理法则嵌入方式：等效电路模型（ECM）解析解 作为物理先验
约束目标：幅度一致性 + 相位一致性
嵌入位置：解码器输出层 → ECM计算 → PINN损失 → 反传至全网络
训练策略：余弦退火调度，渐进式增强物理约束权重
评估工具：UQ 指标定量衡量预测置信度
```

> **与典型 PINN 的区别**：传统 PINN 将 PDE 残差直接嵌入损失；本文将 ECM 解析模型作为等效"物理方程"，更适合无解析 PDE 的电磁工程问题。

## 六、结论

1. 提出了基于 G-CVAE-PINN 的**带阻 FSS 逆向设计**新框架，将图学习、生成模型与物理约束统一在混合损失函数中。

2. 所预测 FSS 设计**数据一致且物理可行**，具备角度和极化稳定性。

3. 三谐振 FSS 实现 **8–28 GHz 超宽阻带（20 GHz）**、**80 dB 屏蔽效能**、**±75° 角度稳定**（TE/TM）。

4. 平均相对误差约 **3%**，在单元尺寸（0.08λg）和性能指标上优于现有文献。

5. 适用于雷达天线罩、EMI 屏蔽、卫星通信及 5G/超5G 超宽带应用。

## 七、批判性分析

### 7.1 方法优势

- **图表征**比像素/矢量格式更自然地描述 FSS 拓扑关系
- **ECM 作为物理先验**是 PINN 的轻量化替代方案，无需昂贵的全波 PDE 约束
- 余弦退火调度使物理约束渐进式生效，避免训练初期不稳定
- UQ 机制为工程应用提供了可靠的置信度度量

### 7.2 潜在不足

| 问题 | 描述 |
|------|------|
| **ECM 精度边界** | ECM 本身在极复杂几何下存在近似误差，限制了 PINN 物理约束的上界 |
| **数据集规模** | 3300 样本对于高维设计空间相对有限，三谐振精度略低印证了这一点 |
| **ECM 参数自动化** | R、L、C 参数的提取和映射细节未完全说明，可复现性存疑 |
| **谐振频点误差** | 靠近谐振处预测置信度下降，对精细频点调控不够稳定 |
| **仅阻带类型** | 仅验证 bandstop FSS，带通 FSS 的适用性未知 |
| **泛化测试有限** | 仅对 3 个文献结构进行了跨结构验证，样本量小 |

### 7.3 与其他 PINN 应用的横向比较

| 维度 | 本文（ECM-PINN） | 经典 PINN（PDE 残差） |
|------|----------------|----------------------|
| 物理嵌入方式 | ECM 解析公式作为约束 | PDE 方程残差 |
| 适用场景 | 电磁工程（有解析模型）| 流体、力学、传热等 |
| 计算代价 | 较低（ECM 计算快） | 较高（需要 PDE 积分）|
| 物理精度 | 受 ECM 近似限制 | 更接近第一原理 |
| 收敛速度 | 较快 | 有时收敛慢 |

## 八、与研究方向的关联思考

- **超表面逆向设计**：本文的 G-CVAE-PINN 框架可迁移至超表面（Metasurface）设计，尤其是具有周期结构的热控/辐射制冷超表面。
- **物理约束生成模型**：PINN 损失函数的设计思路对光学常数反演（薄膜 n/k/d 预测）也有参考价值——可将 Fresnel 方程或 TMM 作为物理约束嵌入。
- **图神经网络用于结构编码**：对于不规则或互连的纳米结构（如分形型超表面单元），GCN 编码优于像素化或参数化方法。
- **不确定性量化**：UQ 基于 ECM 偏差的思路，可借鉴用于椭偏仪测量中的误差置信评估。
