# 第 0 章 速览

## 0.1 一句话定位

这是一篇 **"相变材料（PCM）→ 动态热辐射 → 自适应智能热管理"** 技术链条的系统性综述：以 **AMnO₃ 钙钛矿锰氧化物 / VO₂ / GST（Ge₂Sb₂Te₅）** 三种金属–绝缘体相变（MIT）材料为轴心，梳理相变机理、掺杂调控、制备路线、结构设计范式与工程应用，最终收敛到"性能平衡 + AI 设计 + 规模化制造"三大瓶颈。

**它的独特价值**在于两点：

1. 是目前少见的把三种 PCM 放在**同一评价框架**下横向对比的综述（Table 1 + Table 2）；
2. 把**结构增强机理**单独成节（第 4.2 节），而不是混在材料章节里一带而过——对做辐射制冷 / 红外隐身 / 智能窗 / 超表面逆设计都很实用。

## 0.3 最值得记住的七条结论

1. **发射率 ε 比温度 T 更适合做调控旋钮**（§1.2）——改 ε 不引入额外温控器件，但绝大多数材料的 ε 由结构固定，于是研究焦点落在"能响应外场改变 ε"的 PCM 上。
2. **"高发射 + 低太阳吸收"是贯穿全文的核心矛盾**（α_sol 与 ε 的波段错配）。单一 PCM 无法同时满足，必须靠结构设计——这是全文所有结构工作的共同动机。
3. **VO₂ 是唯一具有"正 / 负微分发射率双路径"的材料**（§2.2.3）：ε 随 T 升高而升（PDTE，自稳定）或而降（NDTE，可致辐射热失控）都做得到，且可通过结构互转。这既是风险也是设计自由度。
4. **GST 的核心卖点是"三态 + 非易失 + 纳秒切换"**：非晶 / 亚稳 FCC（150 °C）/ 稳定六方（200 °C），晶态保持无需持续供能——这是它区别于 VO₂ 的根本优势。
5. **掺杂增强发射率的微观机制可归纳为五条**（§2.1.4）：晶格畸变→局域偶极矩；杂质带→带隙窄化；局域声子模→发射带展宽；氧空位散射声子→热局域化；小极化子→极化率改变。**短波走电子跃迁通道，长波走声子通道**，两者分工是普适规律。
6. **评价范式正在从"看 Δε 数字"转向"综合平衡"**（§3.1 末）——Δε 不再是唯一判据，还要看 α_sol、稳定性、可制造性、切换速度。
7. **综述自己承认的首要障碍是"数据稀缺"**（§5.2 原文 *data scarcity remains the foremost obstacles*），并点名需要 **"相态分辨的 n/k 光谱 + 制备参数"跨尺度关联数据库**。这句话是本领域 AI for science 最直接的入场券（详见附录 B）。

# 第 1 章 物理基础：什么叫"动态热辐射"

## 1.1 问题的起点

传统材料的热辐射是**宽带、全向、非相干**的——发射率 ε 基本恒定，光子调控自由度极低。这与自适应热管理所要求的能力（辐射制冷、红外成像、航天器热控）直接冲突。

理想动态热辐射需同时满足：**大发射率变化 Δε、长寿命、波长可调**。难点在于这三者很难与纳米光子学结构的设计原则在复合材料中兼容集成。

## 1.2 调控路径：为什么选发射率而不是温度

由 Stefan–Boltzmann 定律出发：

```
E_rad = ε·σ·(T_H⁴ − T_C⁴)                     (1)
σ = 5.67051×10⁻⁸ W/(m²·K⁴)
```

系统达平衡时：

```
E_g + E_a = ε·σ·(T_H⁴ − T_C⁴)                 (3)
```

**推论**：物体热辐射可由温度 T 或发射率 ε 两条路径调控。

- **改 T**：需额外引入温控材料 / 器件 → 系统复杂度上升 ❌
- **改 ε**：更合理 ✅ —— 但绝大多数材料的 ε 由内部结构决定，是固定的

**⇒ 研究焦点落到"能响应外部条件改变 ε"的材料上，即 PCM。**

**关键约束**：热辐射发生在 **2.5–25 μm**，而太阳能吸收 α_sol（0.3–2.5 μm）必须保持低。这条"高发射 + 低吸收"的矛盾是全文的评价主线——单一 PCM 无法同时满足，必须做结构设计。

## 1.3 自适应性的物理判据与辐射热失控

若环境温度稳定，为维持系统温度稳定，**发射率必须随辐射能量的增减而同向变化**——这就是"动态热辐射"。否则会导致热辐射系统温度崩溃。

由能量平衡：

```
C·dT/dt = E_gain − ε(T)·σ·(T⁴ − T_c⁴)
```

| 类型 | 判据 | 反馈性质 | 后果 |
|---|---|---|---|
| **正微分发射率（PDTE）** | dε/dT > 0 | **负反馈** | T↑ → ε↑ → 散热增强 → 抑制升温 ⇒ **自动回稳** |
| **负微分发射率（NDTE）** | dε/dT < 0 | **正反馈** | T↑ → ε↓ → 散热变差 → 继续升温 ⇒ **辐射热失控（radiative thermal runaway）** |

> ⚠️ 文中特别指出这个反直觉点（ref 106, Bierman et al., *Phys. Rev. Applied* 2018；见 §2.2.3 详解）：NDTE 既是风险，也被用作器件设计自由度。

## 1.5 评价指标与公式汇总

原文将公式散布在第 2–4 章，这里集中整理，便于设计时直接取用。

**(a) 核心性能指标**

| 指标 | 含义 | 典型判据 |
|---|---|---|
| **ε(T)** | 温度依赖发射率 | — |
| **Δε = ε_hot − ε_cold** | 发射率调制幅度 | 单 PCM 本征 0.2–0.5；结构增强 0.5–0.8 |
| **α_sol** | 太阳光谱吸收率 | 越低越好；VO₂ 体系常见 ≈0.5，最优做到 0.22 |
| **T_lum** | 可见光透过率 | 智能窗需 > 50% |
| **ΔT_sol** | 太阳调制效率 | 智能窗需 > 10%，先进微结构已 > 25% |
| **迟滞宽度** | 升温支与降温支的温差 | 影响控制精度 |
| **循环寿命** | 失效前循环次数 | 当前最大短板 |

**(b) 光学量定义**

发光 / 太阳透过率（式 4）与太阳调制效率（式 5）：

```
T_lum/sol = ∫φ_lum/sol(λ)·T(λ)dλ / ∫φ_lum/sol(λ)dλ        (4)
ΔT_sol    = T_sol(T < T_MIT) − T_sol(T > T_MIT)             (5)
```

其中 φ_lum(λ) 为标准光视效率函数，φ_sol(λ) 为太阳辐照谱。**T_lum 与 ΔT_sol 需平衡**——主流解法是**多层优化、微结构、纳米复合** [50, 90–92]。

Wien 位移定律（式 6）——决定红外成像与伪装的工作窗口：

```
λ_m · T = b = 2897.756 μm·K                                (6)
```

人体 T ≈ 310 K ⇒ λ_m ≈ **9.4 μm**，正落在大气窗口内。

发射率（式 7，Planck + Kirchhoff）与太阳吸收率（式 8）：

```
ε     = ∫[1−R(λ)−T(λ)]·E(λ,T)dλ / ∫E(λ,T)dλ                (7)
α_sol = ∫[1−R(λ)]·I_s(λ)dλ / ∫I_s(λ)dλ                     (8)
```

**(c) 结构共振条件**（详见 §3.2.1）

```
F–P 腔共振：   2·n·d·cosθ = m·λ_res        (m = 1, 2, 3, …)
相对线宽：     Δλ/λ_res ≈ 1/(F·m)，  F = π√R /(1−R)
角度色散：     λ_res(θ) = λ_res(0)·cosθ
```

**(d) 有效介质近似**（描述相变中间态的必备工具）

```
ε_eff(T) = EMA[ ε_metal, ε_insulator, f_metal(T) ]          (Bruggeman / Maxwell-Garnett)
f_metal(T) / f_insulator(T) ∝ exp(−ΔE / k_B T)              (Boltzmann 分布)
```

**(e) 光–热关系**

依据 Kirchhoff 定律 A + R + T = 1 且 ε(T) = A(T)，**"吸收调制"在某种意义上就是"发射率调制"**【2.2.2 (C)】。

# 第 2 章 三大核心相变材料

## 2.1 AMnO₃ 钙钛矿锰氧化物

### 2.1.1 结构与 MIT 原理

- **化学式**：AMnO₃；A 位为**二价碱金属或稀土元素**（La、Ca、Ba 等）[52]
- **理想 AMnO₃**：绝缘态，反铁磁
- **掺杂触发共存**：A 位被二价碱金属部分取代后成为 **A₁₋ₓBₓMnO₃**，Mn³⁺ 与 Mn⁴⁺ 可**共存**，磁性与电阻率随之改变（Fig. 4a–c）
  - 理论基础可追溯到 **Zener 双交换作用**（C. Zener, *Phys. Rev.* 1951, ref 23）
- **MIT 过程机理**：目前主流用**逾渗理论（percolation theory）**解释 [53–56]
  - 材料的电磁性质变化是多种机制共同作用的结果
  - 基于**金属相与绝缘相体积分数的 Boltzmann 分布**的温度模拟，与实测动态发射率趋势一致
- **发射率行为**：MIT 过程中 A₁₋ₓBₓMnO₃ 的发射率**随温度升高而增大**（正微分）——正是航天器热控所需的方向：高温高发射率散热、低温低发射率保温。

### 2.1.2 深度解析 A：Jahn–Teller 效应与 MnO₆ 八面体畸变

原文只写了一句"MnO₆ 八面体畸变（Jahn–Teller 效应）"，但**这是理解整个 AMnO₃ 体系发射率增强的物理起点**，值得拆开讲。

**(1) Jahn–Teller 定理本身**

> 任何**非线性**分子 / 离子，如果其电子基态是**轨道简并**的，则该构型不稳定，必然发生几何畸变以消除简并、降低总能量。

关键词是"**轨道简并**"：当电子可以在两个能量相同的轨道间"任选一个"时，系统会主动扭曲自己，让其中一个轨道能量降下来——代价是另一个升上去，但电子占据低的那个，净收益为正。

**(2) 为什么 Mn³⁺ 会发生、Mn⁴⁺ 不会**

在 MnO₆ 八面体晶体场中，Mn 的 3d 轨道劈裂为两组：

```
        eg  ├── d(x²−y²)   ── 高能，指向配位 O
            └── dz²
        ───────────────────  Δ_oct ≈ 1.5–2 eV
        t2g ├── dxy  dxz  dyz  ── 低能，指向配位 O 之间
```

| 离子 | d 电子组态（高自旋） | eg 占据 | 是否 JT 活性 |
|------|---------------------|---------|-------------|
| **Mn³⁺** | (t2g)³(eg)¹ | eg **半满 1 个电子** | ✅ **是**——这个 eg 电子可在 d(x²−y²) 与 dz² 间二选一 ⇒ 轨道简并 ⇒ JT 不稳定 |
| **Mn⁴⁺** | (t2g)³(eg)⁰ | **空** | ❌ **否**——eg 全空，无简并可言 |
| Mn²⁺ | (t2g)³(eg)² | 全满 | ❌ 否 |

**这个对比极其重要**，因为它直接决定"掺杂 → 发射率"的因果链：A 位二价掺杂把部分 Mn³⁺ 氧化成 Mn⁴⁺，**减少** JT 活性离子数目；但与此同时，掺杂引起的 A 位离子半径失配又**引入**化学压力，产生另一套晶格畸变（见下文 (5)）。**两股力量方向相反**——这正是"掺杂量–发射率"曲线存在最优值的根源。

**(3) 畸变的具体形式：两种简正模式**

| 模式 | 对称性 | 几何表现 | 后果 |
|------|--------|---------|------|
| **Q₃ 模式**（四角畸变） | 呼吸型 | 沿 z 轴**拉长**（2 长 + 4 短）或**压缩**（4 长 + 2 短） | 使 dz² 与 d(x²−y²) 能量分裂；拉伸时 dz² 下降、d(x²−y²) 上升 → 电子占据 dz² |
| **Q₂ 模式**（正交畸变） | 面内非对称 | 面内 x、y 方向不再等价 | 导致 d(x²−y²) 面内进一步分裂；与 Q₃ 耦合形成**轨道有序** |

**(4) 定量：LaMnO₃ 实际长什么样**

JT 畸变并非微量修正，而是**量级巨大的结构畸变**：

| 量 | 数值 | 说明 |
|---|------|------|
| **Mn–O 键长（实测，3 种）** | **0.218 / 0.196 / 0.191 nm** | 长 / 中 / 短——**每个八面体都是"2 长 + 2 中 + 2 短"** |
| 理论计算（SIC-LSD） | 面内 **1.90 Å 与 2.18 Å**（对比假设立方相 1.96 Å） | 面内长短差达 **0.28 Å** |
| 晶格常数 | ≈ 0.55 / 0.57 / 0.78 nm（O′ 型正交，空间群 *Pbnm*） | 正交畸变显著 |
| Mn–O–Mn 键角 | **≈ 155°**（理想 180°） | 八面体**倾转 / 扭转**（GdFeO₃ 型倾转），与 JT 畸变叠加 |
| 氧位对称性 | **2 种不等价氧**：面内 O_IP（一长一短）、面外 O_OP（两个中等键） | 直接影响红外声子谱 |
| 轨道有序化 | **C 型**：两根相对的 Mn–O 长键在两个正交方向间交替 | 即 d(3x²−r²) 与 d(3y²−r²) 交替排列 |
| 轨道有序–无序转变 | **> 750 K** 塌缩为**赝立方相**；但局域探针显示畸变并未消失，只是**取向随机化** | 即"动态 JT"而非"JT 消失"——对高温服役至关重要 |

> **重要含义**："2 长 + 2 中 + 2 短"这种键长交替 = **周期性的电荷分布不对称**。正负电荷中心不再重合 ⇒ 每个八面体都成为一个**局域电偶极子**的载体，可直接与入射红外电磁场耦合（极性光学声子）。**这就是"晶格畸变 → 长波发射率增强"的物理桥梁。**

**(5) 掺杂引入的第二套畸变：化学压力与失配**

A 位掺杂 A₁₋ₓBₓMnO₃ 时，若 B 离子半径与 A 不同（如 La³⁺ 1.36 Å vs Sr²⁺ 1.44 Å vs Ca²⁺ 1.34 Å，均为 12 配位），会造成：

- **A 位尺寸失配（size mismatch）** → 八面体倾转角变化 → Mn–O–Mn 键角偏离 → 改变轨道重叠积分
- **平均 A 位半径变化** → 化学压力 → 键长整体伸缩
- **电荷补偿需求** → 产生氧空位或阳离子空位 → 进一步降低对称性
- **Mn³⁺/Mn⁴⁺ 比例变化** → 改变 JT 活性离子浓度与双交换强度

**(6) 从结构畸变到红外发射率：完整因果链**

```
A 位二价掺杂
   ↓
Mn³⁺ ⇄ Mn⁴⁺ 共存 + 化学压力 + 缺陷
   ↓
① JT 畸变（Q₂/Q₃）→ "2长2中2短" → 局域偶极矩
② 八面体倾转 → Mn–O–Mn 键角 ≈155° → 键角/键长双重不对称
③ 轨道有序（C 型）→ 周期性电荷不对称
   ↓
晶格对称性破缺 → 正负电荷中心不重合 → 极化率 α_p 提升
   ↓
极性光学声子（TO 模）强度增强 + 局域态密度提高
   ↓
长波（远红外）热辐射效率提升 → 发射率 ε ↑
```

**顺带解释"为什么是长波而非短波"**：红外光子能量（~0.1 eV @ 10 μm）远小于电子带间跃迁能（~1–2 eV），因此长波吸收 / 发射的主要通道是**声子**——而声子吸收强度正比于晶格振动过程中的**动态偶极矩变化（∂μ/∂Q）**。JT 畸变把静态偶极矩做大了，等价于把 ∂μ/∂Q 放大，声子通道自然变强。**短波通道则靠另一条路**：杂质带 / 带隙窄化引入新的电子跃迁通道（见 §2.1.4 机制 2）。

### 2.1.3 深度解析 B：双交换（Zener）、逾渗与小极化子

原文只给了文献编号 [23]，未展开。

**(1) 双交换（Double Exchange, DE）——C. Zener 1951**

```
Mn³⁺ — O²⁻ — Mn⁴⁺
(d⁴, eg¹)      (d³, eg⁰)
```

- 中间的 O²⁻ 通过 2p 轨道与两侧 Mn 的 eg 轨道杂化
- eg¹ 电子可以**跳跃**到邻近 Mn⁴⁺ 的 eg 空位上
- 关键：**跳跃过程中电子自旋不发生翻转**（强 Hund 耦合，J_H ≈ 1–2 eV ≫ 跳跃积分 t）
- ⇒ **电子可实现跳跃的前提是两侧 Mn 的芯自旋同向排列** ⇒ 跳跃本身**产生并稳定了铁磁耦合**
- ⇒ **金属性与铁磁性同时出现**；载流子（eg 电子）浓度越高，DE 越强、居里温度 T_C 越高

**对发射率的意义**：DE 是"绝缘态 → 金属态"的电子通道。掺杂量 x 增大 → Mn⁴⁺ 增多 → eg 载流子增多 → DE 增强 → 体系更倾向金属态 → MIT 温度与电磁性质被调制。

**(2) 逾渗理论（Percolation）——原文解释 MIT 的核心框架 [53–56]**

原文表述为"基于金属相与绝缘相体积分数的 Boltzmann 分布模拟，与实测动态发射率趋势一致"。其物理图像是**电子相分离（electronic phase separation）**：

- 锰氧化物在 MIT 附近**不是均匀转变**，而是形成**金属畴 + 绝缘畴共存**的两相混合物
- 两相体积分数随温度按 **Boltzmann 分布**变化：
  ```
  f_metal(T) / f_insulator(T) ∝ exp(−ΔE / k_B T)
  ```
- **逾渗阈值**：当金属相体积分数超过临界值（3D 连续介质体系约 **0.16–0.30**，取决于几何与连通性），金属畴突然连通成贯穿通道 → 宏观电阻率断崖式下跌、红外反射 / 吸收特性突变
- **对发射率的直接后果**：有效介电常数可用**有效介质近似（EMA / Bruggeman）**写成两相混合：
  ```
  ε_eff(T) = EMA[ ε_metal, ε_insulator, f_metal(T) ]
  ```
  ⇒ ε(T) 随 f_metal(T) 连续演化，但变化最剧烈的区间落在**逾渗阈值附近**

> **为什么这个框架值得记住**：它提供了一个**可计算的温度–发射率模型**（只需 ΔE + 阈值 + 两相介电常数），非常适合作为 AI for science 的物理先验（见附录 B 方向 B）。

**(3) 小极化子（Small Polaron）——Xu 等 [171] 的机制**

- 晶格中的一个**空穴（或电子）+ 其周围自陷的晶格畸变**，作为一个准粒子整体运动
- 形成条件：电子–声子耦合足够强，使载流子自陷（self-trapping）的能量降低大于动能增益
- 在锰氧化物中，Mn⁴⁺ 处的空穴会拉近周围 O，形成局域畸变，**空穴 + 畸变**共同构成小极化子
- **对发射率的意义**：小极化子的**跳跃导电（hopping）**在红外区有强烈的吸收 / 发射贡献；且小极化子本身就是"局域偶极矩的载体"，改变材料的**极化率**。Xu 等观测到：高温下 Mn³⁺ → Mn⁴⁺ 部分氧化 → 晶格畸变 → 空穴与其周围畸变共存（即小极化子）→ 发射显著增强（Fig. 10d）

**(4) 氧空位与局域声子模的补充作用**

| 机制 | 物理过程 | 后果 |
|------|---------|------|
| **氧空位散射声子** | 点缺陷破坏声子周期性 → 声子平均自由程 ↓ | **热导率降低** → 热局域化 → 表面更易升温 → 辐射更强 |
| **局域声子模耦合** | 掺杂 / 缺陷引入的局域振动模与晶格主声子谱耦合 | **红外发射带展宽** → 覆盖更宽的波长范围 |
| **高价掺杂 → 自由载流子** | W⁶⁺ / Nb⁵⁺ 等高价离子提供额外电子 | 自由电子浓度 ↑ → 等离子体共振（Drude 项）增强 |
| **低价掺杂 → 空穴导电** | 低价离子引入空穴 | 通过空穴导电机制改变载流子迁移率 |

**(5) 短 / 长波分工的普适规律**（§4.2 开篇）

- **短波区**：热辐射主要来自**能级间电子跃迁**（价带–导带带间跃迁、杂质能级激发）
- **长波区**：热辐射主要受**晶格声子非谐振动**支配，与声子态密度和极化性质密切相关

### 2.1.4 掺杂效应

| 掺杂类型 | 代表体系 | 效果 | 文献 |
|---------|---------|------|------|
| A 位二价（Sr/Ca） | La₁₋ₓBₓMnO₃ (B = Sr, Ca, x = 0.1–0.5) | Δε 从 0.693→0.818（20→55 °C，8–14 μm） | Shen [57] |
| A 位共掺 | La₀.₆₇Ca₀.₃₃₋ₓSrₓMnO₃ | MIT 温度可通过掺杂量在 **0–10 °C** 区间调控，Δε > 0.45 | Sun [58] |
| K 掺杂 | La₀.₇Ca₀.₃₋ₓKₓMnO₃ (LCKMO, x = 0.05–0.20) | **提高**发射率与相变温度，Δε ≈ 0.4；航天热控优势 | Chen [186] |
| 稀土镍酸盐 | SmNiO₃（超材料） | Δε ≈ 0.6，工作区间 0/140 °C | Khalichi [51] |
| 钙钛矿铁氧体 | **Sc 掺杂 LaFeO₃** | 晶格畸变使带隙与晶格振动耦合增强；Δε = 0.35（3–5 μm，25→270 °C） | Chen [61] |
| 复相陶瓷 | La₂(Zr₀.₇Ce₀.₃)₂O₇ / LaMnO₃ | Δε ≈ 0.21；高温下 Mn³⁺ 部分氧化为 Mn⁴⁺ → 晶格畸变 | Xu [171] |

**掺杂增强发射率的五条微观机制**（§4.2 核心内容，Fig. 10a/d）——这是全文对 AMnO₃ 讲得最透的部分：

1. **晶格对称性破缺 → 局域偶极矩**
   掺杂改变晶体结构，使 MnO₆ 八面体发生 **Jahn–Teller 畸变**或晶格形变 → 对称性下降 → 破坏原有电中性平衡 → 诱导局域偶极矩。晶体缺陷与杂质缺陷进一步加剧晶格不对称 → **极化率提升**。这些偶极矩的动态变化可与电磁场耦合，**显著提高长波热辐射效率**。（物理细节见 §2.1.2）
2. **电子结构改变 → 短波辐射增强**
   掺杂引入**中间能级或杂质带**，缩小原带隙宽度 → 拓宽电子跃迁通道 → 增强短波热辐射。
   - **高价掺杂**：提高自由电子浓度，增强**等离子体共振**
   - **低价掺杂**：通过空穴导电机制影响载流子迁移率
3. **晶格振动–缺陷耦合 → 展宽红外发射带**
   掺杂诱导的**局域声子模**与晶格主声子谱耦合，展宽红外发射带；氧空位等缺陷**散射声子**、降低热导率，通过**热局域化**增强性能。
4. **小极化子路径**
   Xu 等 [171] 系统评估 La₂(Zr₀.₇Ce₀.₃)₂O₇/LaMnO₃ 的晶体结构–发射率关系：增强源于第二相 LaMnO₃ 的高吸收率；高温下部分 Mn³⁺ 氧化为 Mn⁴⁺ 导致晶格畸变，**空穴与其周围晶格畸变共存（即小极化子）**改变极化率，从而显著增强发射。
5. **Mn–O 八面体畸变的定量化**
   Yang 等 [187] 专门研究掺杂诱导的 MnO₆ 畸变对 LaMnO₃ 基材料相变温度与发射率的影响（*J. Eur. Ceram. Soc.* 2025）。

### 2.1.6 经典结构设计

**(a) 遗传算法（GA）优化的光谱选择性多层膜** — Shimazaki 等 [59]

- 体系：基于 La₀.₈₂₅Sr₀.₁₇₅MnO₃ 的多层膜，用 GA 优化
- 效果：**Δε = 0.42 同时 α_sol = 0.28**（低太阳吸收）
- 机理：膜层具备光谱选择性——**反射太阳辐射，同时让远红外穿过**

**(b) La₀.₈₂₅Sr₀.₁₇₅MnO₃ / BaF₂ 叠加多层膜** — Wang 等 [60]（*Appl. Therm. Eng.* 2024）

- 设计逻辑：通过结构设计**破坏膜间干涉效应**以抑制 Fresnel 反射；同时合理设计介质层厚度，**避免相变时 F–P 腔共振引起的高发射**
- 效果：**Δε = 0.65**，且**同时抑制 α_sol 的增长**，对入射角与偏振不敏感（Fig. 4e）
- 意义：AMnO₃ 体系里"高 Δε + 低 α + 角度不敏感"三者兼顾的标杆工作

**(c) 柔性钙钛矿光子堆栈** — Zhao 等 [178]（*Mater. Des.* 2022）

- 体系：La₀.₇Ca₀.₃₋ₓKₓMnO₃，固相反应 + 磁控溅射
- 效果：多层结构 Δε = 0.47，用于自适应红外伪装；服役温度 800 / 900 / 1000 °C

## 2.2 二氧化钒 VO₂

> 本节是全文与本人研究重合度最高的部分，含三个深度解析（§2.2.2–2.2.4）与一份钨掺杂要点（§2.2.7）。

### 2.2.1 结构与 MIT 原理

- **T_MIT ≈ 68 °C**（远高于室温 → 这也是它最大的应用障碍）
- 升温时绝缘体 → 金属态，同时**晶体结构与能带对应改变**（Fig. 5a）
- **多晶型**：VO₂(R)、VO₂(M)、VO₂(A) 等 [74, 75]；微观结构变化导致宏观光电性质变化
  - 注：单斜 VO₂ 的光致金属相已由超快电子衍射直接观测（Morrison et al., *Science* 2014, ref 96）
- **电学**：相变后载流子浓度显著增加、电阻率急剧降低 → 金属行为
- **光学**：绝缘态 VO₂ 红外**高透射**；金属态**高反射**
- **迟滞（hysteresis）**：相变可逆并伴随迟滞，迟滞宽度与**晶体形貌和取向**相关
- 与其他 PCM 突出的差别：**VO₂ 在不同波段的热辐射特性差异显著**（可在 Vis-NIR / Mid-IR / FIR / THz 分段利用）

### 2.2.2 深度解析 A：M1/R 结构相变与 Peierls–Mott 之争

原文只说"晶体结构与能带对应改变"，而**"到底是 Peierls 还是 Mott 主导"直接决定掺杂该怎么设计**。

**(1) 两个端点的晶体结构**

| 相 | 温度 | 空间群 | 结构特征 | 电子态 |
|---|------|--------|---------|--------|
| **M1（单斜，绝缘）** | < 68 °C | *P2₁/c* | V 沿 c 轴形成 **V–V 二聚体（dimer）**，V–V 间距交替 **2.65 Å / 3.12 Å**；V 偏离八面体中心 → V–O 键长不等 | 带隙 **≈ 0.68–0.7 eV**，红外透明 |
| **R（金红石，金属）** | > 68 °C | *P4₂/mnm* | V–V 等距 **2.87 Å**，无二聚化 | 零带隙，自由载流子，红外高反射 |

> 附注：VO₂ 还存在 **M2 相**（*C2/m*，掺 Cr/Al 或受应力时出现）、**T 相**、**VO₂(A)**、**VO₂(B)** 等，性质差异很大（VO₂(B) 是亚稳相，用于电池 / 柔性探测器）。

**(2) 两种解释路径**

| 理论 | 驱动因素 | 物理图像 | 支持证据 |
|------|---------|---------|---------|
| **Peierls（晶格驱动）** | 电子–晶格耦合 | V–V 二聚化 → 3d‖ 轨道形成成键 / 反键分子轨道 → 劈裂出 0.7 eV 带隙。**结构变化是因，带隙是果** | 超快电子衍射观测到光致金属相（Morrison, *Science* 2014 [96]）；V–V 二聚化缺失实验 |
| **Mott（电子关联驱动）** | 电子–电子库仑关联 U | 即使不发生结构畸变，当 U/W 超过临界值时体系也会变为绝缘体（Mott–Hubbard）。**电子关联是因，结构变化是果** | Zylbersztejn & Mott 1975 [22]；声子熵驱动金属化（Budai, *Nature* 2014 [73]） |

**目前的共识**：**两者协同作用，只是随温度 / 压力 / 时间尺度不同而权重不同**。超快实验表明：光激发后 **~100 fs** 内先出现电子态变化（Mott 特征），**~1 ps** 后才出现晶格响应（Peierls 特征）——即**电子响应先行**。这也是 GST 那一节"随波长切换主导机制"论述的物理基础。

**(3) 为什么这一点决定掺杂设计**

- 若**电子通道**主导 → 掺杂应重在**调节载流子浓度**（W⁶⁺/Nb⁵⁺ 施主掺杂直接往 t2g 带注入电子）
- 若**晶格通道**主导 → 掺杂应重在**引入应力 / 畸变**（大离子半径取代、间隙位掺杂、薄膜–衬底失配应变）
- **W 掺杂同时作用在两个通道上**——这正是它效率最高（20–26 °C/at%）的原因。定量数据见 §2.2.7 与**附录 A**。

### 2.2.3 深度解析 B：负微分发射率（NDTE）与辐射热失控

这是 VO₂ 最反直觉、也最有工程价值的特性，原文只用一段带过。

**(1) 正 / 负微分发射率的物理来源**

```
C·dT/dt = E_gain − ε(T)·σ·(T⁴ − T_c⁴)
```

- **正微分（PDTE, dε/dT > 0）——负反馈，自稳定**
  T 升高 → ε 升高 → 辐射散热增强 → 抑制升温 ⇒ **系统自动回稳**
  典型来源：VO₂ 在基底（如 Al、Au）上时，金属态 VO₂ 的反射被基底调制，整体表现为 ε 随 T 升
- **负微分（NDTE, dε/dT < 0）——正反馈，可能失控**
  T 升高 → ε **降低** → 散热变差 → 温度进一步升高 ⇒ **辐射热失控**
  典型来源（Kats 等, *Phys. Rev. X* 2013 [109]）：VO₂ 本身在金属态时**红外反射率极高**（ε 小）。若基底对红外透明或无强反射，则 VO₂ 一旦转为金属态，整体 ε 骤降 ⇒ NDTE。

**(2) 一个关键的实验现象**

Kats 等观测到：~150 nm VO₂ 蓝宝石薄膜在 **85 °C** 时，热像仪中呈现**"变冷"**的假象。原因不是降温，而是 **ε 降低导致热像仪接收到的辐射功率下降**。这既是红外隐身的原理（高温时反而"看不见"），也是热管理设计的陷阱。

**(3) 工程上如何利用 / 规避**

| 目的 | 策略 |
|------|------|
| **要 PDTE**（散热自稳、航天热控） | 引入**高红外反射基底**（Al / Ag / Au）；构建 F–P 腔使金属态 VO₂ 参与共振吸收；微结构工程设计腔长 |
| **要 NDTE**（自适应红外伪装、智能辐射开关） | 让 VO₂ 直接作为辐射面；或用**核壳结构**（VO₂@Al-O，Wu [102]）兼顾抗氧化 |
| **正负双向切换**（可重构器件） | 把 F–P 腔与微结构**复合**——Gu 等 [99] 实现 8–14 μm 内 **ε 从 +0.61 翻转到 −0.53** |

### 2.2.4 深度解析 C：V⁴⁺ → V⁵⁺ 氧化失效链

原文只说"生成惰性 V₂O₅"。补全失效路径——**这是制约 VO₂ 实用化的头号问题，也是防护层设计的依据**。

```
VO₂（V⁴⁺）
  │  ① 潮湿空气 + 氧：表面吸附 H₂O/O₂
  ↓
  │  ② V⁴⁺ → V⁵⁺ 氧化（钒的多价性使这一步热力学有利）
  ↓
V₂O₅（V⁵⁺，d⁰ 组态，无 d 电子）
  │  ③ V₂O₅ 是宽禁带绝缘体，无 MIT、红外透明
  ↓
热致变色性能逐步退化 → Δε 衰减 → 器件失效
```

**并行的第二条失效路径（机械失效）**：

```
MIT 每循环一次 → 单斜 ↔ 金红石晶胞体积变化 ~0.3–1%
  ↓
薄膜内累积应变 → 微裂纹萌生与扩展
  ↓
裂纹成为氧化通道 → 加速化学失效（与上面第 ② 步耦合）
```

**对策与各自代价**：

| 策略 | 做法 | 代价 |
|------|------|------|
| **核壳包覆** | ALD 生长 Al-O、SiO₂、CeO₂ 壳层 [102, 175] | 壳层影响整体光学性能；需匹配折射率 |
| **多层膜封装** | Cr₂O₃/VO₂/SiO₂ 中 SiO₂ 顶层兼具减反 + 稳定性 + 自清洁 [94] | 增加层数与工艺复杂度 |
| **合金化 / 共掺杂** | W + F、W + Mo 共掺，或掺 Ti/Zr 稳定 | 可能牺牲 Tc 调控效率 |
| **纳米复合** | VO₂ 纳米颗粒弥散于 V₂O₅/V₃O₇ 基体（基体抑制裂纹扩展）[95] | 需精确控制相组成 |
| **缺陷工程** | 可控缺陷实现低温相变同时保持红外调制 [241] | 缺陷同时影响相变对比度 |
| **准梯度掺杂** | 多层不同 W 掺杂浓度堆叠，**拓宽 MIT 温度窗口 + 降低迟滞**（*ACS Nano* 2025） | 转移 / 堆叠工艺难度 |

### 2.2.5 分段应用与关键性能参数

**(A) Vis-NIR（0.25–2.5 μm）——智能窗**

两个必须满足的参数（通常要求 T_lum > 50%、ΔT_sol > 10% [88]），定义见 §1.5 式 (4)(5)。**T_lum 与 ΔT_sol 需平衡**——主流解法是**多层优化、微结构、纳米复合** [50, 90–92]。

**(B) Mid-IR（2.5–25 μm）——红外成像 / 自适应伪装**

依据 Wien 位移定律（式 6）：人体 T ≈ 310 K → λ_m ≈ **9.4 μm**，落在大气窗口内。发射率与太阳吸收率由式 (7)(8) 给出。

**(C) FIR（> 30 μm）与 THz——吸收调制**

依据 Kirchhoff 定律 A + R + T = 1，且 ε(T) = A(T)——**"吸收调制"在某种意义上就是"发射率调制"**。

### 2.2.6 正 / 负微分发射率的双路径

文中特别强调 VO₂ 基复合材料存在**两种完全相反**的动态热辐射行为 [106–109]（物理机制见 §2.2.3）：

| 类型 | 定义 | 代表工作 |
|------|------|---------|
| **正微分（PDTE）** | ε 随 T 升高而增大 | Benkahoul [110]、Saini [112]、Audhkhasi [113] |
| **负微分（NDTE）** | ε 随 T 升高而减小 | Xiao [114]、Wu [102]、Chandra [115]、Gu [99] |

- Benkahoul 等 [110] 最早发现：VO₂ 沉积在 **Al / 石英 / Si** 衬底上时晶体结构由单斜变为四方；由于 **Al 的红外反射性能更好**，表现为正微分热行为但 **Δε 低**
- **F–P 腔与微结构是增强 Δε 的有效手段** [78, 111]

#### ⭐ 钨（W）掺杂要点（完整数据汇编见**附录 A**）

原文只给了"W 可降 T_MIT"的定性描述。补上定量数据后，"W 掺杂"这件事的面貌会完全不同。

**要点一：W 的降 Tc 效率不是材料常数，而是强工艺依赖量——跨工艺差 14 倍。**

| 工艺路线 | 材料形态 | ΔTc (°C/at% W) | 备注 |
|---------|---------|----------------|------|
| **W 离子注入** | 薄膜 | **74.2** ⚡最高 | DPA = 4.46，结构损伤严重 |
| 表面热氧化 | 微米单晶棒 | **52** | 线性，0–0.6 at% |
| WxV₁₋ₓO₂ 纳米线 | 纳米线 | 48–56 | |
| **PLD** | 薄膜 | **26** | 1.7 at% → Tc = 26 °C，T_lum = 62% |
| 单晶纳米束 | 单晶 | 20–28 | |
| 掠角共沉积 + RTA | 薄膜 | ~20 | x = 0.97 → Tc 降 44 °C |
| **水热法** | 粉体 | **5.2** ⚡最低 | 名义 18 at% 仅实得 5.5 at%（EDS） |

**⇒ 综述与多数文献引用的"20–26 °C/at%"只是薄膜路线的典型值，不能外推到水热 / 离子注入体系。**

**要点二：W 是"降 Tc 最强、但伤 Δε 也最明显"的掺杂剂。**

| 维度 | W 掺杂的作用 | 定量 |
|------|------------|------|
| **降 Tc** | 效率最高 → 约 **2 at% 即到室温** | 20–26 °C/at%（典型） |
| **Δε（红外发射率调制）** | **普遍降低** | 未掺杂 Δε = 0.6 → **1 at% W 后 Δε = 0.4** |
| **ΔT_sol（太阳调制）** | **降低**；> 2–3 at% 时相变变宽、协同性下降 | — |
| **T_lum（可见透过）** | **降低** | 需靠共掺杂或减反层补偿 |
| **迟滞宽度** | **降低**（缺陷位点增多） | — |
| **辐射散热能力** | 相变温度下移使散热窗口前移 | 1 at% W：辐射热流 175→493 W/m²（30→55 °C）；散热增强 **3.5×** |
| **超量掺杂** | ⚠️ 0.16 ≤ x ≤ 0.2 重掺杂区出现 **Tc 异常升高** | Tc(x) 非全域单调 |

**要点三：结构设计能把 Δε 补回来，甚至反超。** 破解路径是"W 负责降 Tc，结构（F–P 腔 / 超表面）负责把 Δε 补回来"：

| 补偿方案 | 结果 |
|---------|------|
| **W-VO₂ / HfO₂ / Al** F–P 腔（HiPIMS） | **Tc = 27.5 °C 且 Δε = 0.51–0.61**（同时达成），**已上实际航天任务** |
| **Al / HfO₂(800) / WxV₁₋ₓO₂(65)** DRTM | **ε: 0.25 @0 °C → 0.87 @70 °C**（7–13 μm）；α_sol ≈ 0.5 |
| **W:VO₂ 超表面** meta-OSR | α 降至 **0.22**，ε_hot = 0.8，**Δε = 0.33**，Tc = 30 °C，10×10 cm² 航天级验证 |
| W-VO₂ 多层膜（专利 CN122105312A，上海交大） | Tc 可调 **15–68 °C**，**Δε = 0.5–0.7**（2–25 μm），可见反射率 0.55–0.65 |

> 💡 **CN122105312A 与本组工作直接对口**：它与所读综述同属上海交大，结构为 `Al 基底 / 无机介质层（干涉腔）/ W-VO₂ 功能层 / 防护层`，把"**W 掺杂比例 + 各层厚度**"当作两个独立设计自由度。这提示在多目标逆设计中，**掺杂浓度应作为变量而非固定参数**。

**要点四：W 掺杂的微观机理（两通道）**

- **电荷补偿路径**：W⁶⁺ 取代 V⁴⁺ → d 层电子转移给邻近 V → 形成 **V³⁺–W⁶⁺ 对** → 沿单斜晶胞轴**削弱 V⁴⁺–V⁴⁺ 键** → 半导体相失稳 → Tc 降
- **结构路径**：大离子半径取代 / 间隙插入 → 压应变 + 畸变 → 诱导**类金红石结构** → 降低相变能垒
- **为什么 W 强于 Nb / Mo**：W 的**电负性最高** → 与 V-3d 杂化最强 → 最能有效贡献局域电子；而 Nb–O 离子性过强、4d 与 V-3d 杂化不良
- ⚠️ 网络流传的"电子 85% / 晶格 15%"源自不可靠来源，**不建议引用**

> ⚠️ **重要警告（文中原文逻辑）**：VO₂ 本身**不稳定**，掺杂会改变载流子浓度与带隙，**可能对 MIT 过程不利** [126–128]。这是 VO₂ 掺杂设计中的核心权衡。

### 2.2.10 局限与对策

- **T_MIT 高（~68 °C）**：多数自适性热管理器件内部电子元件工作温度远低于此
- **化学稳定性差**：潮湿空气中 V⁴⁺ → V⁵⁺ 氧化，生成惰性 V₂O₅，热致变色性能逐渐退化（失效链见 §2.2.4）
- 外部激励（电压、应力）可有效诱导相变，但**增加系统设计复杂度** [124, 125]
- 保护层可避免外部环境导致的变性，但**会影响整体光学性能**
- 还需考虑温度变化下的**热膨胀系数与热扩散行为**差异 [129–131]
- 对策方向：缺陷工程实现低温相变并保持红外调制能力（Wu et al., *Opt. Mater.* 2026, ref 241）

## 2.3 锗锑碲 GST（Ge₂Sb₂Te₅）

### 2.3.1 三态结构与相变原理

GST 因**可逆、可重复**的相变特性受关注，最常用组分为 **Ge₂Sb₂Te₅** [26, 132, 133]。存在**三种结构状态**：

| 状态 | 温度条件 | 晶体结构 | 特征 |
|------|---------|---------|------|
| **非晶态（aGST）** | 低温 | 非晶 | 介电光学性质：**低折射率、近零损耗** |
| **亚稳态（substable）** | **T_MIT ≈ 150 °C** | 面心立方（FCC），类岩盐结构 [134, 135] | 光学性质开始变化 |
| **稳定态（stable）** | **≈ 200 °C** | 六方结构 [136, 137] | 相态**长期保持**，除非特殊处理（T > 640 °C、激光辐照）[138] |

相变后：**cGST 呈现大折射率与光学损耗**（与 aGST 相反）。

**两个主流相变机理**：

| 机理 | 别名 | 物理来源 | 文献 |
|------|------|---------|------|
| **晶格畸变** | **Peierls 相变机制** | 结构重排 | Jones [139] |
| **电子关联** | **Mott 相变机制** | 强电子–电子关联 | Otjacques [140] |

**★ 波长依赖的机制竞争（本文一个很有价值的论述）**

由于发射率表现出波长依赖的动态行为，必须厘清两种机制与光学波长的相互作用关系 [141, 142]：

| 波段 | 主导机制 | 物理原因 |
|------|---------|---------|
| **Vis-NIR** | **Peierls 相变更显著**（两机制共同调制） | 光子能量较高，利于带间电子激发；超快光激发下材料呈现快速原子–结构响应 |
| **Mid-IR** | **Mott 相变主导**，Peierls 贡献受抑制 | 晶格振动与自由载流子吸收变得重要 |
| **THz** | **Mott 相变明显主导** | 晶态 GST 呈金属性，大量自由载流子引起强吸收，改变宏观光学行为 |

**组分依赖**：GST 的**结晶温度随 GeTe 含量增加而升高**，同时光学常数在**宽波长范围**内变化（Fig. 9a），在 **Vis-IR 与 THz** 均表现普适的光谱调制特性 [19, 148, 149]。

### 2.3.2 深度解析 A：Peierls 与 Mott 到底差在哪

原文把两者并列列出，但没说清区别。这是凝聚态物理中一对容易混淆的概念，用一张表切开：

| 维度 | **Peierls 相变** | **Mott 相变** |
|------|-----------------|--------------|
| **驱动力** | 电子–**晶格**耦合 | 电子–**电子**库仑关联 |
| **因果关系** | **结构变化是因，带隙是果**：晶格畸变（Peierls 失稳）使原子位移、周期性改变，从而打开能隙 | **电子关联是因**：即使晶格不动，当库仑排斥 U 与带宽 W 之比 U/W 超过临界值，体系也必须是绝缘体 |
| **结构是否变化** | **必须**变化（键长 / 键角改变，对称性降低） | **可以不变**（"关联驱动"的 MIT 可无结构相变伴随） |
| **判据** | 一维金属对晶格畸变不稳定（Peierls 定理）：2k_F 处费米面嵌套 → 声子软化 → 周期畸变 | Hubbard 模型：U/W ≳ 1 时出现 Mott–Hubbard 能隙；可通过载流子掺杂（填充控制）或带宽调控（压力 / 应变）触发 |
| **在 GST 中的表现** | 亚稳 FCC ↔ 非晶之间的**结构重排**：Ge 原子从八面体位向四面体位迁移，sp³ 杂化恢复 → 带隙打开 | 晶态 GST 呈金属性时，**大量自由载流子强吸收**（THz / Mid-IR）——这是关联效应主导的光学表现 |
| **一句话记忆** | **"原子动，电子跟着分裂"** | **"电子之间打架，原子未必要动"** |

**为什么原文要花一段强调"波长决定主导机制"**：因为**不同波段的探针看到的物理过程不同**：

| 波段 | 光子能量 | 主要光学过程 | 主导机制 | 原因 |
|------|---------|-------------|---------|------|
| **Vis-NIR** | 1.5–4 eV | **带间跃迁**（interband） | **Peierls**（两机制共同作用，Peierls 更显著） | 光子能量高，直接激发价带→导带电子；超快光激发下原子结构响应快（~1 ps） |
| **Mid-IR** | 0.05–0.5 eV | **晶格振动（声子）+ 自由载流子吸收** | **Mott**（Peierls 被抑制） | 光子能量低于带隙，只能耦合声子与载流子；两者都是"关联 / 载流子"敏感通道 |
| **THz** | 1–10 meV | 自由载流子 **Drude 响应** | **Mott 明确主导** | 晶态 GST 呈金属性，自由载流子对 THz 强吸收，宏观光学行为几乎全由 Drude 项决定 |

> ⚠️ **引用提醒**：支撑这一段的文献是 [141]（Sun 等, *PNAS* 2011，压力诱导非晶化）与 [142]（Sun 等, *PRL* 2006，相变材料结构），**都不是直接针对"机制随波长切换"的实验证据**。这是一处综述性推断，转引前建议回溯原始文献。

### 2.3.3 深度解析 B：三态与"亚稳"为什么能长期保持

原文提到"亚稳态（FCC，150 °C）"与"稳定态（六方，200 °C）"，并说相态"长期保持，除非 T > 640 °C 或激光辐照"。其物理如下：

| 状态 | 结构 | 微观有序度 | 光学性质 | 稳定性来源 |
|------|------|-----------|---------|-----------|
| **非晶 aGST** | 无序网络，Ge 四面体配位为主（sp³） | 短程有序 | 低 n、近零 k（介电性） | 动力学势垒高，室温下几乎不弛豫 |
| **亚稳 cGST（FCC）** | 类岩盐结构，**Te 占阴离子位，Ge/Sb 随机占阳离子位，并有大量空位**（~25%） | 长程有序但**阳离子位无序** | 中等 n、中等 k | 空位稳定了 FCC 骨架；是**非易失存储的工作态** |
| **稳定 hGST（六方）** | 六方层状，**层内 Ge/Sb/Te 有序排布**（"层块"结构，类 Kooi 结构） | 长程 + 阳离子有序 + 层序 | 高 n、高 k | 热力学最稳定，需 > 200 °C 才形成；一旦形成难以逆转（除非 T > 640 °C 或激光熔融淬火） |

**核心矛盾的解释**：亚稳 FCC 之所以能长期保持，是因为**从 FCC → 六方需要阳离子扩散重排（长程输运），势垒远高于晶态 → 非晶的"局部键合切换"**。而**反复相变导致失效**则来自另一条路：非晶态与 FCC 态**密度差 ~5–6%**，每次循环都产生体积应变 → **元素偏析（Ge 富集 / 贫化）、空洞形成、界面粗化** → 累积性器件失效 [156]。

3. **难以将其他影响因素（光、电等）与热致相变结合**——若能耦合可大幅提升整体动态热性能
4. **循环耐久性有限**：反复相变导致**元素偏析、空洞形成、界面粗化** → 累积性器件失效 [156]
5. **非晶态热稳定性差**

**作者的三段式总结**：

- **钙钛矿锰氧化物**：空间环境稳定性强、相变温度可调 → **最适合航天器智能热管理**；但**高太阳吸收率**与**高温制备时的相不稳态**是紧迫问题。

| Chen [186] | 掺杂 | Δε ≈ 0.4 | 高温固相反应 | 航天器热系统 | La₀.₇Ca₀.₃₋ₓKₓMnO₃，90–100 °C |

> **评价范式的重要转变（文中原话）**：Δε 的数值**不再是衡量热辐射性能的唯一标准**，需转向**综合平衡（comprehensive equilibrium）**。

## 3.2 三种增强机理

| 范式 | 增强机理 | 固有局限 | 典型 Δε |
|------|---------|---------|---------|
| **掺杂** | 晶格畸变 → 对称性破缺 → 局域偶极矩 / 极化率↑（长波）；杂质带 / 带隙窄化（短波）；局域声子模耦合展宽发射带；氧空位散射声子降低热导（热局域化）；小极化子 | 掺杂改变载流子浓度与带隙，可能损害 MIT 本身 | 0.2–0.5 |
| **多层膜** | F–P 腔相干干涉 → 驻波场 → 局域态密度↑ → 特定共振波长发射率↑ | **带宽窄 + 角度敏感** | 0.4–0.8 |
| **超材料 / 超表面** | 亚波长共振单元阵列；局域等离激元共振（LSPR）、Mie 散射、非对称激发模式；电–磁共振协同耦合；共振波长由几何尺寸精确调谐 | **大面积制备困难**（需高精度纳米加工 + 异质集成） | 0.5–0.8 |

### 3.2.1 深度解析 A：F–P 腔为什么"窄带宽 + 角度敏感"

原文只给了结论，这里补上公式层面的原因——**因为这直接决定设计空间的边界**。

**(1) 共振条件与"局域态密度"**

MIM 三层结构（金属 / 介质 / 金属）相当于一个 F–P 谐振腔。光在腔内多次反射，满足：

```
2·n·d·cosθ = m·λ_res          (m = 1, 2, 3, …)
```

- n：介质层折射率；d：介质层厚度；θ：腔内传播角；λ_res：共振波长
- 满足条件时形成**驻波场**：腔内电场幅值被放大若干倍（典型 Q 因子 **10–100**）
- 物理等价说法：**局域光子态密度（local density of states, LDOS）在共振波长处被提升** → 该波长的吸收 / 发射率被增强（Purcell 效应在热辐射中的推广）

**这对 VO₂ 意味着什么**：VO₂ 从绝缘态变金属态时，其 n/k 在 Mid-IR 剧烈变化 → 腔的等效光程 n·d 变化 → **共振波长移动**（文中多个工作利用的正是"共振波长红移 / 蓝移"作为调制手段）。所以 F–P 腔对 VO₂ **特别有效**：**不是"吸收多少"变了，而是"共振峰在哪"变了。**

**(2) 为什么带宽窄**

单腔 F–P 的**相对线宽**满足：

```
Δλ / λ_res ≈ 1 / (F·m)          F = π√R / (1−R)
```

- R：腔壁反射率；F：精细度（finesse）
- R 越高（金属腔壁接近 1）→ F 越大 → **线宽越窄**
- 反过来：**想要宽带 ⇒ 必须牺牲 Q 值 ⇒ 牺牲增强倍数**
- 工程解法：**多腔堆叠**（文中 (BaF₂/VO₂)₃ 即三层腔叠加 [17]，多个共振峰拼接成宽带）、**多尺寸单元混排**（超表面）、**渐变 / 非对称结构**（准连续谱）

**(3) 为什么角度敏感**

看共振条件：**θ 一变，λ_res 就变**。定量地：

```
λ_res(θ) = λ_res(0)·cosθ
```

- θ = 60° 时 λ_res 缩小一半——对 Mid-IR 意味着共振峰整体移动数微米
- 对辐射制冷 / 航天热控是**致命问题**：航天器表面相对太阳、地球、深空的方向各不相同，角度敏感意味着"在不同方向上表现完全不同"
- 解法的物理本质是**阻抗匹配 / 等效介质**：让结构的等效折射率与自由空间匹配，使响应退化为"光学厚膜"行为（不依赖 θ）——这就是超表面能同时做到"宽带 + 角度不敏感"的原因，代价是制备复杂度

### 3.2.2 深度解析 B：超表面的四种共振机制

原文列了"LSPR / Mie 散射 / 非对称激发"但未展开。四者物理不同，适用场景也不同：

| 机制 | 物理图像 | 主导条件 | 共振波长由什么决定 | 增强什么 |
|------|---------|---------|------------------|---------|
| **LSPR（局域表面等离激元共振）** | 金属纳米结构的自由电子集体振荡；电场在结构表面 / 间隙处**极度集中**（近场增强可达 10–10⁴ 倍） | **金属**结构（Au/Ag/Al）或在红外用重掺杂半导体 | 结构**尺寸 + 介电环境** | **近场增强** → 使弱吸收介质也表现出强发射 [206, 207] |
| **磁极化激元（magnetic polariton, MP）** | MIM 结构中**上 / 下金属层内电流反平行** → 形成**磁共振**（"暗模式"，辐射损耗低） | **MIM 型结构**（金属–介质–金属），介质层夹在中间 | 介质层厚度 + 单元尺寸 | **Q 值高、吸收峰窄而强**；Long 等 [48] 的 HfO₂ + VO₂ 圆盘正是激发**不同温度下的不同磁极化激元** |
| **Mie 散射** | 高折射率**介质**纳米柱内的电磁多极共振（电偶极 / 磁偶极 / 四极…） | **高折射率介质**（Si、Ge、TiO₂） | 柱**半径与高度**之比 | 低损耗、可设计多极干涉（如 Kerker 效应）；适合介质超表面 |
| **非对称激发（asymmetric excitation）** | **故意打破结构对称性** → 原本的"暗"高阶级数被激发（对称性破缺使选择定则松弛）→ **高阶模耦合** | 非对称单元（斜切、错位、双尺寸） | 对称性破缺的程度与方式 | **宽谱增强**（多高阶模叠加）；代价是偏振依赖 |

> **对 VO₂ 超表面的设计要点**：VO₂ 在金属态本身就是"金属"，在绝缘态是"介质"——所以**同一个结构在相变前后会切换共振机制**（绝缘态像 Mie / 介质共振，金属态像 MP 或 LSPR）。Long [48]、Yang [13] 的高 Δε 正源于**相变前后"共振有无 / 机制切换"的对比度**，而非简单的吸收率增减。

**一个被反复引用的损耗–制备权衡**：文中明确写出电子束光刻 + 聚焦离子束刻蚀的工艺复杂度是超表面大面积化的瓶颈 [197–200]。这也是为什么"纳米压印 + 低温工艺"（如 W:VO₂ meta-OSR 做到 10×10 cm² 并通过航天级验证）会被视为重要进展。

## 3.3 新兴增强机制

当前研究已超越传统"本征材料响应 + 被动微纳结构设计"，纳入：

- **ENZ（epsilon-near-zero）模式激发**，如 **Berreman 构型**——在选定角度与波长实现大幅发射率增强
- **动态表面发射率调控**——在系统层面解决"储热与散热的时间权衡"
- **仿生多功能集成**（如 **Janus 架构**）——结合外部光场 / 磁场，提升器件适应性
- **外场耦合增强**——提高光热转换效率

### 3.3.1 深度解析 C：ENZ 模式与 Berreman 构型

这是全文中术语密度最高、最容易被跳过的一段，值得单独讲清楚。

**(1) ENZ（epsilon-near-zero）**

- 定义：介电常数实部 ε₁(ω) → 0 的频率区间
- 出现在哪里：**金属的等离子体频率附近**、**极性介质的纵光学声子（LO）频率附近**（如 SiO₂ 的 ~9.8 μm、SiC 的 ~10.3 μm）
- 为什么特殊：由 Maxwell 方程 ∇·(εE) = 0，当 ε → 0 时纵向电场可极大；同时波矢 k = (ω/c)√ε → 极小（**波长被"压缩"**），相位在介质内几乎不累积
- 后果：在极薄（≪ λ）的层内即可积累**巨大相位变化** → 强烈的**角度依赖**吸收 / 发射；同时局域场增强 → 高吸收

**(2) Berreman 构型 / Berreman 模式**

- 场景：**极性介质薄膜**（如 SiO₂、SiC、VO₂ 在 LO 频段）置于衬底上，p 偏振光**斜入射**
- 机制：在 LO 频率处，膜内出现**纵光学声子**，其电场沿膜面法向，**只有斜入射的 p 偏振光才能激发**（只有 p 偏振有法向电场分量）
- 表现：在 LO 频率处出现一个**窄而强的吸收峰**，强度和位置**强烈依赖入射角**——θ 增大时峰位红移、强度变化
- 为什么被纳入"新兴机制"：它提供了一条**在选定角度与波长上实现近 100% 发射**的通道，且无需纳米加工（仅靠薄膜本身的极性声子），天然适合**大面积、低成本**的辐射调控

**(3) 与 F–P 腔的本质区别**

| 维度 | F–P 腔共振 | Berreman / ENZ 模式 |
|------|-----------|-------------------|
| 物理本质 | **几何**共振（腔长决定） | **材料本征**光学声子（介电函数决定） |
| 频率位置 | 由 n·d 调 | 由材料 LO 频率固定（SiO₂ ≈ 9–10 μm） |
| 角度依赖 | 有（cosθ 位移） | **强**（p 偏振、斜入射专属） |
| 是否需要纳米加工 | 需要精确镀膜 | **不需要**（薄膜即可） |
| 可调性 | 靠调厚度 | 靠选材料 / 调整层介质环境 |

> **对做辐射制冷的设计意义**：SiO₂ 的 Berreman 模式恰好落在 **8–13 μm 大气窗口**内，这是为什么几乎所有多层辐射冷却器都含 SiO₂ 层——它不只是"低折射率间隔层"，更是**选择性发射的功能层**。

### 3.3.2 其余三个方向的物理实质

| 方向 | 物理本质 | 工程含义 |
|------|---------|---------|
| **动态表面发射率调控** | 在系统层面把"储热"与"散热"在**时间上解耦**（如白天储热、夜间放热），而非在同一时刻既高发射又低发射 | 用 PCM 的**迟滞**特性当"记忆"，或用相变潜热当缓冲 |
| **仿生 Janus 架构** | 两侧功能不同（一侧高发射制冷、一侧低发射保温 / 吸热），利用**各向异性**同时满足矛盾需求 | 文中 [185] 的"企鹅启发 Janus 复合膜"实现热管理 + 微波调制 |
| **外场耦合增强** | 引入光场 / 磁场 / 电场作为**第二个独立调节旋钮** | 突破"温度是唯一自变量"的限制；但增加系统复杂度（与 §2.2.10 中 VO₂ 的复杂性问题同源） |

这些机制并非孤立，而是与"本征相变 + 超表面 / 腔共振"经典策略**互补**，推动动态热辐射控制从**静态、单参数设计**走向**可编程、智能化系统**。

GA 优化超材料结构；在红外隐身层引入 VO₂，实现温度自适应红外隐身切换，**发射率降低 0.41**。

# 第 5 章 挑战与展望

作者提出未来三大方向：**高效率（high efficiency）/ 智能化（intelligence）/ 可持续（sustainability）**。

## 5.1 挑战一：服役条件下的性能平衡（最根本）

- 已开发出 Δε > 0.5 的材料，但**往往牺牲环境稳定性与长期耐久性** [165, 238, 239]
- **VO₂ 的典型权衡**：优异发射率调制源于 MIT 伴随的晶格畸变，但**每次循环的变化会诱导机械应力** → 微裂纹萌生与扩展；钒的多价特性使其在潮湿空气中由 **V⁴⁺ → V⁵⁺ 氧化**，生成惰性 **V₂O₅**，热致变色性能逐渐退化 [240, 241]（失效链详解见 §2.2.4）
- **GST 的失效路径**：非易失性 + 纳秒切换是其优势，但反复循环中非晶 / 晶态差异导致**元素偏析、空洞形成、界面粗化** → 累积性器件失效 [156]
- **环境–性能鸿沟（environment–performance gap）**：当前研究多在受控实验室条件下评价，无法复现真实工况的复杂动态特性。热循环、机械磨损、环境退化等多因素应力会显著影响可靠性与寿命 → 需更严格的评价协议

## 5.2 挑战二：AI 驱动的材料设计

**多尺度成分–结构–性能关联模型**可显著加速材料发现、结构优化与性能提升 [242–251]。

**三个层次的 AI 应用**：

| 尺度 | 方法 | 作用 |
|------|------|------|
| **器件尺度** | 神经网络 + 遗传算法混合方案 | 逆向设计 |
| **器件尺度** | **双向神经网络** | 从目标光谱响应直接提取结构参数 |
| **原子尺度** | 基于**团簇展开（cluster expansion）**框架的机器学习原子间势 | 以接近 DFT 的精度模拟 PCM 的原子构型与相变路径，但计算成本大幅降低 [254–256] |
| **闭环** | 生成式 AI + 主动学习**贝叶斯优化** + 实验反馈 | 逐步成熟 |

**最大障碍：数据稀缺（data scarcity）**

综述原文：*"Obtaining reliable experimental optical constants is both time-intensive and expensive, and currently available public repositories are markedly limited in their coverage of material types, **phase states**, and spectral ranges."*

- 可靠的**实验光学常数获取耗时且昂贵**
- 现有公共数据库在**材料类型、相态、光谱范围**覆盖上明显不足
- 高通量计算产生的数据量**远未达到有效深度学习训练的要求**
- 缺乏跨数据源的标准化 → 数据聚合与复用困难 → 小样本学习过拟合、迁移到陌生材料体系泛化差

**迫切需求**（作者给出的"应该建什么"）：

1. 面向动态热发射器的**专用多尺度仿真数据集**
2. **全面光谱数据（PCM 的折射率 n 与消光系数 k）**
3. 宏观层面纳入**真实工况下的器件性能指标**
4. 关键一步：构建**跨尺度关联数据库**，连接**电子结构 → 介电函数 → 动态热发射**，同时考虑**制备参数对最终性能的影响**

> 💡 **对本人工作的直接启示**：§5.2 这条"n/k 光谱数据库 + 相态 + 制备参数"的需求链条，与正在做的 VO₂ nk 反演（定厚度法 / 双厚度包络法）思路高度契合——**反演框架产出的正是这里最缺的"相态分辨 n/k 数据"**。据此展开的 8 个研究方向见**附录 B**。

## 5.3 挑战三：规模化制造

| 应用场景 | 规模化要求 | 具体挑战 |

# 第 7 章 个人判读与研究工作衔接

## 7.1 这篇文章的三个"抓手"

1. **"三材料 × 三结构 × 三战场"的矩阵化叙事很清晰**：
   - AMnO₃ → 掺杂 / 多层 → 航天热控
   - VO₂ → F–P 腔 / 超材料 → 智能窗 + 红外隐身
   - GST → 超表面 / 激光直写 → 光子集成 + 传感
2. **把"增强机理"独立成节**（第 4.2 节）：掺杂讲晶格畸变 → 偶极矩 / 声子 / 小极化子，多层讲 F–P 相干干涉 → 局域态密度，超表面讲 LSPR / Mie / 非对称激发——这是全文知识密度最高的部分。
3. **评价范式转变的明确宣示**：Δε 不再是唯一判据，转向"综合平衡"。

## 7.2 我认为值得警惕 / 深挖的点

- **Table 1 与 Table 2 存在若干不一致**：Table 1 把 VO₂ 的稳定性记为 "Low"，但正文多处强调 VO₂ 是当前商业化最有希望的材料之一（仅耐久性不足）；Table 1 把 AMnO₃ 的调制能力记为 "Low (Δε < 0.7)"，而 Table 2 中 AMnO₃ 系最高做到 Δε = 0.65（Wang [60]）——两处在边界上打转，说明**这条分界线本身有点勉强**。
- **VO₂ 的 Δε > 0.7 归属**：Δε = 0.78（Xie [17]）、0.72（Yang [13]）、0.78（Liang [179]）都靠**结构设计**（F–P 腔 / 超材料）而非材料本征，Table 1 把这一成绩记在 VO₂ 名下，严格说是"VO₂ 基复合结构"的成绩。
- **GST 的 "stable state" 定义**：文中说 200 °C 转六方稳定态，且"除非 T > 640 °C 或激光辐照否则长期保持"——但同段又说循环会导致元素偏析与失效。**"长期保持"与"循环失效"这对表述需要看原始文献才能调和**（建议查 [138] Hu et al., *Acta Mater.* 2020 与 [156] Huo et al., *Appl. Phys. Rev.* 2024）。
- **波长–机制对应关系（GST）是本文独有的梳理**，但支撑文献 [141] *PNAS* 2011 与 [142] *PRL* 2006 都是较老文献，且不直接针对"机制随波长切换"。**这一节更像作者的综述性推断，需谨慎引用。**

## A.0 一页速览

1. **W 是降低 VO₂ 相变温度（Tc）效率最高的施主掺杂元素**，典型效率 **20–26 °C/at%**，约 **2 at% 即可把 Tc 拉到室温**。
2. **但 W 掺杂效率随工艺路线剧烈变化**：从水热法的 **5.2 °C/at%**（按实际掺杂量）到离子注入的 **74.2 °C/at%**，相差 **14 倍**。这意味着**"掺杂量–Tc"不存在普适经验公式**——这正是 AI for science 可切入的真空地带。
3. **W 掺杂普遍降低红外发射率调制幅度 Δε**：未掺杂 Δε ≈ 0.6 → 1 at% W 后 Δε ≈ 0.4。原因是施主电子稳定金属态、削弱相变前后的介电对比度。
4. **但结构设计可以补偿**：W:VO₂ + F–P 腔 + 高反射基底，可同时做到 **Tc = 27.5 °C 且 Δε = 0.51–0.61**；HiPIMS 多晶方案做到 **ε: 0.25→0.87**（7–13 μm 大气窗口）。
5. **过量掺杂反效果**：> 2–3 at% 时相变变宽、协同性下降，ΔT_sol 与开关锐度衰减；重掺杂区（0.16 ≤ x ≤ 0.2）甚至出现 **Tc 异常升高**。
6. **实测坑**：名义掺杂量 ≠ 实际掺杂量（水热法名义 18 at% 仅实得 5.5 at%）；DSC 测得的 Tc 与升降温速率强相关。

## A.1 物理机理：为什么 W 最有效

### A.1.1 电荷补偿与 V–V 键削弱

```
W⁶⁺ 取代 V⁴⁺（离子半径 W⁶⁺ ≈ 0.60 Å vs V⁴⁺ ≈ 0.58 Å，六配位）
   ↓
一个 W⁶⁺ 相对 V⁴⁺ 多出 2 个正电荷
   ↓
电荷补偿：W 的 d 层电子转移给邻近 V 离子
   ↓
形成 V³⁺–W⁶⁺ 对（沿单斜晶胞轴方向）
   ↓
V⁴⁺–V⁴⁺ 键被削弱 → 半导体相（M1）失稳
   ↓
Tc 下降
```

**关键点**：这不是简单的"电子注入"，而是**电荷补偿驱动的局域键合重构**。文献原文表述为："*the reduction of Tc is attributed to a decrease in the bond strength between the V ions through the formation of V³⁺–W⁶⁺ pairs along the axis of the VO₂ monoclinic cell*"（*Appl. Surf. Sci.* 2023）。

### A.1.2 两条并行的调控通道

| 通道 | 物理内容 | 定量贡献 |
|------|---------|---------|
| **电子通道** | W⁶⁺ 施主电子填充 t2g 带；额外电子破坏 R 相 V–V 二聚化的结构对称性，**缩小 M 相与 R 相的能量差** | 有文献称约 **85%**（⚠️ 见 A.1.4） |
| **晶格通道** | 大离子半径取代 / 间隙位插入 → **压应变 + 结构畸变** → 诱导**类金红石结构** → 降低相变需克服的热能垒 | 约 **15%** |

> **注意"间隙掺杂更有效"这条**：文献指出 interstitial doping 比 V 取代掺杂更能降低 Tc。典型例子是 **B 掺杂**（−31.5 °C/at%），比 W 更高效——但 B 的光学代价与稳定性尚不清楚。

### A.1.3 为什么 W 强于 Nb 和 Mo

| 元素 | 电负性 | 与 V-3d 杂化 | 效果 |
|------|-------|-------------|------|
| **W** | **最高** | **强杂化** → 有效贡献局域电子 | **效率最高（20–26 °C/at%）** |
| Mo | 中 | 中等 | 11–17 °C/at% |
| Nb | 较低 | **Nb-4d 与 V-3d 杂化差**；Nb–O 离子性增强 → **软化 V–V 相互作用** | 5–12 °C/at% |

即：Nb 效果弱不只是"电价低"（Nb⁵⁺ vs W⁶⁺），更因为 **Nb–O 键的离子性太强、4d 轨道与 V-3d 杂化不良**，无法有效地把电子"送进"V 的 t2g 带。

### A.1.4 ⚠️ 可信度提示

网上流传"W⁶⁺ 每引入一个阳离子给导带注入**一个**电子"与"**两个**电子"两种说法（分别见于综述性页面与 *Appl. Surf. Sci.* 原文）。以电荷守恒计，W⁶⁺ 取代 V⁴⁺ 应净多出 **2** 个电子（若补偿为纯电子机制）。**"85% 电子 / 15% 晶格"这组比例来自一个内容农场页面（johal.in），标注引用"López et al. 2018"，但无法核实原文，建议不要直接引用**，需自行回溯。

### A.3.1 常被忽略的两条规律

**(a) 高电价 → 降 Tc；低电价 → 升 Tc**

- 高价离子（W⁶⁺、Mo⁶⁺、Nb⁵⁺、Ta⁵⁺）→ **降低** Tc
- 低价离子 → **升高** Tc

物理原因：高价离子提供额外电子填充 t2g 带，缩小 M–R 相能量差；低价离子反之（缺电子 → 稳定绝缘相）。

**(b) 掺杂效率与"光学代价"反相关**

文献的核心结论是：**没有一种掺杂能同时优化所有指标**——W 在降 Tc 上胜出（效率最高），而 **F 与共掺杂方案（W+F、W+Mo）在保持光学质量上胜出**。

### A.3.2 共掺杂方案（绕过 trade-off 的主流思路）

| 体系 | 最佳组分 | 性能 | 说明 |
|------|---------|------|------|
| **Mg / W** | 2% W + 4% Mg | **T_lum = 81.3%**，Tc = 35.5 °C | 溶胶–凝胶纳米颗粒；Mg 补偿 W 的透过率损失 |
| **W / Zr** | — | Tc = 28.6 °C，T_lum = 48.6% | 水热合成 |
| **Sn / W** | — | **ΔT_sol = 13.4%**，T_lum = 41.1%，Tc = 26 °C | 水热法纳米颗粒 |
| **W + F** | — | 保留光学品质 | F 无结构性扰动 |
| **W + Mo** | — | 保留光学品质 | Mo 畸变较温和 |

> **设计逻辑**：**W 负责降 Tc，共掺元素负责救光学性能**。这是当前最实用的工程折中路线。

## B.2 方向 A：相态分辨 PCM n/k 数据库 + 自动反演流水线 ⭐P0

### B.2.1 科学问题与 gap 出处

综述 §5.2 原文点名了"**相态**（phase states）"——这正是 PCM 类材料最特殊、也最缺的数据维度。现有数据库（refractiveindex.info、Materials Project）几乎都只收录室温、单一相态的 n/k。

### B.2.2 为什么可行（资产盘点）

| 已有资产 | 在本方向的作用 |
|---------|--------------|
| VO₂ RT 曲线反演框架（定厚度法 / 双厚度包络法） | **反演引擎** |
| 50 / 200 nm 两种厚度的 VO₂（Si 基底）样品 | **双厚度包络法的物理基础** |
| 0.28–25 μm 波长范围覆盖 | 覆盖 Vis-NIR + Mid-IR 两大应用波段 |
| 工作站 `tmm` + GPU 加速 `tmm-fast` | 正向模型 & 批量拟合加速 |
| 现有滤波 / 平滑与边缘残差检查流程 | 数据质量控制 |

### B.2.3 具体怎么做

**Step 1 — 定义数据 schema（整个方向的地基）**

```
材料:      化学式、相态（M1/R/M2/非晶/FCC/六方）、相分数 f
制备:      工艺（PLD/溅射/水热/溶胶凝胶…）、衬底、膜厚、退火条件、
           掺杂元素 + 名义/实际掺杂量（EDS 值）
测量:      温度 T、波长 λ 网格、测量量（R/T/ε/ΨΔ）、仪器、入射角
光学:      n(λ,T)、k(λ,T)、色散模型 + 参数、不确定度
质量:      KK 残差、边缘残差、拟合 R²、可信区间
溯源:      DOI / 数据来源 / 是否二次反演
```

> **关键设计决策**：把 **`相态` 和 `相分数 f`** 作为**一等公民字段**，而不是把温度当唯一自变量。这是与通用光学数据库最大的区别，也是"相态分辨"这四个字的落地方式。

**Step 2 — 数据来源三条腿**

| 来源 | 做法 | 优势 | 风险 |
|------|------|------|------|
| **① 自己实测** | 变温（25–90 °C，步长 2–5 °C）× 变 W 掺杂（0/0.5/1/2/3 at%）× 0.28–25 μm × 两种厚度 | 数据质量最高、可控、有物理配套 | 工作量大，需要样品与设备 |
| **② 文献二次反演** | 从论文 Supplementary 或图中提取 R/T/ε 曲线 → 用自己的反演框架重算 n/k | 快速扩充规模；**且"重新反演"本身就能发现原文献的错误或不一致** | 需注意版权与引用规范；图形数字化有误差 |
| **③ 已发表椭偏 / n,k** | 直接收录并标注来源 | 建立基准锚点（ground truth） | 覆盖相态有限 |

> 💡 **来源 ② 是一个被低估的加分项**：把同一材料不同文献的 n/k 放在统一框架下重算，往往会暴露 **k（消光系数）在弱吸收区差异达数倍**的问题——这本身就是一篇可发表的"数据质量审计"论文。

**Step 3 — 反演方法融合（多方法交叉验证）**

```
输入 R(λ,T), T(λ,T)
   ↓
① Swanepoel / 双厚度包络法  →  给 n(λ) 初值 + 厚度 d       [物理透明，不依赖初值猜测]
   ↓
② TMM 正演 + 最小二乘精化    →  精修 n, k, d              [用 tmm-fast 批量加速]
   ↓
③ 色散模型全局拟合           →  参数化到物理模型
     绝缘态: Tauc-Lorentz（带间）+ 若干 Lorentz 振子（声子）
     金属态: Drude（自由载流子）+ Lorentz（声子）+ 可加 Tauc-Lorentz
     中间态: 上述两态的 EMA（Bruggeman）混合，混合系数 = 相分数 f
   ↓
④ Kramers-Kronig 一致性校验  →  作为硬约束（不合格则退回 ③）
   ↓
⑤ 不确定性量化              →  MCMC / bootstrap 给 n,k 的置信区间
   ↓
输出: n(λ,T), k(λ,T) ± 置信区间, 色散模型参数, 质量指标
```

**为什么 ③ 的"参数化 + 相分数混合"特别重要**：它让不同温度、不同掺杂量的数据**在同一个参数空间里可比**。比如可以直接画出：

```
W 掺杂量 → Drude 等离子体频率 ω_p → 金属态 ε_∞
W 掺杂量 → 相变温度 Tc
W 掺杂量 → 两态介电对比度 Δε
```

**这三条曲线本身就是"W 掺杂如何改变 VO₂ 光学性质"的系统性答案**——而检索显示这类数据目前是**缺失的**（见附录 A.7 第 4 条）。

**Step 4 — 质量控制与不确定性（多数论文缺失的一环）**

| 指标 | 目的 |
|------|------|
| KK 残差 | 保证 n,k 物理自洽 |
| 边缘残差（波长上下限附近） | 既有习惯，必须保留并**数据化** |
| 拟合 R² / RMS | 常规 |
| Bootstrap 置信区间 | 把"反演出的 k 在弱吸收区不可靠"这一事实**量化出来**，而不是藏起来 |
| 交叉方法一致性 | 包络法 vs TMM 拟合 vs 椭偏基准 的差异 |

### B.2.4 评价指标与输出物

| 项 | 内容 |
|---|------|
| **评价** | ① 与椭偏仪 / 文献基准的相对偏差；② KK 残差；③ 弱吸收区 k 的可信区间宽度；④ 跨文献同材料一致性 |
| **输出** | 开源数据集（附 schema 文档）+ 自动反演代码（可复用）+ 1 篇 Data descriptor |
| **投稿** | *Scientific Data* / *Optical Materials Express* / *ACS Applied Materials & Interfaces*（若含新实验） |
| **价值** | **这份数据是所有后续方向（B/C/D/E/F）的燃料**。没有它，后面的 AI 工作都只能在小样本上打转 |

## B.3 方向 B：可微分 TMM + 相分数隐变量的端到端逆设计 ⭐P0

### B.3.1 科学问题

现有 VO₂ 逆向设计几乎都把它当**两套固定 n/k**（绝缘态一套、金属态一套）来优化，但真实的相变是**渐变的**：存在**中间态**（相分数 f 从 0 到 1 连续变化）、存在**迟滞**（升温 / 降温路径不同）、**梯度掺杂**（如 *ACS Nano* 2025 的准梯度架构）会形成**连续分布的多态**。忽略这些，设计出的器件在真实温度扫描下表现会偏离预期。

### B.3.2 具体怎么做

**Step 1 — 把 TMM 写成可微层**（PyTorch / JAX 重写传输矩阵法）

```python
class TMMLayer(nn.Module):
    def forward(self, wl, nk_stack, thickness):   # 全可微
        # 1. 各界面 Fresnel 系数（复数）
        # 2. 各层相位 δ = 2π·n·d·cosθ / λ
        # 3. 传输矩阵连乘 → r, t
        # 4. R = |r|², T = (n_sub/n_inc)·|t|²
        return R, T
```

- **用现有 `tmm` 库做数值基准测试**（保证梯度版与成熟版结果一致到 1e−10）
- 注意复数运算的梯度：PyTorch 支持 complex autograd，但要小心 `torch.abs()` 在 0 处的不可导点

**Step 2 — 引入相分数 f 作为可微隐变量**（整个方向的技术核心）

```python
# 有效介质近似（Bruggeman / Maxwell-Garnett）
def eps_eff(f, eps_ins, eps_met):
    return ema_bruggeman(eps_ins, eps_met, f)      # 自洽解，可微

# 相分数随温度演化（物理模型）
def f_of_T(T, Tc, width, hysteresis):
    f_up   = sigmoid((T - Tc) / width)                    # 升温支
    f_down = sigmoid((T - Tc - hysteresis) / width)       # 降温支
    return f_up, f_down
```

它让"相变"变成可微的，于是 **Tc、迟滞宽度、相变陡度都能作为设计变量参与梯度优化**。

**Step 3 — 多目标损失函数（把物理和工艺都写成 loss）**

```python
L = w1 * (-Δε)                          # 最大化发射率调制幅度
  + w2 * relu(α_sol - α_budget)**2      # 太阳吸收硬约束
  + w3 * (T_MIT_pred - T_MIT_target)**2 # 目标相变温度
  + w4 * hysteresis_norm                # 抑制迟滞（可选，看应用）
  + w5 * KK_violation                   # KK 一致性（物理约束）
  + w6 * thickness_roughness            # 抑制厚度极端值 / 交替层（可制造性）
  + w7 * interdiffusion_penalty         # 相邻层互扩散风险（工艺约束）
```

**Step 4 — 制造性约束前移**（从 DiffMeta 学到的关键经验）

| 约束 | 实现方式 |
|------|---------|
| 厚度只能取 5 nm 的整数倍 | 量化 + straight-through estimator（STE） |
| 材料只能从给定库中选 | Gumbel-softmax 松弛 |
| 层数有上限 | 固定最大层数 + L0 稀疏正则让多余层"消失" |
| 最小层厚（避免互扩散） | 参数裁剪 / 惩罚项 |
| 沉积顺序限制 | 可行组合掩码 |

**Step 5 — 求解策略（三级递进）**

```
① 梯度优化（Adam / L-BFGS）→ 找到局部最优的连续解
② 多起点重启 + 随机初始化 → 找到多个解（一对多）
③ 离散化 + 局部穷举精修 → 得到可制造的解
   ↓
④ 用高保真 TMM / CST 复算 Top-K → 剔除代理模型误判
```

### B.3.3 评价指标与输出物

| 项 | 内容 |
|---|------|
| **评价** | Δε / α_sol / T_MIT 达标率；**鲁棒性**（±5% 厚度误差下的性能退化）；Pareto 前沿覆盖度；可制造性（层数、极值厚度比例） |
| **输出** | 可微 TMM 开源库 + 若干具体器件设计（W:VO₂ 多层 / RMM 双态） |
| **投稿** | *Laser & Photonics Reviews* / *ACS Photonics* / *Advanced Optical Materials* / *Optics Express* |
| **与现有工作的衔接** | 直接升级 **RMM 逆设计（VO₂ + 多层堆栈，2–14 μm 双态）**：从"参数扫描"升级为"梯度端到端优化 + 相分数建模" |

## B.4 方向 C：多目标条件生成式逆设计（图案化超表面）P1

### B.4.1 关键定位判断（这一步别做错）

InfoMetaGen 笔记中已有的结论：

> **"准 1D 多层膜不值得上扩散（TMM 太便宜使摊销省时失效）；2D 图案化超表面（RCWA/FDTD 才贵）才回归。"**

**这个判断必须沿用**。所以方向 C 的**正确对象是图案化结构**（超表面 / 光栅 / 超原子阵列），前向模型用 **RCWA 或 FDTD（CST）**，不能用 TMM。

### B.4.2 具体怎么做

**Step 1 — 数据与正演**

| 项 | 方案 |
|---|------|
| 前向 | RCWA（周期结构，快，可微）为主；CST 用于最终验证 |
| 几何参数化 | 用与制造对应的低维参数（周期、柱径、高度、占空比、圆角半径），而非像素图 → **制造约束天然前移** |
| 相变维度 | 每个结构要算**两态（或三态）光谱** + 相分数连续演化 → 数据集维度翻倍 |
| 数据量 | 条件生成模型通常需 10⁴–10⁵ 样本；RCWA 可离线批量生成 |

**Step 2 — 模型选型（三条路线，按代价排序）**

| 路线 | 架构 | 优点 | 缺点 | 建议 |
|------|------|------|------|------|
| **① 条件 VAE / cGAN** | 条件 = (Δε 目标, α 预算, 波段)；输出 = 几何参数 | 训练稳定、采样快 | 多样性 / 精度弱于扩散 | 先做基线 |
| **② 条件扩散 + 代理引导** | 冻结扩散底座 + 轻量适配器（InfoMetaGen 范式）；用可微 RCWA 做 gradient guidance | 一对多、可控性最强 | 训练成本高 | **推荐主线** |
| **③ 训练无关引导** | 预训练无条件扩散 + 可微正演的梯度引导 | 无需配对数据 | 引导质量依赖正演保真度 | 快速验证用 |

**Step 3 — "物理约束走数据内嵌"的具体实现**（InfoMetaGen 的核心经验是**训练期零 EM 仿真**）

| 物理约束 | 内嵌方式 |
|---------|---------|
| 结构连续性 | 几何参数化天然保证（用尺寸参数而非像素） |
| 对称性 | 单元设计时强制 C4/C2 对称，减少样本空间 |
| 相变物理 | 两态光谱必须由**同一几何**生成（共享几何、只换材料 n/k）→ 保证生成的结构两态自洽 |
| 可制造性 | 参数范围裁剪（周期 2–10 μm、柱高 0.2–2 μm、圆角 ≥ 50 nm） |

**Step 4 — 采样与筛选**

```
采样 N 个候选（如 5000）
   ↓
用可微代理快速评分（Δε、α_sol）
   ↓
Pareto 排序 + 多样性筛选（结构参数的 k-means / 最大最小距离）
   ↓
Top-50 用 RCWA 复算 → Top-5 用 CST 复算（含真实色散与损耗）
   ↓
输出：Pareto 前沿 + 每个解的两态光谱与电场分布
```

### B.4.3 评价指标与输出物

| 项 | 内容 |
|---|------|
| **评价** | 目标命中率；Pareto 覆盖度 / 超体积；**结构多样性**（参数分布熵）；**可行性率**；采样速度 vs 传统 GA/PSO 的加速倍数 |
| **输出** | 生成模型 + 数据集 + 若干超表面设计 |
| **投稿** | *Laser & Photonics Reviews* / *Advanced Photonics* / *Photonics Research* / *ACS Nano* |
| **与现有工作的衔接** | 已有 **CST 仿真代码库**（反射 / 透射 / EMI 屏蔽）→ 可直接用于数据生成与最终验证 |

## B.5 方向 D：掺杂–工艺–Tc–ε 的可解释 ML 与物理信息符号回归 ⭐P0（性价比最高）

### B.5.1 为什么推荐它

| 理由 | 说明 |
|------|------|
| **问题真实且被综述点名** | 综述明确指出 AMnO₃ 的"**doping components 最优解**"尚未解决；而附录 A 证实：同一元素 W 的降 Tc 效率**跨工艺差 14 倍**，但综述与多数文献都把它当**材料本征常数**引用 |
| **数据可得** | 全部来自公开文献，不需要新设备；已抽取 10 组 W 数据作为种子 |
| **方法已掌握** | TOPCon 论文正是"**物理信息符号回归推导工艺公式**"——**同一套方法论可以平移** |
| **验证成本低** | 论文结论只需几个掺杂样品即可闭环验证，实验门槛低 |
| **结论有普适价值** | 若能得到 Tc(x, 工艺) 的统一表达式，会被领域广泛引用 |

### B.5.2 科学问题（精确定义）

> **Q1**：为什么同一元素（W）在不同工艺路线下的降 Tc 效率相差 14 倍？各工艺的贡献如何定量分解？
> **Q2**：能否给出一个**跨工艺统一的** Tc(x, 工艺参数) 半经验表达式？
> **Q3**：Tc 与 Δε 之间的 trade-off 是否存在**可量化的约束边界**（即 Pareto 面）？

### B.5.3 具体怎么做

**Step 1 — 数据构建（手动 + 半自动）**

| 特征类别 | 字段 | 说明 |
|---------|------|------|
| **掺杂** | 元素、电负性、离子半径、氧化态、**名义掺杂量**、**实际掺杂量（EDS/XPS）**、掺杂位点（取代 / 间隙） | 名义 vs 实际必须分列（这是关键） |
| **材料** | 化学式、形态（单晶 / 多晶 / 粉体 / 薄膜）、膜厚、晶粒尺寸、相纯度 | 形态是第一级影响因素 |
| **工艺** | 方法（PLD/溅射/HiPIMS/水热/溶胶凝胶/离子注入/CVD）、沉积温度、退火温度与时间、气氛、氧流量 | — |
| **结构** | 晶格常数、晶胞体积、V–V 二聚体键长、DPA（缺陷密度）、氧空位浓度 | 有报道就录，缺失用工艺代理 |
| **目标** | Tc（升温 / 降温分别记）、ΔTc/at%、迟滞宽度、Δε、T_lum、ΔT_sol | 多任务目标 |

- **目标规模**：200–500 条（W/Mo/Nb/F/B/Ta/Ti × 工艺 × 形态）
- **来源**：本次检索已找到 10 组高质量 W 数据作为种子；再扩充到其他元素与 AMnO₃/GST 体系

**Step 2 — 层次化建模（先分离，再预测）**

```
第一层：元分析（meta-analysis）
   混合效应模型:  ΔTc/at% ~ 元素效应 + (1|文献ID) + (1|工艺类型)
   → 先把"工艺离散度"从"元素本征效应"里剥离出来 → 这一步就能回答 Q1

第二层：树模型 + SHAP 解释
   XGBoost / LightGBM 预测 Tc
   → SHAP 排序出主导特征
   → 验证"材料形态 + 实际掺杂量 + 缺陷密度"是否是隐藏的支配变量

第三层：物理信息符号回归  ← 熟悉的套路
   工具: PySR / gplearn / 自研符号回归
   物理约束:
     - 单位一致性（量纲约束）
     - 单调性先验（Tc 随 x 单调下降，在低掺杂区）
     - 渐近行为（x→0 时 Tc→68 °C）
     - 允许的算子集（+ − × ÷ exp log sigmoid，禁止无物理意义的组合）
   目标: 搜出 Tc = f(x; 工艺参数) 的闭式表达式
```

**Step 3 — 严格的数据划分（这一步最容易翻车）**

| 划分方式 | 目的 | 为什么必须做 |
|---------|------|-------------|
| **按文献来源分组划分（GroupKFold）** | 防止同一篇论文的数据同时进训练与测试 | ⚠️ **多数材料 ML 论文的致命伤**：同源数据泄漏会让 R² 虚高 |
| **留一工艺法（Leave-one-route-out）** | 测试跨工艺外推能力 | 这是 Q1/Q2 的核心能力 |
| **留一元素法（Leave-one-dopant-out）** | 测试跨元素泛化 | 检验是否为"元素特异性拟合" |

**Step 4 — 不确定性量化**：深度集成（Deep Ensembles）或 NGBoost → 给出预测区间；报告"预测区间覆盖率"而非只报 R²（材料 ML 中少有人做）。

**Step 5 — 实验闭环验证**（论文能否上高影响因子的分水岭）

- 用模型预测 **2–3 个未曾报道的 (元素, 工艺, 掺杂量) 组合** → 制备 → 测 Tc 与 Δε → 对比预测

### B.5.4 评价指标与输出物

| 项 | 内容 |
|---|------|
| **评价** | GroupKFold R²；留一工艺法的 MAE；预测区间覆盖率；符号回归表达式的**简洁度–精度权衡**（Pareto 面）；实验验证的命中率 |
| **输出** | ① 结构化文献数据库（可开放）② Tc 预测器（含不确定度）③ 闭式半经验公式 ④ 实验验证 |
| **投稿** | *npj Computational Materials* / *Chemistry of Materials* / *Acta Materialia* / *Journal of Materials Chemistry A* / *Journal of the European Ceramic Society* |
| **风险** | 数据噪音大（不同实验室的 Tc 定义与测量方法不同）→ 必须显式记录测量方法并做敏感性分析 |

## B.6 方向 E：相变滞后与循环退化的寿命预测 P1

### B.6.1 科学问题与 gap 出处

综述 §5.1 原文指出两条退化路径（详见 §2.2.4 与 §2.3.3），并明确批评：*"Current research predominantly evaluates materials under controlled laboratory conditions that fail to replicate the complex, dynamic nature of actual operating environments."*

### B.6.2 具体怎么做

**Step 1 — 把"退化"从"幅值衰减"升级为"指纹漂移"（本方向的创新点）**

传统做法：只记 Δε 从 0.6 衰减到 0.4 → 信息量太少。

**本方向做法**：用**反演出的光学常数**做退化指纹——

| 退化指标 | 物理含义 | 优势 |
|---------|---------|------|
| Drude 阻尼 γ 上升 | 自由载流子散射增强（缺陷增多、晶界恶化） | 比 Δε 敏感 |
| 等离子体频率 ω_p 下降 | 有效载流子浓度降低（氧化成 V₂O₅） | 直接反映化学失效 |
| 相变陡度下降（相分数过渡变宽） | 晶粒 / 畴尺寸不均匀化 | 反映微结构退化 |
| Tc 漂移 | 化学计量比变化 | 反映组分偏析 |
| 迟滞宽度变化 | 界面钉扎（内应力累积） | 反映机械失效 |

**⇒ 用"n/k 的漂移量"当退化指纹，是别人没做过的角度**，且恰好复用方向 A 的反演引擎。

**Step 2 — 加速老化实验设计（DoE）**

| 变量 | 水平 |
|------|------|
| 热循环次数 | 0 / 100 / 500 / 1000 / 5000 |
| 湿度 | 干燥 / 30% RH / 85% RH |
| 温度上限 | 90 °C / 120 °C（加速） |
| 防护层 | 无 / Al-O 核壳 / SiO₂ 顶层 / 多层封装 |
| 掺杂 | 0 / 1 at% W |

→ 用**正交或拉丁超立方设计**控制实验数量（5×3×2×4×2 全因子太大，取 L18 或 L27 正交表）

**Step 3 — 生存分析建模**

```python
① Weibull 参数模型（领域已有，作基线）
② 随机生存森林 / XGBoost-AFT（非线性协变量）
③ DeepSurv / 神经 Cox（若数据量够）
```

- 特征：膜厚、晶粒尺寸、掺杂量、防护层类型、初始 Δε、初始 KK 参数
- 输出：**寿命预测曲线 + 特征重要性**（哪些设计变量真正决定寿命）

### B.6.3 评价指标与输出物

| 项 | 内容 |
|---|------|
| **评价** | C-index（一致性指数）；校准曲线；分位数预测覆盖率；与单纯 Δε 衰减法相比的**提前预警时间** |
| **输出** | 退化数据库 + 寿命预测模型 + "退化指纹"方法论 |
| **投稿** | *Solar Energy Materials & Solar Cells* / *ACS Applied Materials & Interfaces* / *Applied Thermal Engineering* |

## B.7 方向 F：跨材料族光谱基础模型 / 迁移学习 P2

**科学问题**：综述 §5.2 指出 *"leading to overfitting in small-sample learning and poor generalization when applied to unfamiliar material systems"*——现有模型**换个材料族就失效**。

**务实版本（不要一上来做"通用光谱大模型"）**：

| 版本 | 范围 | 可行性 |
|------|------|-------|
| ❌ 全材料通用介电基础模型 | 所有无机材料 | 数据量门槛过高，不适合单人博士课题 |
| ✅ **VO₂ 族内 + 少量外族** | VO₂ / W:VO₂ / Mo:VO₂ / Nb:VO₂ + AMnO₃ + GST 作外族测试 | **推荐** |

**具体路径**：

**Step 1 — 预训练语料**：Materials Project / AFLOW / NOMAD 的从头算介电函数（10⁴–10⁵）+ 文献 n/k 汇编（10²–10³）+ 自己实测（10²–10³）。

**Step 2 — 表征设计（PCM 特有的关键）**

```
Token 序列:  [组成 tokens] [晶体结构 tokens] [相态 token] [温度 token] [掺杂 tokens]
                    ↓
              Transformer 编码器
                    ↓
        双头解码: n(λ) 与 k(λ)（在固定 λ 网格上）
```

> **"相态 token"是本方向的创新点**——通用介电基础模型没有这个维度，而 PCM 恰恰最需要它。

**Step 3 — 训练策略**：① 在从头算介电数据上做掩码重建 / 对比学习预训练 → ② 在实验 n/k 数据上小学习率监督微调 → ③ 下游零样本 / 少样本预测未见掺杂量的 W:VO₂ n/k，直接喂给方向 B 的逆设计。

**评价与投稿**：零样本 / 5-shot / 20-shot 下的 n,k 预测误差（对比从零训练基线）与跨材料族迁移增益；*npj Computational Materials* / *Digital Discovery* / *J. Chem. Inf. Model.*

## B.8 方向 G：ML 原子间势模拟相变路径 P2

**科学问题**：综述中 Peierls vs Mott 的权重问题**未决**；W 掺杂降 Tc 的机制**只有定性描述**（"电子施主 + 晶格畸变"），缺乏定量分离。

**Step 1 — 训练等变势**

| 项 | 方案 |
|---|------|
| 架构 | MACE / NequIP / 微调 CHGNet 或 MACE-MP-0（从基础模型微调，大幅降低 DFT 数据需求） |

| 算力 | 工作站 GPU（注意 CHGNet/MACE 的显存需求） |

**Step 2 — 模拟目标**

| 模拟 | 输出 | 对应科学问题 |
|------|------|-------------|
| 温度扫描（NPT MD） | V–V 二聚体键长分布随 T 的变化 → 定出转变温度 | Peierls 通道的定量 |
| W 掺杂位点扫描 | W 在 V 位 vs 间隙位；不同浓度的局域结构响应 | W 掺杂机制 |
| 声子谱计算 | 声子软化位置（判断 Peierls 失稳） | 区分 Peierls/Mott |

**Step 3 — 与方向 D 联动（关键）**

```
MLIP 模拟  →  生成"纯净"的 Tc(x, 缺陷浓度, 应变) 数据（无工艺噪音）
                          ↓
              作为方向 D 的先验 / 数据增强
                          ↓
        帮助 D 分离"本征效应"与"工艺效应" ← 这正是 Q1 的答案
```

> 💡 **这是一个漂亮的双向闭环**：实验文献给"真实但混杂"的数据（D），第一性原理给"干净但理想化"的数据（G），两者结合才能做因果分解。

**投稿定位**：*npj Computational Materials* / *Physical Review Materials* / *J. Phys. Chem. C* / *ACS Applied Materials & Interfaces*（若含实验）。

## B.9 方向 H：主动学习 + 半自动实验闭环 P2

**务实版（人在环，不上全自动平台）**

```
初始实验设计（拉丁超立方，~15 个样本）
        ↓
制备 + 表征（R/T、ε）
        ↓
方向 A 的反演引擎 → n/k + 相变参数（Tc、Δε、迟滞）
        ↓
更新多目标代理模型（高斯过程 / 深度集成）
        ↓
多目标贝叶斯优化（qNEHVI，同时优化 Tc 达标 + Δε 最大 + α 最小）
        ↓
批量推荐下一轮 5–8 个实验点（batch BO，匹配实验节奏）
        ↓
        └──────→ 回到"制备 + 表征"
```

**搜索空间示例**：`(W 掺杂量, O₂ 流量, 退火温度, 退火时间, 膜厚)` → 目标 `(Tc → 30±2 °C, Δε → max, α_sol → min)`

**评价与卖点**：达到同等 Pareto 性能所需的**实验次数减少倍数**（相对随机 / 网格搜索），并设一组"专家经验起始点"作为对照；若敢做"AI 盲推荐 → 实验验证"的对照，故事会很有力。投稿 *Digital Discovery* / *Matter* / *Advanced Materials Interfaces* / *Chemistry of Materials*。

## B.10 公共底座：无论做哪个方向都要先搭的三样东西

**这三样不做，后面所有方向都会卡住。**

| # | 底座 | 内容 | 工作量 |
|---|------|------|-------|
| **1** | **统一数据 schema** | 材料 / 工艺 / 相态 / 光谱 / 性能 / 质量指标 六段式结构，CSV 或 SQLite。**把实验记录从"散落的 Excel"变成"结构化数据库"** | 1–2 周 |
| **2** | **可微正向模型** | 可微 TMM（多层膜）+ 可微 RCWA（图案化）。**这是方向 B 和 C 的共同前提** | 3–6 周 |
| **3** | **闭环实验记录流程** | 每次实验的参数与结果自动结构化存储（建议脚本化，输入即入库）。**这是方向 D/E/H 的数据来源** | 1–2 周 |

> ⚠️ **第 3 条是很多人忽略的**：AI for science 的瓶颈往往不是模型，而是**数据在产生的那一刻没有被正确记录下来**。一旦某次实验的参数散失，那份数据就永久失去作为训练样本的价值。

## B.11 推荐执行顺序

不要八个方向全做。按"底座 → 快速产出 → 高亮点"三步走：

**阶段一（0–6 月）：底座 + 快速产出**

```
方向 A（数据底座）  ─┬─→ 产出1：相态分辨 n/k 数据集（Data descriptor）
                     │
方向 D（符号回归）  ─┴─→ 产出2：Tc(x, 工艺) 半经验公式（高性价比，快速）
```

**为什么这两个先做**：A 是所有后续的燃料，且已有反演框架（启动快）；D 数据来自文献（不依赖新实验）、方法已掌握（TOPCon 论文验证过）、结论普适价值高。**两者互为支撑**——A 产出的 n/k 给 D 提供 Δε 数据；D 需要的 Tc 数据可以用 A 的变温测量补齐。

**阶段二（3–9 月，与阶段一并行）：把正向模型做可微**

```
方向 B（可微 TMM + 相分数）  ──→ 产出3：梯度端到端逆设计（升级 RMM 项目）
```

**为什么并行**：B 是纯计算工作，不占用实验资源；且 B 的产出是 C 的前提。

**阶段三（9–18 月）：高亮点**

```
方向 C（图案化超表面的条件生成）  ──→ 产出4：一对多 Pareto 解集（新颖性最高）
方向 E（退化指纹 + 寿命预测）    ──→ 产出5：稳定性方法论（补综述指出的空白①）
```

**长期 / 合作（视资源）**：G（MLIP，支撑 D 的因果分解，需云计算 / 合作）→ F（基础模型，视数据积累）→ H（闭环 BO，需实验资源与设备条件）。

## B.13 最有价值的三个"钩子"

如果只能记三件事，记这三个——它们都从综述的**自身空白**里长出来，因此既有引用依据，又有真实需求：

1. **"相态分辨的 n/k 数据"是综述亲自认定的首要瓶颈**（§5.2 原文），而反演框架正是生产这类数据的工具 ⇒ **方向 A** 是天然入口，且产出能被所有后续方向复用。
2. **W 掺杂降 Tc 效率跨工艺差 14 倍（5.2 → 74.2 °C/at%），但文献普遍当它是材料常数** ⇒ 一个**真实存在、被忽视、可量化、可用已掌握方法解决**的问题 ⇒ **方向 D** 是性价比最高的单点突破。
3. **"退化"可以被重新定义为"反演出的光学常数漂移指纹"，而不是"Δε 幅值衰减"** ⇒ 用更敏感的物理量做寿命预测，同时回应综述点名的"环境–性能鸿沟" ⇒ **方向 E** 是别人没做过的角度。
