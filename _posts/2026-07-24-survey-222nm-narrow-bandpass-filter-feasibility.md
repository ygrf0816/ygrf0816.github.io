# [专题调研] 222 nm 超窄带滤光片可行性调研报告

> 调研日期：2026-07-24  
> 目标指标：中心波长 222nm，T > 90%，其余波段 OD > 4，FWHM < 2–4 nm  
> 考虑路线：① 多层介质膜 ② 微纳结构/超表面

---

## 一、目标指标拆解与难度评估

| 参数 | 目标值 | 当前国际最好水平 | 差距分析 |
|------|--------|-----------------|---------|
| 中心波长 | 222 nm | 222 nm（已有商业化产品） | ✅ 可实现 |
| 峰值透过率 Tp | > 90% | 78–85%（商业 IBS HfO₂/SiO₂） | ⚠️ **核心瓶颈**：222nm 处于 HfO₂ 吸收边附近 |
| FWHM | < 2–4 nm | 8–12 nm（商业）；1.9 nm（研究，T=27.7%） | ⚠️ **T-FWHM 不可兼得**：收窄带宽必然牺牲透过率 |
| 带外截止深度 | OD > 4 | OD4–OD6（商业已达） | ✅ 可实现 |
| 截止范围 | 全波段（除通带外） | 230–1100 nm（商业已达） | ✅ 可实现 |

**核心矛盾**：在 222nm 波长处，**峰值透过率 > 90%** 与 **FWHM < 2nm** 之间存在根本性物理冲突。原因在于：

1. **材料吸收边限制**：最常用的高折射率材料 HfO₂ 的带隙约 5.7–6.2 eV（对应 ~200–220nm），在 222nm 处 k 值虽小但非零（~10⁻³–10⁻⁴ 量级），每层膜都会引入微量吸收
2. **层数-损耗累积**：FWHM 越窄 → 需要更多腔体/层数 → 吸收和散射损耗累积越大 → 峰值透过率越低
3. **可用材料稀少**：DUV 波段同时满足 n > 2.0 且 k ≈ 0 的材料极少，目前只有 HfO₂ 和 AlN 勉强可用

## 二、路线一：多层介质膜设计

### 2.1 基本原理

采用多腔 Fabry-Perot（F-P）干涉结构：

```
[反射镜组1] | 间隔层 | [反射镜组2] | 间隔层 | [反射镜组3] ...
```

每个反射镜组为 (HL)^n 结构，H = HfO₂（n≈2.0），L = SiO₂（n≈1.5）。

- FWHM ∝ 1 / (F × 腔数)，F 为反射镜精细度
- 单腔 FWHM ≈ λ / (πF)；三腔可降至单腔的 ~1/5
- **关键关系**：n（反射镜对数）→ FWHM 与透过率的权衡

| 反射镜对数 n | 理论 FWHM (nm) | 理论 Tp (%) | 层数估算 |
|-------------|---------------|-------------|---------|
| 2 | ~27 | >95 | ~11 |
| 3 | ~11 | >92 | ~15 |
| 4 | ~6 | ~88 | ~19 |
| 5 | ~4 | ~82 | ~23 |
| 6 | ~2 | ~70 | ~27 |
| 8 | ~1 | <50 | ~35 |
| 10+ | <0.5 | <30 | 45+ |

> 注：上述为理想无损耗估算。实际 222nm 处 HfO₂ 的吸收会使 Tp 进一步降低 5–15%。

### 2.2 当前研究进展

#### (1) 商业产品（2024–2026）

| 厂商 | 材料/工艺 | Tp | FWHM | OD | 备注 |
|------|----------|-----|------|-----|------|
| **万业成（中国）** | HfO₂/SiO₂ IBS, 40–60层 | 78–85% | 8–12 nm | OD4–OD6 | CWL漂移≤1nm/2000h |
| **Alluxa（美国）** | SIRRUS 等离子体沉积 | >90% | 0.3–2 nm | OD6 | **仅限 λ > 250nm**，222nm 未有产品 |
| **Andover（美国）** | 硬镀膜 | ~50% | 10 nm | OD4 | 222nm 标准品 |
| **瑞研光学（中国）** | IBS 三明治工艺 | >10–15% | 10 nm | OD3 | 222nm 低端产品 |
| **NEG（日本）** | 定制 | 高透过 | 可定制 | 可定制 | 面向消杀应用 |
| **UVWAVETEK（中国）** | 硬镀膜 | 90% | 20nm(可定制) | OD3–OD4 | BP222nm 系列产品 |

**关键发现**：Alluxa 在可见-近红外波段已实现 FWHM 0.3nm + T > 90% + OD6 的极高性能，但其技术**无法直接下推到 222nm**，因为其硬镀膜材料体系在 DUV 波段吸收过大。

#### (2) 学术研究

**① 山东大学（Applied Optics, 2021）**
- 作者：朱行悦、于凯雄等
- 设计：DUV 可调谐薄膜滤光片，CWL = 225nm
- 结果：仿真 Tp = 42.1%，FWHM = 1.2nm；实验 Tp = 27.7%，FWHM = 1.9nm
- 角度调谐范围：225.0 → 224.5nm
- **意义**：证明了亚纳米 FWHM 在 DUV 可行，但 Tp 严重不足

**② Springer Applied Physics B（2026）**
- 设计：Si₃N₄/Al/SiO₂ 五层膜，OpenFilters 优化
- 结果：Tp = 7–41%（8个模型），FWHM = 15nm
- 最佳 FOM 模型 Tp 仅 10%
- **意义**：层数少导致 FWHM 宽，金属 Al 层引入额外吸收

**③ 同济大学（光学学报, 2025）**
- 作者：张金龙、季小川等
- 工艺：IBS 制备 HfO₂/SiO₂ 紫外色散薄膜，90层
- 关键发现：氩气溅射 + 500°C 退火可优化 HfO₂ 紫外性能
- 290–390nm 反射率 > 96%
- **意义**：展示了 IBS + 退火在紫外波段的工艺优化路径

**④ 紫外探测系统宽谱段深截止滤光器件（中国激光, 2025）**
- 中心波长 225nm，金属-介质组合结构
- 采用 Al/MgF₂ F-P 腔 + Al₂O₃/AlF₃ 匹配膜系
- 综述了 2013–2017 年紫外滤光片进展：Tp 从 17.96% → 67%（250nm处）
- **关键挑战**：225nm 处深截止（可见-近红外 OD > 4）的报道罕见

### 2.3 多层膜路线的可行性评估

**能否同时满足 T > 90% + FWHM < 2nm + OD > 4？**

**结论：以现有材料体系，几乎不可能同时满足全部指标。**

具体分析：

1. **FWHM < 2nm** 需要至少 n ≥ 6 的反射镜对数（单腔）或 3 腔以上多腔结构，总层数 25–40+
2. 每层 HfO₂ 在 222nm 处的吸收虽小（k ~ 10⁻³），但 30+ 层累积后吸收损耗可达 10–20%
3. 加上界面散射、膜厚误差等因素，实际 Tp 很难超过 70–80%
4. **如果放宽到 FWHM < 4nm**，则 n = 4–5 即可，层数 ~20，理论 Tp 可达 80–85%，接近但仍低于 90%

**可能的突破方向**：
- 🔬 **开发新型高折射率 DUV 材料**：如 AlN（n≈2.1, Eg≈6.2eV）或纳米复合膜（HfO₂/SiO₂ 纳米层状结构）
- 🔬 **退火优化**：500°C 退火可降低 HfO₂ 在 222nm 附近的吸收
- 🔬 **离子束溅射（IBS）+ 实时光学监控**：精确控制每层厚度，补偿误差
- 🔬 **多层材料组合**：如 HfO₂（高n）+ Al₂O₃（中n，更宽带隙）+ SiO₂（低n）

## 三、路线二：微纳结构/超表面

### 3.1 基本原理

利用亚波长周期结构中的**导模共振（GMR）**或**准束缚态连续谱（QBIC）**实现窄带滤波：

- **GMR 滤波器**：光栅周期 < λ，入射光耦合进波导模式，在特定波长产生反射峰（ notch ）或透射峰
- **QBIC 滤波器**：通过打破结构对称性，将 BIC 转化为可从自由空间激发的高 Q 共振
- **表面晶格共振（SLR）**：周期阵列的衍射级与局域模式耦合，产生窄带共振

### 3.2 DUV 超表面的材料与工艺挑战

| 挑战 | 具体问题 |
|------|---------|
| **材料选择** | DUV 波段需 n > 2.0 且 k ≈ 0 的材料，仅有 HfO₂（n≈2.0, Eg≈5.7eV）和 AlN（n≈2.1, Eg≈6.2eV）勉强可用 |
| **加工精度** | 222nm 对应结构周期 ~150nm，特征尺寸 ~50–80nm，深宽比 3–8:1，需电子束光刻（EBL） |
| **加工缺陷** | 侧壁粗糙度直接降低 Q 值；DUV 波段对加工缺陷极其敏感 |
| **工作模式** | GMR 天然是反射型 notch 滤波器，做透射型 bandpass 需要特殊设计 |
| **截止带宽** | 超表面的截止带通常较窄（几十 nm），实现 230–1100nm 全截止需结合其他机制 |

### 3.3 当前研究进展

#### (1) HfO₂ DUV 超表面（Harvard, Nature Light Sci. Appl., 2020）

- 作者：F. Aieta 等（哈佛大学）
- 材料：HfO₂（ALD 沉积，Damascene 工艺）
- 波长：266nm（DUV 最短记录）
- 功能：超透镜、加速光束、全息
- 关键：HfO₂ 在 220–380nm 范围 n > 2.1, k ≈ 0
- **意义**：首次证明 DUV 超表面可行，但未涉及窄带滤波

#### (2) AlN 高数值孔径超透镜（A*STAR, Research Square, 2025）

- 作者：O.A.M. Abdelraouf 等（新加坡 A*STAR）
- 材料：AlN
- 波长：266nm
- NA = 0.7–0.9，衍射极限聚焦
- **意义**：AlN 是比 HfO₂ 更有前景的 DUV 超表面材料（带隙更宽）

#### (3) 全硅 UV 超表面高 Q 吸收（Opt. Commun., 2025）

- 作者：谢宇辰等
- 材料：Si（利用 UV 波段的介电常数负值实现等离激元效应）
- 波长：UV 波段（>300nm）
- 线宽：4.6nm（Q ≈ 65）
- **意义**：证明 UV 高 Q 共振可行，但 4.6nm 仍远大于 2nm 目标，且 Si 在 222nm 处吸收严重

#### (4) 超高 Q 导模共振（Nat. Commun., 2023）

- 作者：L. Huang, R. Jin 等（UNSW + 中科院上海技物所 + CUNY Andrea Alù）
- 方法：在 SOI 波导上叠加光刻胶扰动层，实现 BIC→GMR 转换
- Q 因子：2.39 × 10⁵（实验），理论可达 10⁶
- 波长：通信波段（~1550nm）
- **意义**：方法可原理性推广到 UV，但 DUV 材料和加工限制使 Q 值大幅下降

#### (5) HfO₂ 导模共振光栅（IEEE Photonics Journal, 2014）

- 作者：Y. Wang 等（南京邮电大学）
- 材料：HfO₂ 自支撑薄膜（200nm厚）
- 波长：可见光波段
- 工艺：IBE + DRIE
- **意义**：证明 HfO₂ GMR 光栅可行，但仅限于可见光

#### (6) 光子晶体异质结 UV 滤光片（Opt. Commun., 2012）

- 结构：TiO₂/SiO₂ 1D 光子晶体异质结含缺陷
- 结果：CWL = 364.7nm，Tp = 97.89%，FWHM = 0.47nm
- **意义**：证明亚纳米 FWHM + 高透过率在近紫外可行，但 TiO₂ 在 222nm 处严重吸收

#### (7) Si₃N₄/SiO₂ 光子晶体日盲紫外滤光片（Superlattices Microstruct., 2018）

- 结构：(PC1)₆(PC2)₆(PC3)₆(PC4)₆(PC5)₁₀ 异质结
- 结果：239–280nm 平均 T = 72.2%，290–700nm 平均 T < 3.4%
- **意义**：Si₃N₄（n≈2.0）在 DUV 透过性优于 TiO₂，但 FWHM 仍为宽带（~40nm）

### 3.4 超表面路线的可行性评估

**能否同时满足 T > 90% + FWHM < 2nm + OD > 4？**

**结论：理论上可行，但工程实现难度极大，当前无实验先例。**

具体分析：

1. **Q 因子需求**：FWHM = 2nm @ 222nm → Q ≈ 111；FWHM = 4nm → Q ≈ 56
   - 这些 Q 值在理论上完全可实现（GMR/QBIC 的 Q 可达 10⁴–10⁵）
   - 但在 DUV 波段，加工缺陷会使 Q 下降 1–2 个数量级

2. **透过率问题**：
   - GMR 滤波器天然是反射型（notch），要做透射型 bandpass 需要正交偏振器或异质结构
   - 正交偏振器方案：PCS 置于正交偏振片之间，利用 GMR 处 TE/TM 相位差产生透射峰
   - 透射峰 Tp 受限于偏振片效率（DUV 偏振片本身 T < 50%）
   - **替代方案**：利用 GMR 的反射峰做反射式滤波，可避免偏振片损耗

3. **截止带宽问题**：
   - 单一 GMR 超表面的截止带通常仅覆盖 ±50nm 范围
   - 实现 230–1100nm 全波段 OD > 4 需要结合多层膜截止滤光片
   - **混合方案**：超表面（提供窄通带）+ 宽带截止膜（提供 OD > 4）

4. **最关键的限制——加工**：
   - 222nm 工作波长 → 光栅周期 P ≈ 150nm
   - 特征尺寸 ~50–80nm，深宽比 3–8:1
   - 需要高分辨率 EBL（100 keV）+ 精密刻蚀
   - HfO₂ 刻蚀困难（化学稳定性极高），Damascene 工艺是唯一已验证路径
   - 大面积均匀性是量产瓶颈

## 四、两条路线对比

| 维度 | 多层介质膜 | 微纳结构/超表面 |
|------|-----------|----------------|
| **FWHM < 2nm** | ⚠️ 需要 30+ 层，Tp 大幅下降 | ✅ 理论上 Q 因子足够 |
| **T > 90%** | ⚠️ 222nm 处材料吸收是硬伤 | ⚠️ 透射型设计需要偏振片或复杂结构 |
| **OD > 4** | ✅ 多腔结构天然提供深截止 | ⚠️ 需要额外截止膜辅助 |

| **温度稳定性** | 好（硬镀膜） | 未知（DUV 超表面未验证） |

## 五、综合评估与建议

### 5.1 直接回答：目标指标能否实现？

| 指标组合 | 可行性 | 说明 |
|---------|--------|------|
| T > 90% + FWHM < 10nm + OD > 4 | ✅ 已有商业产品 | 万业成等已实现 Tp ~85%, FWHM 8–12nm |
| T > 80% + FWHM < 4nm + OD > 4 | ⚠️ 接近极限 | 需要优化材料 + 工艺，可能实现 |
| T > 90% + FWHM < 4nm + OD > 4 | ❌ **当前不可行** | T 与 FWHM 的权衡无法突破 |
| T > 90% + FWHM < 2nm + OD > 4 | ❌ **当前不可行** | 两个指标同时达到超出当前技术水平 |
| T > 70% + FWHM < 2nm + OD > 4 | ⚠️ 极限挑战 | 多层膜可能接近；超表面理论可行但无实验验证 |

### 5.2 推荐技术路线

#### 方案 A：多层膜优化（近期可行）

**目标**：T > 80%, FWHM < 4nm, OD > 4

1. **材料优化**：
   - 高 n 材料：HfO₂（IBS 沉积 + 500°C 退火，降低 222nm 吸收）
   - 替代考虑：AlN（Eg = 6.2eV，222nm 处 k 更小）或 Al₂O₃（Eg = 7.0eV，但 n 偏低）
   - 低 n 材料：SiO₂（n = 1.5，DUV 透明）
   - 纳米层状复合膜：HfO₂/SiO₂ 交替 nm 级层状结构，抑制结晶、降低吸收

2. **膜系设计**：
   - 三腔 F-P 结构：(HL)^n H 2L H (LH)^n L (HL)^n H 2L H (LH)^n L (HL)^n H 2L H (LH)^n
   - n = 4–5 对，总层数 ~30–40
   - 使用 OpenFilters / OptiLayer / TFCalc 进行全局优化
   - 实时光学监控（turning point method）补偿膜厚误差

3. **工艺**：
   - IBS（离子束溅射）沉积，超抛石英基底（RMS < 0.3nm）
   - 基板温度 100–150°C
   - 沉积后退火 500°C × 4h（空气中）

#### 方案 B：超表面 + 多层膜混合（中远期探索）

**目标**：利用超表面提供超窄通带，多层膜提供宽带截止

1. **超表面设计**：
   - 材料：HfO₂（ALD 沉积）或 AlN
   - 结构：1D 或 2D 亚波长光栅，周期 P ≈ 150nm
   - 机制：GMR 或 QBIC，目标 Q ≈ 100–200（FWHM 1–2nm）
   - 工作模式：反射式 GMR（避免偏振片损耗）或透射式正交偏振方案

2. **宽带截止膜**：
   - 在超表面基底背面镀制 HfO₂/SiO₂ 截止膜
   - 提供 230–1100nm OD > 4 的背景截止

3. **工艺挑战**：
   - EBL（100 keV）定义 ~80nm 特征
   - Damascene 工艺填充 HfO₂
   - 大面积均匀性控制

#### 方案 C：光子晶体异质结（理论探索）

**目标**：利用 1D 光子晶体异质结含缺陷结构

- 参考 TiO₂/SiO₂ 在 364.7nm 实现 Tp = 97.89%, FWHM = 0.47nm 的先例
- 将材料替换为 DUV 透明材料（HfO₂/SiO₂ 或 AlN/SiO₂）
- 结构：(PC₁)^m (PC₂)^n Defect (PC₂)^n (PC₁)^m
- **挑战**：层数可能达 50–100+，且 DUV 材料吸收会显著降低 Tp

| 文献 | 波长 | Tp | FWHM | 方法 | 与目标的关系 |
|------|------|-----|------|------|------------|

## 六、结论

**目标指标（T > 90% + FWHM < 2nm + OD > 4 @ 222nm）在当前技术水平下无法同时实现。**

核心瓶颈是 **222nm 处于可用高折射率材料的吸收边**，导致"窄带宽"与"高透过率"不可兼得。

**最务实的路径**：
1. **近期**：多层膜优化，目标 T > 80% + FWHM < 4nm + OD > 4（接近但未完全达标）
2. **中期**：超表面 GMR + 多层膜截止混合方案，目标 FWHM < 2nm（超表面提供窄带）+ T > 70%（超表面效率限制）+ OD > 4（多层膜提供）
3. **远期**：新型 DUV 材料（如宽禁带半导体 MgF₂-AlF₃ 复合、ALD AlN 纳米结构）突破吸收瓶颈

**如果应用场景允许折中**：
- 放宽 FWHM 到 8–10nm → 直接采购商业产品（Tp ~85%）
- 放宽 Tp 到 50–60% → 可尝试多层膜设计实现 FWHM < 2nm
- 放宽中心波长到 230–250nm → 材料吸收大幅降低，T > 90% + FWHM < 4nm 有望实现
