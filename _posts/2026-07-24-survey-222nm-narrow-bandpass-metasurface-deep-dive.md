# [专题调研] 222 nm 超窄带滤光片：超表面路线深度分析

> 补充调研日期：2026-07-24
> 背景：在上一份调研报告基础上，针对用户关注的"能否用超表面微纳结构替代多层膜"进行深度展开
> 目标指标：CWL=222nm, T>90%, OD>4, FWHM<2–4nm

---

## 一、超表面路线的核心优势

多层膜的根本困境是 **"层数越多 → 吸收累积越严重 → Tp 越低"** 的线性矛盾。超表面从原理上绕开了这一矛盾：

| 维度 | 多层膜的困境 | 超表面的潜在优势 |
|------|-------------|-----------------|
| **窄带机制** | 靠层数堆叠提高精细度 | 靠共振 Q 因子，与"层数"无关 |
| **材料吸收** | 30+ 层 HfO₂ 累积吸收 10–20% | 单层结构，光-物质交互路径短，吸收仅 1–3% |
| **厚度** | 总厚度 2–5 μm（30–60 层） | 单层结构 ~200–500 nm |
| **层数控制** | 需要逐层 ±0.1nm 精度监控 | 只需加工一套图案 |
| **角度容差** | 多腔 F-P 可设计低角度敏感 | GMR 对角度敏感，但 ZCG 结构可改善 |

**关键洞察**：超表面的 Q 因子取决于结构对称性控制，而非材料层数。理论上，一个 Q=200 的超表面即可实现 FWHM ≈ 1.1nm @222nm，且仅涉及一层材料，吸收损耗极小。

## 二、超表面窄带滤波的物理机制与设计路线

### 2.1 四种可选机制对比

| 机制 | 原理 | 典型 Q 值 | 透射/反射 | DUV 适用性 |
|------|------|----------|----------|-----------|
| **导模共振 (GMR)** | 光栅衍射级耦合进波导模式 | 10²–10⁴ | 反射型 notch（需转换） | ✅ 已有可见光 HfO₂ GMR 先例 |
| **准束缚态连续谱 (QBIC)** | 打破对称性使 BIC 变为可激发 | 10³–10⁵ | 反射型 notch | ⚠️ UV QBIC 已有报道，但非 222nm |
| **Mie 共振叠加 + BIC 透射峰** | 宽带消光谷中嵌套窄带透射峰 | 10²–10³ | **透射型 bandpass** ✅ | ⚠️ 仅在近红外/可见验证 |
| **Tamm 等离激元 (TPP)** | 金属/DBR 界面表面态 | 10²–10³ | 透射型 bandpass ✅ | ⚠️ 需金属 Al，DUV 损耗大 |

### 2.2 最有前途的方案：Mie 共振谷 + BIC 透射峰

**参考工作**：Zheng et al., "Planar narrow-band-pass filter based on Si resonant metasurface," arXiv:2012.10667 (2020)

该工作提出了一种巧妙的超表面带通设计思路：

```
原理：Si 纳米柱阵列
  → 电偶极子 (ED) + 磁偶极子 (MD) 共振叠加 → 宽带消光谷 (~200nm)
  → 部分打破 BIC → 窄带泄漏模式 → 消光谷中嵌入尖锐透射峰
  → 天然透射型 bandpass，无需偏振片
```

**移植到 222nm 的可行性分析**：

- **结构缩放**：Si 纳米柱 → HfO₂ 或 AlN 纳米柱，所有尺寸按 λ 比例缩放
- **材料替换**：Si 在 222nm 严重吸收（Eg=1.1eV），必须换为 HfO₂（Eg=5.7eV）或 AlN（Eg=6.2eV）
- **Q 因子需求**：FWHM=2nm @222nm → Q≈111，该机制实验已证明 Q≈10²–10³，完全足够
- **关键挑战**：DUV 波段 ED/MD 共振需要精确匹配，且 HfO₂ 的折射率对比度 (n≈2.1 vs SiO₂ n≈1.5) 低于 Si/air (n≈3.5 vs 1.0)，可能需要更大的深宽比

### 2.3 备选方案：1D 光子晶体平板 GMR

**参考工作**：
- Wang et al., "Guided-mode resonant HfO₂ grating at visible wavelength range," IEEE Photon. J. (2014) — HfO₂ GMR 已验证
- HfO₂ ZCG (Zero-Contrast Grating) 滤波器, Opt. Express 23(12), 15235 (2015) — HfO₂ 偏振无关 GMR 已验证

**设计思路**：
```
[基底: UV级熔石英] / [SiO₂ 间隔层] / [HfO₂ 亚波长光栅层] / [SiO₂ 覆盖层]

光栅参数：
  周期 P ≈ 150 nm (= λ/n_eff, 222nm 一阶衍射)
  占空比 f ≈ 0.5
  光栅厚度 tg ≈ 80–120 nm
  波导层厚度 tw ≈ 60–100 nm

→ TE 偏振入射 → 一阶衍射耦合进 HfO₂ 波导模式
→ 共振波长处反射率 → ~100%（notch）
→ 非共振波长透过率 > 95%
```

**从反射型 notch 到透射型 bandpass 的转换策略**：

| 策略 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| **正交偏振片** | GMR 处 TE/TM 相位差 π，正交偏振器间出现透射峰 | 简单 | DUV 偏振片 T<50%，Tp 严重受限 |
| **反射式使用** | 直接利用 GMR 反射峰 | 无偏振片损耗 | 系统需改为反射式光路 |
| **级联 GMR + 消光谷** | 两个 GMR notch 叠加，中间夹透射窗 | 透射型，无需偏振片 | 需要双层精确对准 |
| **Mie+BIC 复合** | 宽带消光谷 + 窄带 BIC 透射峰 | 单层透射型 | 设计复杂度最高 |

## 三、材料选择深度分析

### 3.1 DUV 超表面可用材料对比

| 材料 | n @222nm | k @222nm | Eg (eV) | 带隙波长 (nm) | 加工性 | 评价 |
|------|---------|---------|---------|-------------|--------|------|
| **HfO₂** | 2.0–2.1 | ~10⁻³ (近吸收边) | 5.7 | 217 | ✅ ALD + Damascene | **首选**：已验证 DUV 超表面，但 k 值非零 |
| **AlN** | 2.1–2.2 | ≈0 | 6.2 | 200 | ⚠️ 刻蚀困难 | **次选**：带隙更宽，但加工不如 HfO₂ 成熟 |
| **Si₃N₄** | 2.0–2.3 | ≈0 (λ>250nm) | 5.1 | 243 | ✅ PECVD/EBL | 222nm 处可能开始吸收 |
| **CaF₂** | 1.46 | 0 | 12.0 | 100 | ❌ n 太低 | 透明但折射率对比度不足 |
| **Al₂O₃** | 1.77 | ≈0 | 7.0 | 177 | ✅ ALD | n 偏低，GMR 精细度不足 |
| **Si** | 复数 | 严重吸收 | 1.1 | 1100 | ❌ 222nm 不透明 | 不可用 |

### 3.2 HfO₂ 的关键问题：222nm 处的 k 值

根据 Harvard 组 (Light: Sci. Appl. 2020) 的椭偏测量：
- HfO₂ 的带隙 Eg = 5.7 eV → 对应 λ_g = 217nm
- 在 220nm ≤ λ ≤ 380nm 范围：n > 2.1, k ≈ 0（**实测**）
- 在 222nm 处：k 确切值取决于 ALD 工艺（沉积温度、前驱体、退火条件）

**关键**：Harvard 的 HfO₂ 是 95°C 低温 ALD（TDMAH 前驱体），实测 k=0 延伸至 ~220nm。222nm 仅比带隙长 5nm，k 值应该极小但可能非零。

**AlN 的优势**：Eg=6.2eV → λ_g=200nm，222nm 远离吸收边，k 确切为 0。但 AlN 的刻蚀工艺不成熟（需要 Cr 硬掩膜 + ICP-RIE）。

### 3.3 推荐：HfO₂ 为主，AlN 为备选

**理由**：
1. HfO₂ 的 Damascene 加工流程已被 Harvard 验证至 266nm，向 222nm 下推仅需缩小尺寸
2. AlN 虽然光学性能更优，但加工难度更大——2023 年 VUT 硕士论文尝试 AlN 超表面加工，遇到"challenges thoroughly discussed"
3. 若 HfO₂ 在 222nm 的 k 值过大，可考虑 500°C 退火处理（同济大学 2025 年验证可降低紫外吸收）

## 四、加工工艺深度分析

### 4.1 HfO₂ DUV 超表面——Damascene 工艺流程

基于 Harvard (Light: Sci. Appl. 2020) 的已验证流程：

```
Step 1: 基底准备
  → UV 级熔石英晶圆 (500μm, 双面抛光)
  → HMDS 蒸气涂层 (150°C, 增加附着)

Step 2: 光刻胶涂布
  → ZEP 520A 旋涂 → 180°C 烘烤 10min
  → 厚度 400–550nm (根据设计调整)
  → 蒸镀 20nm Al 层 (抑制 EBL 充电)

Step 3: 电子束光刻 (EBL)
  → 100 keV 加速电压, 0.2 nA 束流
  → 对 222nm 工作波长: 需要周期 P≈150nm, 特征尺寸~50-80nm
  → 100 keV 电子穿透深、散射小 → 适合高深宽比纳米结构

Step 4: 显影
  → Al 层去除 (AZ 400K 1:3, 2min)
  → 光刻胶显影 (hexyl acetate 2min + IPA 30s)
  → 得到 ZEP 模板

Step 5: HfO₂ ALD 填充
  → 低温 ALD: TDMAH + H₂O, 95°C
  → 沉积速率 0.11 nm/cycle
  → 沉积至 200nm 厚（完全填充 + 过涂）

Step 6: 回刻
  → Ar 离子铣削 (HfO₂ 铣削率 ~0.4 nm/s)
  → 回刻至光刻胶顶面 → 准平面化

Step 7: 去胶
  → 溶剂浸泡去除 ZEP
  → 得到 HfO₂ 纳米柱 (高度 400–550nm, 深宽比 3–11)
```

### 4.2 222nm 的尺寸需求 vs 已验证能力

| 参数 | 已验证 (266nm) | 222nm 目标 | 可行性 |
|------|---------------|-----------|--------|
| 光栅周期 P | ~250nm (266nm 超透镜) | ~150nm | ⚠️ 缩小 40%，EBL 仍可行 |
| 最小特征尺寸 | ~50nm | ~50–80nm | ✅ 相当 |
| 纳米柱高度 | 480nm (266nm 全息) | ~300–400nm | ✅ 深宽比 ~4–8 |
| 深宽比 | 3–11 | 4–8 | ✅ 在已验证范围内 |
| 侧壁粗糙度 | ~2nm (ZEP 模板工艺) | <2nm (目标) | ⚠️ 粗糙度对 Q 影响大 |

**判断**：从 266nm 下推到 222nm，尺寸缩小约 17%，在 EBL 100keV 系统的分辨能力范围内。关键瓶颈不是光刻分辨率，而是 **DUV 波段对侧壁粗糙度的极端敏感性**——222nm 波长下，2nm RMS 粗糙度产生的散射损耗可能使 Q 下降一个数量级。

### 4.3 AlN 加工的替代路径

若 HfO₂ 的 k 值在 222nm 不可接受，AlN 是唯一替代：

```
AlN 加工流程 (基于 NYCU/东京大学 Nano Lett. 2025):
  → AlN 薄膜沉积 (溅射或 MBE, ~380nm)
  → Cr 硬掩膜沉积 + 光刻
  → ICP-RIE 刻蚀 (Cl₂/BCl₃ 化学刻蚀)
  → 去 Cr 掩膜
```

**AlN 加工的主要挑战**（VUT 2023 硕士论文总结）：
- AlN 化学稳定性高，刻蚀速率慢
- Cr 硬掩膜需要的光刻步骤比 HfO₂ 的 Damascene 更多
- 刻蚀选择比有限，难以获得高深宽比结构
- 侧壁质量不如 Damascene 工艺的 HfO₂

## 五、超表面 + 多层膜混合架构——推荐方案

### 5.1 整体架构

```
入射光 ↓
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  [超表面层]  ← 提供窄通带 (FWHM 1–4nm)
   HfO₂ 纳米柱阵列 (~300nm 高)
   周期 ~150nm, 在 UV 级熔石英基底上
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  [SiO₂ 间隔层]  ← 光学隔离 (~200nm)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  [多层截止膜]  ← 提供宽带 OD>4 (230–1100nm)
   HfO₂/SiO₂ 截止膜 (~15–20 层)
   在熔石英基底背面
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  ↓ 222nm 窄带通输出
```

### 5.2 超表面层的两种设计选项

#### 选项 A：GMR 反射式 + 吸收背景

```
结构: Substrate / SiO₂ / HfO₂ 光栅 / 空气
模式: 反射式 GMR
  → 222nm 处反射率 ~100% (共振峰)
  → 非共振波长透过
  → 需要在反射光路中使用
  
问题: 天然是反射型 notch → bandpass 需要反向思考
解决: 在反射方向收集 222nm 光 = 反射式 bandpass
     其他波长透过被吸收层吸收
```

#### 选项 B：Mie 消光谷 + BIC 透射峰（推荐）

```
结构: Substrate / HfO₂ 纳米柱阵列 / 空气
模式: 透射式 bandpass
  → ED + MD 共振叠加 → 200–260nm 宽带消光 (T<5%)
  → 消光谷中嵌套 BIC 泄漏模式 → 222nm 窄带透射峰
  → Tp 取决于 HfO₂ 吸收 + 散射损耗
  
关键参数:
  纳米柱直径 D ≈ 80–100nm
  纳米柱高度 H ≈ 300–400nm
  周期 P ≈ 150nm
  非对称参数 α ≈ 0.05–0.1 (控制 Q 因子)
  
预期性能 (仿真):
  FWHM ≈ 1–3nm (Q ≈ 70–220)
  Tp ≈ 60–85% (取决于 HfO₂ 的 k 值和侧壁粗糙度)
  消光谷深度: T<5% (200–260nm)
```

### 5.3 OD > 4 的实现

**超表面本身无法提供 230–1100nm 全波段 OD > 4**。消光谷宽度受限于 Mie 共振带宽，通常仅 ~60nm。

**解决方案**：在基底背面镀制 HfO₂/SiO₂ 截止膜系
- 短波截止 (< 222nm)：HfO₂ 本身在 < 217nm 开始吸收，天然截止
- 长波截止 (> 230nm)：15–20 层 HfO₂/SiO₂ 长波通截止膜 (long-pass cut-off)
  - 这个层数远少于纯多层膜方案需要的 30–40 层
  - 因为只需要提供 OD > 4 的背景截止，不需要提供窄带
  - 222nm 附近透过率不受截止膜影响（处于通带内）

## 六、可行性综合评估

### 6.1 超表面路线能否达到目标指标？

| 指标 | 超表面理论极限 | DUV 工程现实 | 达标概率 |
|------|-------------|-------------|---------|
| CWL = 222nm | ✅ 尺寸缩放 | ✅ EBL 可加工 | 高 |
| FWHM < 4nm | ✅ Q > 56 容易 | ⚠️ 粗糙度使 Q 降至 ~100 | **中高** |
| FWHM < 2nm | ✅ Q > 111 可行 | ⚠️ 粗糙度使 Q 降至 ~100 | **中等** |
| T > 90% | ⚠️ 理论 T>95% | ⚠️ 散射 + 吸收 → 70–85% | **低** |
| T > 70% | ✅ 可实现 | ✅ 单层损耗小 | **高** |
| OD > 4 | ✅ 混合方案 | ✅ 多层膜辅助 | **高** |

### 6.2 超表面 vs 多层膜——更新对比

| 维度 | 多层介质膜 | 超表面（Mie+BIC 透射型） |
|------|-----------|------------------------|
| FWHM < 2nm | ❌ 需要 30+ 层，Tp < 50% | ✅ Q 因子足够，单层即可 |
| FWHM < 4nm | ⚠️ 需要 ~20 层，Tp ~80% | ✅ 容易实现 |
| T > 90% | ❌ 222nm 吸收硬伤 | ⚠️ 理论可达 85%，散射是变数 |
| T > 70% | ⚠️ 可争取 | ✅ 单层损耗小 |
| OD > 4 (全波段) | ✅ 多腔天然提供 | ⚠️ 需要混合多层膜 |
| 加工难度 | ✅ IBS 成熟 | ❌ EBL + ALD + 离子铣 |
| 量产可行性 | ✅ 晶圆级 | ❌ EBL 写场面积有限 |
| 设计自由度 | 低（材料组合有限） | 高（几何参数丰富） |
| AI 逆设计适用性 | 中等 | ✅ 高（RL+RCWA 已验证 DUV） |
| 角度敏感性 | 中等 | ⚠️ 高（ZCG 结构可改善） |
| 温度稳定性 | 好 | 未验证 |

### 6.3 关键判断

**超表面路线相比多层膜的核心优势在于 FWHM 与 T 的解耦**：
- 多层膜：收窄 FWHM 必须增加层数 → 吸收累积 → Tp 下降
- 超表面：收窄 FWHM 只需调节非对称参数 → Q 因子升高 → Tp 不受直接影响

**但超表面路线的核心劣势是加工成熟度和 Tp 的不确定性**：
- DUV 超表面无滤波实验先例（仅有透镜/全息验证）
- 侧壁粗糙度对 222nm 波段的 Q 和 T 影响是未知数
- 大面积 EBL 写场对均匀性的限制

## 七、推荐技术路线

### 阶段一：仿真验证（0–6 个月）

1. **材料参数标定**
   - 用椭偏仪实测 ALD 沉积 HfO₂ 薄膜在 200–300nm 的 n/k 值
   - 对比 95°C (TDMAH) vs 200°C (TDMAH) vs 退火后 (500°C) 的色散曲线
   - 若 222nm 处 k < 10⁻⁴ → HfO₂ 可用；否则转向 AlN

2. **FDTD 仿真**
   - 建立 HfO₂ 纳米柱阵列模型 (P≈150nm, D≈80nm, H≈350nm)
   - 优化 ED/MD 共振匹配，使消光谷覆盖 210–260nm
   - 引入非对称参数 α，扫描 BIC→QBIC 转化
   - 目标：消光谷中 222nm 透射峰 FWHM < 2nm, T > 85%（理想无损耗）

3. **容差分析**
   - 模拟侧壁粗糙度 (0–5nm RMS) 对 Q 和 Tp 的影响
   - 模拟 EBL 线宽误差 (±5nm) 对共振波长的偏移
   - 模拟角度偏转 (0–10°) 对滤波性能的影响

### 阶段二：加工验证（6–18 个月）

1. **工艺开发**
   - 在 UV 级熔石英基底上实现 HfO₂ Damascene 工艺
   - 先在 266nm 验证（已有 Harvard 先例），再下推到 222nm
   - SEM 表征：侧壁垂直度、粗糙度、均匀性

2. **光学测试**
   - DUV 光谱仪测量透过率 (200–400nm)
   - 验证消光谷 + 透射峰是否出现
   - 测量 FWHM 和 Tp，与仿真对比

3. **多层截止膜**
   - 在基底背面镀制 HfO₂/SiO₂ 截止膜
   - 验证 230–1100nm OD > 4

### 阶段三：性能优化（18–36 个月）

1. **AI 逆设计**
   - 参考 RL+RCWA 方法 (ScienceDirect 2025) 优化 DUV 超表面
   - 使用 Tandem NN 或扩散模型逆向设计结构参数
   - 在目标函数中嵌入制造容差

2. **退火优化**
   - 对加工后的 HfO₂ 超表面进行 500°C 退火
   - 验证退火对 k 值和 Tp 的改善

3. **角度补偿设计**
   - 采用 ZCG (Zero-Contrast Grating) 结构降低角度敏感性
   - 或采用 2D 光栅实现偏振无关

## 九、结论

**超表面路线是实现 222nm 超窄带滤光的可行且有吸引力的替代方案，核心优势在于 FWHM 与 Tp 的解耦。**

1. **FWHM < 2–4nm**：超表面可轻松实现 Q > 100，理论上 FWHM < 2nm 不成问题
2. **Tp > 90%**：这是最大不确定项——单层 HfO₂ 的吸收远低于 30+ 层多层膜，但侧壁散射是未知数。保守估计 Tp ≈ 70–85%，乐观估计可达 85–90%
3. **OD > 4**：通过"超表面（窄通带）+ 多层膜截止膜（宽带 OD）"混合方案实现，且多层膜仅需 ~15 层（远少于纯多层膜方案的 30–40 层）
4. **最大风险**：DUV 超表面无滤波实验先例，加工-性能关系需要从零建立
5. **最大机遇**：若成功，将首次实现 222nm 处 FWHM < 2nm 且 T > 70% 的窄带滤光片，突破多层膜的 T-FWHM 物理极限

**推荐策略**：先做 FDTD 仿真评估 Tp 上限（关键是 HfO₂ 在 222nm 的 k 值和侧壁粗糙度模型），再决定是否投入加工。
