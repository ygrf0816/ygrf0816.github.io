## 域适应方法深入讲解

> 针对论文中涉及的域适应核心概念进行深入浅出的梳理，适合有深度学习基础但不熟悉域适应方法的读者。

---

### A.1 什么是域适应（Domain Adaptation）？为什么需要它？

![image-20260523111043750](/assets/posts_figs/2026-05-23-paper-ML-Consistency-Constrained-Domain-Adaptation/image-20260523111043750.png)

你在一个领域（比如红外波段圆柱结构）花了很大功夫训练了一个超表面逆设计模型，学到的映射关系是 **结构 A → 光谱 A'**。现在你要换到新任务（比如太赫兹波段 H 形结构），模型碰到的全是新花样——材料变了、形状变了、频率差了 60 倍——它当然就懵了。

**域适应（Domain Adaptation）** 就是解决这个问题的一张牌：能不能让源域学到的“通用知识”迁移到目标域，而不是重头来过？其中被研究得最多的一类叫 **UDA（Unsupervised Domain Adaptation，无监督域适应）**——目标域连标签（光谱对应的正确结构参数）都没有，你只能靠对齐两个域的“特征分布”来适配。

**核心类比**：就像你学会了开燃油车（源域），现在要开电动汽车（目标域）。两者有共性（方向盘、刹车、交通规则），也有差异（油门响应、能量回收、充电 vs 加油）。一个优秀的“域适应”就是让你利用已有的驾驶知识快速上手电车，而不需要重新去驾校。

**三种域适应问题：**

#### **1. 协变量偏移——输入分布变了**

![image-20260523111457315](/assets/posts_figs/2026-05-23-paper-ML-Consistency-Constrained-Domain-Adaptation/image-20260523111457315.png)

标注规则没变，只是观测到的内容不同了。典型例子包括：

- 用 2020 年邮件训练的垃圾邮件过滤器部署到 2026 年：话题变了，但“什么是垃圾邮件”的定义没变。
- 在西门子 CT 扫描仪上训练的模型用于 GE 扫描仪的数据：成像特性不同，但放射科医生的判读标准一致。

![image-20260523111510521](/assets/posts_figs/2026-05-23-paper-ML-Consistency-Constrained-Domain-Adaptation/image-20260523111510521.png)

高维空间中直接估计概率密度几乎不可能，因此实践中通常直接估计密度比——比如用 KLIEP、uLSIF，或训练一个二分类器区分源域和目标域样本；此时，该分类器的贝叶斯最优输出本身就隐含了密度比。

### A.2 DANN——用对抗训练欺骗域分类器

![DANN 架构与梯度反转层](/assets/posts_figs/2026-05-23-paper-ML-Consistency-Constrained-Domain-Adaptation/fig2_dann_architecture.png)

**域对抗神经网络**（Domain-Adversarial Neural Network, DANN）由 **Ganin et al. (2016)** 提出，核心是一个**三方博弈**：

- **特征提取器 $G_f$**：把输入（无论来自源域还是目标域）映射到一个共享的潜在特征空间 $z$
- **标签预测器 $G_y$**：从 $z$ 预测任务标签（比如结构参数），用有标签的源域样本正常训练
- **域分类器$G_d$**：从 $z$ 判断“这个特征向量来自源域还是目标域”

关键机关在 **梯度反转层（Gradient Reversal Layer, GRL）**：

> **正向传播**：GRL 像个透明玻璃，数据直接穿过 → $D$ 照常分类  
> **反向传播**：梯度乘以 $-\lambda$（负数！） → $G_f$ 收到的梯度是“反方向”的

这意味着：$D$ 越擅长区分源/目标域，$G_f$ 却被逼着往反方向走——**把源域和目标域的特征混得越难分辨越好**。

**DANN 的对抗逻辑本质**：

![image-20260523112116272](/assets/posts_figs/2026-05-23-paper-ML-Consistency-Constrained-Domain-Adaptation/image-20260523112116272.png)

G_f 的目标：让 D 无法分辨特征来自哪个域（产生域不变特征）
G_d 的目标：  尽可能准确区分特征来自源域还是目标域

GRL 使得两个目标可以在一次反向传播中同时优化

训练达到均衡时，$G_f$ 产出的特征 $z$ 就是**域不变（domain-invariant）**的——既包含任务信息，又不带域标签。这就是 DANN 做域适应的本质。

**GRL 的数学形式**：

$$\text{GRL}(x) = x \quad \text{(forward)}$$
$$\frac{\partial \text{GRL}}{\partial x} = -\lambda \cdot I \quad \text{(backward)}$$

其中 $\lambda$ 是控制对抗强度的超参数（本论文中 $\lambda_{max}=0.12$），通常从 0 逐步增长到最大值，避免训练初期梯度破坏性太强。

![DANN 前后：域分布合并，类别仍可分。](/assets/posts_figs/2026-05-23-paper-ML-Consistency-Constrained-Domain-Adaptation/fig03_tsne_dann.png)

### A.3 MMD——直接匹配两个分布之间的距离

![最大均值差异：核均值嵌入](/assets/posts_figs/2026-05-23-paper-ML-Consistency-Constrained-Domain-Adaptation/fig3_mmd_kernel.png)

最大均值差异（Maximum Mean Discrepancy, MMD；Gretton 等，2012）：不需要域分类器，直接把两个域的特征分别**映射到再生核希尔伯特空间（RKHS）**，然后计算两个**分布均值之间的 L2 距离**。

**MMD 的核心公式**：

$$\text{MMD}^2(\mathcal{S}, \mathcal{T}) = \left\| \frac{1}{n_s}\sum_{i=1}^{n_s}\phi(z_i^s) - \frac{1}{n_t}\sum_{j=1}^{n_t}\phi(z_j^t) \right\|_{\mathcal{H}}^2$$

其中 $\phi(\cdot)$ 是核映射函数，$\mathcal{H}$ 是 RKHS。展开后可以用**核技巧**计算：

$$\text{MMD}^2 = \frac{1}{n_s^2}\sum_{i,j}k(z_i^s, z_j^s) + \frac{1}{n_t^2}\sum_{i,j}k(z_i^t, z_j^t) - \frac{2}{n_s n_t}\sum_{i,j}k(z_i^s, z_j^t)$$

论文用的 MMD 是**多尺度 Lorenz RBF 核**的版本（5 个核），相当于从 5 个不同分辨率同时看两个分布的差异，对多尺度的分布差异更敏感。

**DANN vs MMD 对比小结**：

|                  | DANN                       | MMD                  |
| ---------------- | -------------------------- | -------------------- |
| **对齐方式**     | 对抗博弈，动态博弈         | 统计量，静态计算     |
| **需要额外网络** | 域分类器 D                 | 不需要               |
| **优点**         | 灵活，自适应强             | 理论有保证，训练稳定 |
| **缺点**         | 训练不稳定（min-max 博弈） | 核选择敏感           |
| **梯度流**       | 通过 GRL 反转梯度          | 直接计算核距离的梯度 |

### A.4 伪解陷阱（Pseudo-Solution Trap）——为什么标准 UDA 会失效？

![image-20260523135143837](/assets/posts_figs/2026-05-23-paper-ML-Consistency-Constrained-Domain-Adaptation/image-20260523135143837.png)

现在理解了 DANN 和 MMD 怎么对齐特征分布。但原文揭示了一个**致命缺陷**，这也是整篇论文最核心的内容

**定量证据（Target1 上的实验结果）**：

> 标准 DANN 让**参数损失**从 0.1339 降到 0.0920（表面上看特征对齐“成功了”），但**光谱重构损失**从 0.0872 飙升到 0.2865

**这背后发生了什么？**

DANN 的域分类器说：“源域和目标域的特征已经混在一起了，分不清了”——但这只是**统计意义上的对齐**。INN 输出的结构参数在特征空间中“看起来像”目标域的合法样本，但用全波仿真跑一遍就会发现——**光谱完全对不上**。

**根本原因**：特征对齐的优化目标是“让域分类器分不清”，而非“让输出参数对应的光谱正确”。这两个目标在标准 UDA 框架下是**解耦**的——特征统计量对齐了，但光谱重构质量没人管。

通俗来说就是UDA进行的特征分布迁移是一种统计学意义上的，大概分布是对上了，但是单放到个体上误差很大，而且对于超表面光学响应这种对精度特别敏感的就不太行。

**类比理解**：

- DANN 像一位翻译官，目标是让听者分不出说话人的“口音”（哪个域来的）
- 翻译正确的内容：“apple → 苹果” ✅
- 但翻译官可能为了掩盖口音而篡改了内容：“apple → 香蕉” ❌
- 口音确实听不出来了（特征对齐成功），但意思都错了（光谱重构失败）

这就是伪解陷阱的本质：**统计对齐 ≠ 物理保真**。

# 如下是论文正文内容

## 一、研究背景与核心问题

### 1.1 研究背景

超表面（Metasurfaces）是一种由亚波长结构单元组成的人工材料，能够精确调控光场的相位、振幅和偏振，广泛应用于微纳光学、智能器件、先进传感和光谱成像等领域。其逆设计（inverse design）——即从目标光学响应反推结构参数——是一个典型的复杂逆问题，难点在于：

- 光学响应与高维结构参数之间存在**高度非线性映射**；
- 解空间普遍存在**非唯一性**（多个不同结构可能产生相似的光学响应）。

深度学习为这一问题提供了有力工具，主要分为**正向建模**（结构→光谱）和**逆设计**（光谱→结构）两种范式。串联学习（tandem-learning）架构通过耦合逆网络和预训练的正向模型来缓解一对多映射问题。

### 1.2 核心研究问题：域偏移 (Domain Shift) 下的数据高效逆设计

传统深度学习方法基于一个隐含假设：**训练数据和目标应用共享相似的结构-响应分布**。然而，当材料属性、结构拓扑、制备条件或工作频率发生变化时，这一假设不再成立，形成"域偏移"（domain shift）。

**域偏移的典型案例**：

- 训练于可见光波段硅基超透镜的网络，直接应用于新材料体系或太赫兹波段时预测性能大幅下降；
- 更复杂的超原子拓扑或纳米制备过程引入的系统几何偏差也会导致域偏移。

**针对每个新设计场景从头收集大规模数据集并重新训练模型，计算成本过高**，无法体现深度学习的效率优势。现有的迁移学习方案主要有两个方向：

1. **扩大设计空间、增强数据多样性**（如像素化编码），但训练数据集构建极其耗时；
2. **迁移学习/域适应**——通过少量数据将源域知识迁移到目标域，更务实高效。但现有超表面迁移学习研究**大多是有监督的**（需要目标域标记样本进行微调），对**完全无标记目标域条件下的跨域逆设计**研究不足。

## 二、论文创新点

### 2.1 核心贡献（三项）

**创新点 1：提出"伪解陷阱"（Pseudo-Solution Trap）概念**

- 标准无监督域适应（UDA）方法（如 DANN、MMD）通过对齐源域和目标域的潜在特征分布实现知识迁移；
- 但在物理逆问题中，**特征对齐成功不等于光谱重构有效**：UDA 可能在统计意义上对齐了特征空间，而输出的结构参数对应的响应仍偏离目标——这就是"伪解陷阱"；
- 论文从定量角度验证了这一失效模式：在 Target Domain 1，标准 DANN 虽然参数损失下降（0.1339→0.0920），但光谱重构损失反而恶化（0.0872→0.2865），即域对齐*牺牲*了响应级保真度。

**创新点 2：提出一致性约束域适应框架（Consistency-Constrained Domain Adaptation）**

- 核心思想：利用校准后的正向代理模型（calibrated forward surrogate，PNN）在域适应过程中施加**前向一致性约束**（forward-consistency constraint）；
- 具体方法：少量有标记目标域样本用于校准正向代理模型，校准后的 PNN 对大量无标记目标域数据上的逆网络输出进行光谱重构，通过**循环一致性损失（cycle consistency loss）** 规约逆网络预测，确保预测的结构参数对应的物理响应与目标光谱一致。

**创新点 3：提出两种一致性增强的 UDA 变体**

- **PC-DANN**（Physics-Constrained DANN）：在标准 DANN 的对抗域对齐基础上，增加 PNN 前向一致性约束；
- **PC-MMD**（Physics-Constrained MMD）：在标准 MMD 的统计分布对齐基础上，增加 PNN 前向一致性约束。

## 四、研究方法与框架

### 4.1 整体架构

论文的完整框架包含三个核心模块，整体还是个串联网络结构，只是在前向预测网络层面采用了域适应方法，用少量对应target数据来微调在另一种结构的大量数据库训练得到的PNN：

```
目标光谱 s_target → [逆网络 INN] → 预测结构参数 p̂ → [正向代理 PNN] → 重构光谱 ŝ
```

### 4.2 正向预测神经网络（PNN, Forward Prediction Neural Network）

![image-20260523142922784](/assets/posts_figs/2026-05-23-paper-ML-Consistency-Constrained-Domain-Adaptation/image-20260523142922784.png)

​		  **前向预测网络，针对已有开放数据集的圆柱形超表面进行训练并预测，具有较好的预测精度** (c) Comparison of the predicted spectra (red) with the full-wave simulation ground truths (blue) for  multiple test samples in the source domain. The results show excellent agreement in the real/imaginary parts, amplitude, and phase, validating the  model’s effectiveness in high-fidelity forward modeling. 

**架构**：基于改进残差网络（modified ResNet）的全连接神经网络

- 输入嵌入层（input embedding layer）
- 2 个改进残差块（modified residual blocks），包含 **LayerNorm + GELU + Dropout**
- 共享特征层（shared feature layer）
- 输出头（output head）：分别预测实部和虚部

**输入参数**：归一化的结构参数（6维），包括：
- 介电常数 ε（dielectric constant）
- 间隙 gap
- 厚度 thickness
- 半径 radius
- 以及其他几何参数

**输出参数**：**31 个离散频率点**上的复电磁响应光谱（实部 + 虚部，共 62 维向量）

**损失函数**：复域 MSE
$$L_{MSE} = \frac{1}{N}\sum_{i=1}^{N} \left[(\text{Re}(\hat{s}_i) - \text{Re}(s_i))^2 + (\text{Im}(\hat{s}_i) - \text{Im}(s_i))^2\right]$$

**训练配置**：Adam 优化器，batch size = 64，初始学习率 1e-4，训练 150 epochs

### 4.4 逆神经网络（INN, Inverse Neural Network）

前向网络PNN迁移学习完，确保精度后，到了反向INN网络部分

**(a)****架构**：与 PNN 类似的改良Residental Network，反向设计实现是传统的端对端网络（串联神经网络）反向设计

- **输入**：62 维复光谱向量（31 个频率点的实部+虚部）
- **输出**：6 维归一化结构参数（Sigmoid 输出激活）

**损失函数（监督训练）**：
$$L_{total} = \alpha L_{param} + \beta L_{spec}$$

其中：
- $L_{param}$：参数预测 MSE 损失
- $L_{spec}$：光谱重构损失（通过固定权重的 PNN 计算）
- 权重：$\alpha = 1.0$, $\beta = 0.5$

**(b)**这样的网络反演时有的参数具有较好的反演精度

**(c)**但是也有预测精度较差，表现不好的结果，**作者认为模型陷入了“pseudo-solution trap”伪解陷阱。**

### 3.4 域适应模块

针对pseudo-solution trap的问题，作者引入了改进的域适应方法（Domain shifting Method）来进行优化。优化的对象主要是反向设计网络INN部分，PNN由于其精度高，保留作为物理验证器，不进行优化和参数更新。

![image-20260529171115012](/assets/posts_figs/2026-05-23-paper-ML-Consistency-Constrained-Domain-Adaptation/image-20260529171115012.png)

#### 3.4.1 标准 DANN
- 使用**梯度反转层**（Gradient Reversal Layer, GRL），$\lambda_{max} = 0.12$
- 域分类器 D 判别特征来自源域还是目标域

#### 3.4.2 标准 MMD
- 使用**多尺度 Lorenz RBF 核**（kernel num = 5）
- 最小化源域和目标域特征分布间的最大均值差异

#### 3.4.3 一致性约束增强版（PC-DANN / PC-MMD）

**复合损失函数**：
$$L_{composite} = \alpha L_{sup} + \beta L_{cycle} + \gamma L_{domain}$$

- $L_{sup}$：有监督参数损失（仅在少量标记目标域样本上）
- $L_{cycle}$：循环一致性损失——利用校准后的 PNN 对预测参数进行光谱重构，计算与目标光谱的偏差
- $L_{domain}$：域对齐损失（DANN 的对抗损失或 MMD 的分布差异）

训练 50-80 epochs，同时使用有标记 + 无标记目标域数据。

简单的来说，就是多了循环一致性损失$L_{cycle}$这一项，传统的DANN或者MMD方法都是在做统计学意义上的对齐；这里加上循环一致性损失，是进一步物理限制它的数值精度一致，来消除多解性以及物理不确定的问题。

### A.5 一致性约束域适应框架（PC-DA）详解

#### A.5.1 三个关键角色

**角色 ① INN（逆神经网络）= $G_f$ + $G_p$**

- $G_f$（特征提取器）：将输入光谱映射到潜在特征 $z$
- $G_p$（参数预测器）：从 $z$ 预测 6 维结构参数 $\hat{p}$
- 它的参数在训练中被优化（是学习的主体）

**角色 ② PNN（正向代理模型）= 校准后固定权重**

- 输入 $\hat{p}$（结构参数），输出 $\hat{s}$（重构光谱）
- **重点：PNN 的权重在域适应阶段是冻结的（frozen）**，只充当一个“可微的物理验证器”
- 因为 PNN 是神经网络，所以梯度可以穿过它回传到 INN
- PNN 必须先在目标域上校准（calibration），否则验证本身就不可靠

**角色 ③ 域分类器 D（仅 PC-DANN）/ MMD 核（仅 PC-MMD）**

- 负责度量源域和目标域特征之间的分布差异
- 产生 $L_{domain}$ 损失
- 这部分和标准 UDA 完全一样，复用成熟的域对齐机制

#### A.5.2 循环一致性损失（$L_{cycle}$）——前向一致性约束的具体实现

这是论文最精妙的设计：

> **目标光谱 → INN → 预测参数 → PNN → 重构光谱 → 和原目标光谱比 MSE**

$$L_{cycle} = \text{MSE}(\hat{s}, \; s_{target})$$

**为什么叫“循环”？** 因为数据走了一个闭环（spectrum → parameters → spectrum），最后回到起点。如果 INN 预测的结构参数是物理合理的，那么 PNN 重构的光谱必须接近原始输入光谱。如果不是——说明 INN 输出的参数在物理上站不住脚，梯度会被回传惩罚它。

**关键性质**：

- $L_{cycle}$ **不需要目标域的标签**（不需要知道正确的结构参数是什么），只需要输入光谱本身
- 这意味着可以利用**大量无标签目标域数据**来改善域适应质量
- 梯度流：$L_{cycle}$ → PNN（冻结，梯度穿透）→ $\hat{p}$ → $G_p$ → $G_f$

#### A.5.3 三项联合损失的协同机制

$$L_{composite} = \alpha \cdot L_{sup} + \beta \cdot L_{cycle} + \gamma \cdot L_{domain}$$

| 损失项       | 含义                                                        | 需要标签？ | 作用           |
| ------------ | ----------------------------------------------------------- | :--------: | -------------- |
| $L_{sup}$    | 在少量**有标签**目标域样本上计算参数预测 MSE                |   ✅ 需要   | 保证参数级精度 |
| $L_{cycle}$  | 在**所有**目标域样本（含无标签）上通过 PNN 计算重构光谱误差 |  ❌ 不需要  | 物理一致性约束 |
| $L_{domain}$ | 通过 DANN/MMD 对齐源域和目标域的特征分布                    |  ❌ 不需要  | 域不变特征学习 |

**三项损失的分工**：

- $L_{sup}$：负责“锚定”——少量有标签样本确保参数预测不偏离太远
- $L_{cycle}$：负责“物理验证”——输出参数在物理上要说得通（PCA 的核心创新）
- $L_{domain}$：负责“特征迁移”——让目标域特征和源域在一个空间里（复用已有知识）

#### A.5.4 完整训练流程

| 步骤 | 操作                                                         |            使用的数据            |
| :--: | ------------------------------------------------------------ | :------------------------------: |
|  1   | **源域预训练 INN**：用源域的大量标记数据训练 INN（$\alpha L_{param} + \beta L_{spec}$） |        源域大量有标签数据        |
|  2   | **PNN 跨域校准**：用极少目标域标记样本微调 PNN（Strategy 3，13.8% 参数），使其在目标域预测准确 | 目标域少量有标签数据（~20 样本） |
|  3   | **冻结 PNN 权重**                                            |                —                 |
|  4   | **域适应联合训练**：用复合损失 $L_{composite}$ 同时优化 $G_f$ 和 $G_p$，利用所有无标签目标域数据 |  源域 + 目标域（含大量无标签）   |
|  5   | **推断**：目标光谱 → 训练好的 INN → 结构参数（直接用，不需要 PNN） |            仅目标光谱            |

**为什么第 5 步推断时不需要 PNN？** PNN 只是训练时的“教练”（物理验证器），训练完成后 INN 已经学会了在目标域预测物理合理的结构参数，推断时直接用 INN 即可。

#### A.5.5 直观类比

把 UDA 想象成让两个不同语言的人（源域和目标域）学会“用同一种方式表达意思”（特征对齐）。

- **标准 DANN/MMD**：只检查两个人是不是在说“同一种语言”（域分类器分不清了 = 语言对齐了），但不管他们说的是不是真话
- **PC-DA**：在检查语言对齐的同时，还拿一个**物理辞典（PNN）**来验：“你说出的话翻译回去（循环重构），意思还和原来一样吗？”——不一样就扣分

这就是前向一致性约束的本质：**拿物理来验证统计对齐的质量**。

#### A.5.6 两个疑问

> 1. PNN 也是用源域数据训练的，在目标域不一定准，那 $L_{cycle}$ 不是会误导吗？

正是这个顾虑，所以论文**先用少量目标域标记样本校准 PNN**（步骤 2），确保它在目标域的预测精度足够（论文实验显示校准后 MSE 从约 0.55 降到约 0.20）。但论文也坦率承认：当目标域有全新的几何特征（如 Target1 的 H 形结构），PNN 的校正能力有限，PC-DA 的改善也就打折扣——这恰恰解释了为什么 Target2（仅材料/频率变化）的效果远好于 Target1（拓扑变化）。

**这一局限性的启示**：PC-DA 的核心假设是“校准后的 PNN 在目标域足够准确”。如果域偏移涉及全新物理机制或几何拓扑，PNN 本身在目标域就难以做到高精度代理，那么一致性约束的效果自然受限。这一分析框架对其他物理逆设计任务具有普遍参考价值。

2. 这个域迁移技术，能做到那种层面上的迁移学习？例如这篇论文中是对两个不同的目标域分别作迁移，一个是H结构的不同拓扑结构，另一个是同拓扑结构但是介电常数范围不同，那这个方法是否对于网络结构完全不同的模型不适用？例如我现在需要修改输入的参数，把他从四个参数增加到六个，或者更改输出参数光谱范围和参数点，这是否就不适用了？

答案：**是的。域迁移技术只适用于同网络架构**，同输入输出参数维度或者结构的网络进行迁移。修改网络结构导致权重数值维度完全不一致，导致原本domain的预训练权重根本无法迁移到目标域。此时只能用传统迁移学习方法（例如保留某些结构不变的中间层权重，重新训练有修改的层）或者直接重新修改。

## 五、优化策略详解

### 5.1 有监督微调策略（Supervised Fine-Tuning）

论文系统设计了 **4 种微调策略**，按可更新参数比例从小到大排列：

| 策略 | 可更新参数范围 | 参数比例 | 适用场景 |
|------|-------------|---------|---------|
| **Strategy 1** | 仅输入嵌入层 | 2.7% | 极低成本 |
| **Strategy 2** | 输入嵌入层 + 共享特征层 | 3.0% | 轻量级 |
| **Strategy 3** | 输入嵌入层 + 共享特征层 + 输出头 | **13.8%** | **推荐（性价比最优）** |
| **Strategy 4** | 全网络 | 100% | 全量微调 |

**关键发现**：
- **Strategy 3（13.8% 参数）在小样本场景（20 样本）下取得与全网络微调（100%）接近的性能**，性价比极高；
- 仅需 **20 个目标域样本**即可实现显著的性能提升；
- 在 Target Domain 2，微调使参数损失从 0.15 降至 0.0564，光谱重构损失 **降低 3 个数量级**（1.7558→0.0006）。

### 5.2 一致性约束域适应策略（核心优化方法）

**优化流程**：

1. **PNN 跨域校准**：使用少量目标域标记样本微调 PNN（Strategy 3），确保正向代理模型在目标域的预测精度；
2. **冻结 PNN**：校准后的 PNN 固定权重，作为不可微的物理验证器参与后续域适应；
3. **联合优化**：
   - 特征提取器 $G_f$ + 参数预测器 $G_p$ + 域分类器 D
   - 最小化复合损失 $L_{composite} = \alpha L_{sup} + \beta L_{cycle} + \gamma L_{domain}$
   - $L_{cycle}$ 通过 PNN 重构光谱，与目标光谱计算差异

**关键训练参数**：
- PC-DANN: GRL $\lambda_{max} = 0.12$
- PC-MMD: 多尺度 Lorenz RBF 核（5个核）
- 训练 50–80 epochs
- Batch size 等详见 Supporting Information Table S10

### 5.3 三种适应策略对比总览

| 策略 | 标记目标数据 | 无标记目标数据 | 特征对齐 | 一致性约束 | 优势 | 局限 |
|------|------------|-------------|---------|-----------|------|------|
| **有监督微调** | 少量必需 | 不使用 | 无 | 有（监督重构） | 最优性能 | 需要标记目标数据，不使用无标记数据 |
| **标准 UDA** | 不需要 | 使用 | 有 | 无 | 利用无标记数据 | 可能产生伪解陷阱 |
| **PC-DA（本工作）** | 少量（校准 PNN） | 使用 | 有 | **有（校准 PNN + 循环损失）** | 优于 UDA 的响应保真度 | 强拓扑偏移下 PNN 校正能力有限 |

## 七、数值验证与实验结果

### 7.1 物理验证任务：按需元滤波器设计

设计任务：在**两种频率波段**上按需设计具有 Lorenz 线形光谱响应的超表面滤波器：
- **红外波段**：30–60 THz
- **太赫兹波段**：0.5–1.0 THz

生成 10 组 Lorenz 目标光谱（每组对应不同共振深度、带宽、共振频率），覆盖关键光谱特征。

### 7.2 定量评估指标

| 指标 | 含义 |
|------|------|
| **Amplitude MSE** | 振幅均方误差 |
| **Resonant Frequency Error** | 共振频率误差 |
| **Bandwidth Error** | 带宽误差 |
| **Resonant Depth Error** | 共振深度误差 |
| **Quality Factor Error** | 品质因子误差 |

### 7.3 主要实验结果

#### 表：标准 UDA 与一致性约束 UDA 性能对比

| 方法 | 参数损失 | 光谱损失 | 振幅误差 | 相位误差 |
|------|---------|---------|---------|---------|
| **Target1（拓扑偏移）** |||||
| 源域预训练（基线） | 0.1339 | 0.0872 | 0.9105 | 1.0382 |
| DANN | 0.0920 | **0.2865** ↑ | 0.6988 | 1.3746 |
| **PC-DANN** | 0.0905 | **0.2076** ↓ | 0.6438 | 1.0477 |
| MMD | 0.0951 | 0.3764 | 0.7676 | 1.6818 |
| **PC-MMD** | 0.0864 | **0.1774** ↓ | 0.6096 | 0.9968 |
| **Target2（材料/频率偏移）** |||||
| 源域预训练（基线） | 0.1500 | 1.7558 | 0.3510 | 4.3290 |
| DANN | 0.0860 | 0.0018 | 0.0191 | 0.0451 |
| **PC-DANN** | 0.0745 | **0.0008** | 0.0201 | 0.0182 |
| MMD | 0.0831 | 0.0039 | 0.0433 | 0.0581 |
| **PC-MMD** | 0.0740 | **0.0030** | 0.0276 | 0.0371 |

### 7.4 关键分析

1. **伪解陷阱的定量验证**：
   - Target1 上标准 DANN 参数损失下降（0.1339→0.0920），但光谱损失恶化（0.0872→**0.2865**）；
   - 这表明 UDA 的统计特征对齐确实破坏了响应级有效性，验证了"伪解陷阱"的真实存在。

2. **一致性约束的改善效果**：
   - PC-DANN 将光谱损失从 DANN 的 0.2865 降至 0.2076（Target1）；
   - PC-MMD 将光谱损失从 MMD 的 0.3764 降至 0.1774（Target1）；
   - 在 Target2，PC-DANN 的光谱损失进一步降至 0.0008（DANN 为 0.0018）。

3. **域偏移类型对效果的影响**：
   - Target2（材料/频率偏移，拓扑不变）效果远好于 Target1；
   - 原因：Target1 涉及全新几何特征，校准后的 PNN 迁移能力有限，校正能力相应减弱。

4. **与有监督微调的定位**：
   - PC-DA 方法的性能介于标准 UDA 和有监督微调之间；
   - 其核心价值在于**利用无标记数据改善跨域适应性**，而非超越有监督学习。

## 八、研究结论与讨论

### 8.1 主要结论

1. **数据效率**：所提框架在仅需 **20 个标记目标域样本**的条件下即可实现高精度逆设计；轻量级微调策略（Strategy 3，仅更新 13.8% 参数）性价比最优。

2. **伪解陷阱识别**：标准 UDA 方法在物理逆问题中存在根本性缺陷——统计特征对齐不一定保证响应级有效性；PC-DA 通过前向一致性约束有效缓解了这一问题。

3. **域偏移类型敏感性**：所提方法效果强烈依赖于域偏移的类型：
   - 仅涉及材料/频率偏移时，PNN 校准和一致性约束效果显著；
   - 涉及拓扑偏移（全新几何特征）时，一致性约束的改善有限。

4. **工程验证**：在按需 Lorenz 线形光谱的元滤波器设计任务中，PC-DANN 相比标准 DANN 在共振频率误差、带宽误差、共振深度误差等方面均有统计显著性改善。

### 8.2 局限性与未来方向

1. **验证范围有限**：当前仅验证了超表面滤波器设计 + 两种域偏移类型，推广到相位设计、宽带器件、多功能超表面仍需进一步研究。

2. **仿真 vs 实验**：当前验证基于全波仿真（CST），不包含制备容差、测量噪声等实验因素；
   - 未来方向：容差感知数据集生成、噪声增强代理校准、闭环重校准、实验-in-the-loop 微调。

3. **一致性约束的时序位置**：约束主要在特征对齐之后施加，当目标域包含全新几何特征时校正能力有限。

4. **机制假设**：论文提出的"伪解陷阱"是一个操作层面的描述性概念，其广泛适用性（如在其他逆设计任务中的表现）仍需进一步验证。

## 九、个人评价与启示

### 9.1 论文亮点

- **问题新颖性**：首次系统研究了无标记目标域条件下超表面逆设计的跨域适应问题，并揭示了"伪解陷阱"这一重要失效模式。
- **方法论创新**：将校准后的正向代理模型作为前向一致性约束规约域适应，物理直觉清晰、工程可行性强。
- **实验设计系统**：三种适应策略的对比、两种域偏移类型的区分、四种微调策略的消融实验，使得结论具有较强的说服力。
- **开源代码**：提供了完整代码、模型架构和数据集，可复现性强。

### 9.2 值得借鉴的技术细节

1. **复合损失函数设计**：$\alpha L_{sup} + \beta L_{cycle} + \gamma L_{domain}$ 的加权组合，兼顾了监督精度、物理一致性和域对齐。
2. **轻量级微调策略**：Strategy 3 仅更新 13.8% 参数即可达到接近全网络微调的性能，对资源受限场景极具参考价值。
3. **PNN 架构设计**：LayerNorm + GELU + Dropout 的改进残差块设计，在保持拟合精度的同时提高了泛化能力。
4. **数据集设计思路**：通过固定其他变量、仅改变单一变量（拓扑/材料）的方式构建对比实验，能有效分离不同域偏移类型的影响。

### 9.3 与自身研究的相关性

- 此论文的**一致性约束思路**——利用前向物理模型规约逆问题求解——是一种通用范式，可推广到其他物理逆设计问题（如热管理、结构优化等）。
- 论文对**域偏移类型的系统分类**（拓扑偏移 vs 材料/频率偏移）提供了一个有价值的分析框架。
- 轻量级微调策略在**少样本场景**下的优异表现，为实际工程中降低数据采集成本提供了可行方案。

### A.6 概念速查表

| 术语 | 全称 | 一句话解释 |
|------|------|-----------|
| **UDA** | Unsupervised Domain Adaptation | 目标域无标签条件下的域适应方法 |
| **DANN** | Domain-Adversarial Neural Network | 通过梯度反转层（GRL）进行对抗训练，使特征提取器学会产生域不变特征 |
| **GRL** | Gradient Reversal Layer | DANN 的核心机关：正向=恒等变换，反向=梯度×(−λ) |
| **MMD** | Maximum Mean Discrepancy | 在 RKHS 中计算两个域特征分布均值之间的距离 |
| **RKHS** | Reproducing Kernel Hilbert Space | 再生核希尔伯特空间，MMD 在其中计算分布差异 |
| **PNN** | Forward Prediction Neural Network | 正向代理模型：输入结构参数 → 输出光谱，用少量目标域样本校准后冻结 |
| **INN** | Inverse Neural Network | 逆设计模型：输入光谱 → 输出结构参数，是域适应的训练目标 |
| **$L_{cycle}$** | Cycle Consistency Loss | 循环一致性损失：目标光谱 → INN → 参数 → PNN → 光谱，计算重构光谱与目标光谱的 MSE |
| **$L_{sup}$** | Supervised Loss | 在少量有标签目标域样本上计算的参数预测 MSE |
| **$L_{domain}$** | Domain Alignment Loss | 通过 DANN 的对抗损失或 MMD 的分布距离实现特征空间对齐 |
| **PC-DA** | Physics-Constrained Domain Adapt. | 本文提出的框架：在标准 UDA 基础上增加前向一致性约束 |
| **PC-DANN** | Physics-Constrained DANN | DANN + PNN 前向一致性约束 |
| **PC-MMD** | Physics-Constrained MMD | MMD + PNN 前向一致性约束 |
| **伪解陷阱** | Pseudo-Solution Trap | 特征对齐成功但光谱重构失败的 UDA 失效模式 |
