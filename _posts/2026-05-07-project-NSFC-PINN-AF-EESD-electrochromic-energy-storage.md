### 0.1 电致变色技术概述

**电致变色（Electrochromism）** 是指材料在外加电场作用下发生可逆氧化/还原反应，从而引起光学性质（透过率、吸收率、反射率）可逆变化的现象。

**基本原理**：
```
在外加电压下，离子（通常为 H⁺、Li⁺、Zn²⁺）和电子协同注入/抽出电致变色材料：
着色态：  M + xA⁺ + xe⁻ ⇌ A_xM（光学吸收增强，颜色变深）
褪色态：  A_xM ⇌ M + xA⁺ + xe⁻（光学吸收减弱，颜色变浅）
（A⁺ = H⁺/Li⁺/Zn²⁺，M = WO₃ 等电致变色材料）
```

**发展历程**：
| 代际 | 时期 | 特征 | 代表材料 |
|------|------|------|---------|
| 第一代 | 1960s–1980s | 感性发现阶段，单色、液态电解质 | WO₃ 非晶薄膜 |
| 第二代 | 1990s–2010s | 器件化，全固态、商业化起步 | NiO、Viologen、普鲁士蓝 |
| 第三代 | 2010s–至今 | 多功能集成：双波段、储能一体化、智能调控 | WO₃/MoOHCF 双电极、EESD |

### 0.2 研究进展：从 ECD 到 EESD 再到全季候调控

#### 0.2.1 电致变色器件（ECD）—— 仅调控"色"

传统 ECD 的核心功能是**动态调节可见光透过率**，实现节能采光或隐私保护，已部分商业化（如波音 787 舷窗、谷歌总部智能幕墙）。

**局限**：只关注可见光（0.38–0.78 μm），忽略了近红外（0.78–2.5 μm）这一占据太阳光总能量约 **52%** 的热能载体，也无法主动管理热辐射。

#### 0.2.2 双波段电致变色 —— 分治"色"与"热"

**关键突破**：实现可见光（Tvis）与近红外（TNIR）的**独立调控**，这是迈向全季候调控的关键一步。

- **WO₃**（阴极变色材料）：在近红外波段有强自由载流子吸收，可通过调控载流子浓度独立调节 NIR 透过率，同时其在着色态（W⁵⁺ 极化子形成）也能调节可见光。
- **MoOHCF**（钼基普鲁士蓝类似物，阳极变色材料）：在可见光区有强吸收，可在阳极氧化态下调节 Tvis，对 NIR 影响较小。

**四模态**（Dual-band ECD 的典型工作模式）：
| 模态 | WO₃ 状态 | MoOHCF 状态 | 光学效果 |
|------|----------|-------------|---------|
| 透明态 | 褪色（NIR 高透） | 褪色（VIS 高透） | 全光谱透射 |
| 仅 NIR 阻隔 | 着色（NIR 低透） | 褪色（VIS 高透） | 遮阳不遮光 |
| 仅 VIS 阻隔 | 褪色（NIR 高透） | 着色（VIS 低透） | 隐私保护，保留热透射 |
| 全阻隔态 | 着色 | 着色 | 最大隔热/隐私 |

#### 0.2.3 电致变色储能器件（EESD）—— "色+储"一体化

**核心思想**：将电致变色层同时作为电池电极，在变色过程中**存储/释放电能**，实现"一器两用"。

**意义**：
- 传统 ECD 需要外部电源驱动变色，能耗较高；
- EESD 可利用自身存储的电能驱动变色，或与光伏系统协同，实现能源自给；
- 夜间可利用存储的能量维持着色态（记忆效应），减少持续供电需求。

**发展脉络**（关键节点）：
- **2019年**：Cao 等（Joule）首次报道 VIS-NIR 双波段 EESD，实现内部能量存储；
- **2021–2023年**：锌离子 EESD（ZEESD）兴起，水系电解质安全性高、成本低；
- **2024年**：多色四模态 EESD 出现（Adv. Energy Mater. 2024, 2403414）；
- **2025年**：快速切换双阴极 EESD（Nat. Commun. 2025），切换时间 < 10s；
- **2026年**（本项目）：引入**中红外辐射调控**，升级为"全季候"EESD。

#### 0.2.4 辐射调控（中红外发射率动态调控）—— 补齐"热管理"最后一块拼图

**背景**：建筑物不仅需要通过玻璃调控**太阳能得热**（光与热的透射），还需要通过**热辐射**（中红外 2.5–25 μm）与室外环境进行热交换。传统材料的中红外发射率是固定的。

**动态辐射调控的原理**：
- 通过电致变色材料的金属-绝缘体转变（MIT）或自由载流子浓度变化，动态调节材料在中红外波段的发射率/反射率；
- 冬季：提升发射率（~0.9），促进室内热量以辐射形式散出或吸收室外辐射；
- 夏季：降低发射率（~0.2），阻隔室外热辐射进入。

**技术挑战**：需要在同一器件中同时调控 VIS、NIR（太阳能波段）和 MIR（热辐射波段），这是"全季候"调控的真正难点。

### 0.3 常规器件架构详解

#### 0.3.1 经典 ECD 的五层"三明治"结构

```
┌─────────────────────────────────────────┐
│  透明导电电极（TCE）                     │  ← 第1层
│  （ITO/FTO，透光 >80%，导电）            │
├─────────────────────────────────────────┤
│  电致变色层（EC Layer）                  │  ← 第2层
│  （WO₃等，离子/电子注入后变色）           │
├─────────────────────────────────────────┤
│  离子传导层/电解质（Ionic Conductor）      │  ← 第3层
│  （Li⁺/H⁺/Zn²⁺传导，电子绝缘）           │
├─────────────────────────────────────────┤
│  离子存储层/对电极（Counter Electrode）    │  ← 第4层
│  （NiO/MoOHCF等，补偿离子，维持电中性）   │
├─────────────────────────────────────────┤
│  透明导电电极（TCE）                     │  ← 第5层
└─────────────────────────────────────────┘
```

**各层功能详解**：

| 层次 | 常用材料 | 核心功能 | 关键参数 |
|------|---------|---------|---------|
| **透明导电电极** | ITO（氧化铟锡）、FTO（掺氟氧化锡）、AgNW（银纳米线） | 施加电压、透光 | 方阻 < 20 Ω/□，透过率 > 80% |
| **电致变色层** | WO₃（阴极）、NiO（阳极）、Viologen（溶液型） | 离子/电子注入后发生光学变化 | 着色效率（cm²/C）、响应时间、循环寿命 |
| **电解质/离子传导层** | 液态（LiClO₄/PC）、凝胶聚合物（PMMA/PEG）、全固态薄膜 | 传输离子，电子绝缘防止短路 | 离子电导率 > 10⁻⁵ S/cm，电子电阻率 > 10⁸ Ω·cm |
| **离子存储层/对电极** | NiO（与 WO₃ 配对）、普鲁士蓝 PB（与 WO₃ 配对） | 存储/释放离子，维持电荷平衡 | 容量匹配、响应速度匹配 |
| **封装层** | 环氧树脂、玻璃粉、柔性聚合物（PET/PI） | 阻隔水汽氧、机械保护 | WVTR < 10⁻⁴ g/m²/day |

#### 0.3.2 EESD 架构的差异

EESD 在 ECD 的基础上，将电致变色层**同时作为电池电极**，因此架构有以下变化：

```
┌─────────────────────────────────────────┐
│  透明导电集流体                          │
├─────────────────────────────────────────┤
│  负极电致变色层（如 WO₃）                 │  ← 既是电致变色层，又是电池负极
├─────────────────────────────────────────┤
│  电解质（含 Zn²⁺/Li⁺ 等金属离子）         │
├─────────────────────────────────────────┤
│  正极（如 Zn 金属/Zn 合金，或 MoOHCF）    │  ← EESD 的特殊之处
├─────────────────────────────────────────┤
│  透明导电集流体                          │
└─────────────────────────────────────────┘
```

**关键差异**：
- **对电极变为储能正极**：传统 ECD 的对电极只需存储离子，EESD 的正极需要发生可逆的氧化还原反应来存储电能；
- **电解质需兼容储能反应**：通常选择锌离子电池体系（水系，安全）或锂离子体系（有机电解质，电压窗口宽）；
- **三端口驱动**（本项目创新点）：WO₃ 端口、MoOHCF 端口、共同端口，实现三端独立/协同驱动。

#### 0.3.3 AF-EESD（本项目）的三端口架构

```
        端口1 (V_WO3)
            │
    ┌───────▼──────────┐
    │  WO₃ 电致变色层   │  ← 调控 NIR + 部分 VIS
    └───────┬──────────┘
            │
    ┌───────▼──────────┐
    │  共享电解质层      │  ← Zn²⁺ 传导，PC基有机体系
    └───────┬──────────┘
            │
    ┌───────▼──────────┐
    │ MoOHCF 电致变色层 │  ← 调控 VIS
    └───────┬──────────┘
            │
        端口2 (V_MoOHCF)

        端口3 (V_common，共同参考端)
```

**三端口驱动的优势**：
- 可独立控制 WO₃ 和 MoOHCF 的电位，实现 VIS 和 NIR 的**真正独立调控**；
- 传统双电极器件中，VIS 和 NIR 调控存在耦合，难以实现四模态的任意切换。

### 0.4 储能调控机制详解

#### 0.4.1 能量存储的形式

EESD 中，**电能以电化学能的形式存储**，具体表现为：

```
充电过程（电能 → 电化学能）：
  Zn²⁺ + 2e⁻ + WO₃ · nH₂O  →  ZnWO₃ · nH₂O（储能 + 着色）
  Zn → Zn²⁺ + 2e⁻（负极溶解，或在锌电极体系中，Zn 沉积在负极）

放电过程（电化学能 → 电能/热/光）：
  ZnWO₃ · nH₂O → WO₃ · nH₂O + Zn²⁺ + 2e⁻（释能 + 褪色）
  电子通过外电路做功（可驱动其他电子元件，或直接用于反向变色）
```

**储能的本质**：离子（Zn²⁺）在电极材料中的**嵌入能**（插层能）+ 电子转移能，以化学势能形式存储在固体电极中。

#### 0.4.2 能量的利用方式

存储的能量有以下几种利用途径：

| 利用方式 | 说明 | 能量去向 |
|---------|------|---------|
| **自驱动变色** | 利用存储的电能驱动器件自身变色，无需外部电源 | 电化学能 → 光学能（变色） |
| **对外供电** | EESD 作为微型电池，向外接负载供电（如传感器、低功耗电子） | 电化学能 → 电能（外电路） |
| **热管理协同** | 放电过程中的内热（ Joule 热）可用于辅助调温 | 电化学能 → 热能 |
| **与光伏协同** | 白天用光伏充电，夜间用存储能量维持着色态 | 光电 → 电化学能 → 光学能 |

**本项目的"能量回收效率"指标**：指变色过程中可回收/利用的电能占输入电能的比例，目标 > 50%。

#### 0.4.3 "三功能联动"的能量流

```
太阳光入射
    │
    ▼
┌──────────────────────────────┐
│        AF-EESD 器件           │
│                              │
│  VIS 调控 ───→ 采光/遮阳     │  ← 光功能
│  NIR 调控 ───→ 得热/隔热     │  ← 热功能（太阳能）
│  MIR 调控 ───→ 辐射换热管理   │  ← 热功能（热辐射）
│  储能功能 ───→ 电能存储/释放  │  ← 电功能
│                              │
│  "三功能联动"：                │
│  VIS/NIR 调控 ↔ 储能状态相关   │
│  MIR 调控 ↔ 载流子浓度相关     │
│  储能状态 ↔ 初始变色状态相关    │
└──────────────────────────────┘
```

### 0.6 本领域当前的技术瓶颈（本项目的切入点）

| 瓶颈 | 具体表现 | 本项目对策 |
|------|---------|---------|
| **多目标高维优化困难** | VIS/NIR/MIR/储能 多参数强耦合，传统试错法无法遍历 | PINN 可行域裁剪 + NSGA-II 多目标优化 |
| **物理可行性无法保证** | 纯数据驱动模型易产生"拟合正确但物理不可行"的设计 | PINN 将 PDE 约束写入损失函数 |
| **VIS/NIR 独立调控难** | 传统双电极器件中两波段存在耦合 | 三端口独立驱动架构 |
| **循环稳定性不足** | WO₃ 离子残留、MoOHCF 离子滞留导致容量衰减 | 界面能带工程 + PINN 预测最优循环工况 |
| **辐射调控与变色调控的协同机制不清** | MIR 发射率与载流子浓度的关系缺乏定量模型 | PINN + 原位表征揭示耦合机理 |

## 一、研究背景与立项依据

### 1.1 宏观背景

- 建筑能耗约占全社会总能耗的 **41%**，照明与空调占建筑能耗的 **75%以上**，均与门窗玻璃密切相关。
- 21–22°C 是办公绩效的"黄金区间"，偏离舒适带会产生 1–2% 的可量化产出折损。
- 电致变色玻璃窗（ECD）可动态调节透射比、遮光系数，是绿色城市智慧化发展的前沿热点。

### 1.2 器件结构与原理

传统 ECD 具有三明治结构：
```
透明导电电极 / 离子存储层 / 离子传导层 / 电致变色层 / 透明导电电极
```
在外电场下，离子定向迁移并发生可逆氧化还原，颜色与透明度随之变化。

### 1.3 全季候四模态器件（AF-EESD）的构想

传统 ECD 仅关注"可见之色"（Tvis），忽略了近红外波段"不可见之热"的调控。本项目提出：

**"变色 + 储能 + 调温"三功能一体化的全季候四模态变色储能器件（AF-EESD）**

四种工作模态：

| 模态 | 特征 | 适用场景 |
|------|------|---------|
| **Bright（亮态）** | 全光谱高透 | 冬季采暖 + 照明 |
| **Cool（冷态）** | 可见光高透 / 阻隔近红外 | 夏季降温，保留采光 |
| **Warm（暖态）** | 近红外高透 / 阻隔可见光 | 秋冬遮阳保暖 |
| **Dark（暗态）** | 全光谱阻隔 | 强辐射隔热 |

### 1.4 关键挑战

1. **多物理场强耦合**：AF-EESD 融合"变色+储能+调温"三功能，参数空间随功能维度指数级膨胀，传统试错法难以遍历。
2. **数据驱动黑箱风险**：纯数据驱动模型易产生"拟合正确却物理不可行"的解，无法保证电化学稳定性。
3. **材料层面瓶颈**：WO₃ 在长循环下存在离子残留、极化累积；MoOHCF 存在离子滞留与色态残留问题。

## 二、PINN（物理信息神经网络）在本项目中的核心地位

### 2.1 为何引入 PINN

> "单纯'实验数据—黑箱回归'易产生'拟合正确却物理不可行'的风险，难以在稳定电化学窗口与动力学约束下给出可信外推与可执行方案。相比之下，物理信息神经网络（PINN）可将电化学稳定窗口、守恒关系与传输/反应动力学等物理一致性约束显式嵌入学习过程……"

PINN 的核心优势：
- **物理可行性保证**：将 PDE 残差项与边界约束显式嵌入损失函数，规避非物理解
- **域锁定能力**：在电化学可行域内开展多目标优化，约束搜索空间
- **跨体系外推**：结合迁移学习/域自适应，实现从"机理域"到"器件域"的联合标定
- **可解释性**：输出隐变量，为机理阐明提供可验证证据链
- **闭环反向设计**：通过"预测—选样—验证—再训练"迭代，主动推进器件设计

## 三、PINN 三步走流程（核心工程应用路径）

本项目提出 **"PINN 三步走"** 的物理场约束智能研发流程：

### 第一步：可行域建模与候选空间裁剪

**目标**：快速清洗不可行的材料-工艺-驱动条件组合，锁定物理可达的搜索空间。

**技术实现**：
- 以电解质稳定窗口与端口电位边界作为**先验约束**
- 将以下方程作为 PINN **物理约束项**写入损失函数：
  - 离子迁移方程（PDE 残差）
  - 电势分布方程
  - 界面电荷转移机制
- 采用**拉格朗日乘子/罚函数**实现硬约束处理
- 引入**多任务学习（MTL）**，构建双波段光谱调控–储能回收协同效能的统一评价体系
- 目的是排除"可拟合但物理不可达"或"局部最优解"的候选

### 第二步：物理锚点数据集建立与模型替代推演引擎

**目标**：构建跨域可迁移的高保真代理模型，实现从少量精密计算到大规模快速推演的转化。

**技术实现**：
- 以 **DFT/MD/多物理场模拟**产生的高保真数据为锚点（能级/态密度、反应电位、插层能垒、溶剂化结构、内建电场等）
- 在统一状态变量下完成**跨域对齐**
- 采用 **"PINN + MTL"** 训练物理一致性模型：
  - "共享骨干 + 多任务头"架构
  - 联合预测 Tvis、TNIR、能量回收效率等多指标
  - 反演可解释隐变量
- 数据保真感知（DFA）+ 域自适应（DA）：实现机理域→器件域的联合标定
- 引入**神经网络势（NNP）/图神经网络势（NequIP）**对关键"结构-能量"关系进行替代评估

### 第三步：不确定性驱动闭环学习与约束反向生成

**目标**：在物理可行域内开展多目标约束反向优化，输出可执行的器件设计方案。

**技术实现**：

1. **不确定性量化**：
   - 深度集成学习（DE）/ 蒙特卡洛随机失活（MC Dropout）
   - 监测边界区域、稀疏样本区、高耦合区的失稳风险

2. **主动学习（Active Learning）**：
   - 以信息增益最大化为准则选样
   - 形成"预测 → 选样 → 验证 → 再训练"的闭环迭代
   - 加速收敛并稳定外推

3. **多目标约束反向设计**：
   - 将以下约束**显式写入**多目标优化：
     - 稳定电化学窗口
     - 可见光透射率（Tvis）
     - 近红外透射率（TNIR）
     - 库仑效率
     - 热场管理参数
   - 采用**非支配排序遗传算法Ⅱ（NSGA-II）**与**约束贝叶斯优化（CBO）**生成满足约束的帕累托解集
   - 直接反向输出：电极材料优化方案、界面调控参数、三端口驱动策略

## 四、PINN 解决的具体工程问题

### 4.1 问题定义

AF-EESD 的设计是一个典型的**多目标、高维度、多源数据复杂问题**：

- 涉及的物理场：电场 + 光场 + 热场 + 化学/电化学场
- 涉及的材料参数：稀土掺杂种类与浓度、膜层工艺参数、电解质配方…
- 优化目标（多目标权衡）：
  - Tvis（可见光调制幅度 > 60%）
  - TNIR（近红外调制幅度 > 60%）
  - 能量回收效率 > 50%
  - 库仑效率
  - 调温范围 ≥ 15°C
  - 循环寿命

### 4.2 PINN 的具体嵌入方式

```
损失函数 = 数据拟合项 + PDE残差项 + 硬约束项 + 软约束项

其中：
  PDE残差项：离子迁移方程残差 + 电势分布残差 + 界面动力学方程残差
  硬约束项 ：电解质稳定窗口边界（拉格朗日乘子法）
  软约束项 ：端口电压范围、守恒关系（罚函数法）
```

### 4.3 PINN 在"材料→器件"多尺度中的作用链条

```
DFT/MD 高保真数据（微观尺度）
           ↓（锚点数据集）
    PINN + MTL 代理模型训练
           ↓（域自适应对齐）
    器件域预测（Tvis, TNIR, 能量回收率, 热调制）
           ↓（不确定性量化 → 主动选样）
    实验补充测试 → 模型再训练（闭环）
           ↓（NSGA-II / CBO 约束优化）
    反向设计输出：最优材料方案 + 工艺参数 + 驱动策略
```

### 4.4 PINN 辅助机理解释

除了正向预测与反向设计，PINN 还承担**机理解释**功能：
- 输出可解释隐变量（稀土掺杂→缺陷态密度→自由载流子浓度→NIR调制幅度的量化链）
- 通过特征重要度归因分析（可解释性归因），量化各参数对 Tvis、TNIR、能量回收率的贡献
- 以物理一致性分析形成可验证的物理机制，为实验观测提供预测指导

## 五、主要研究内容

### 5.1 研究内容一：基于 PINN 的多目标强约束协同优化与反向设计

**(a) 物理可实现性判定与可行域锁定**
- 建立统一状态变量与特征编码体系（材料/界面结构参数与端口电位轨迹的可微表示）
- 研究电解质稳定窗口、守恒关系、离子迁移、界面动力学等物理约束在 PINN 损失函数中的嵌入方式
- 构建基于 PDE 残差项与约束项的**物理一致可行域判别器**
- 明确不同参数组合进入分解/副反应主导区间的边界条件

**(b) 机理锚点驱动的模型替代推演与跨域联合标定**
- 以 DFT/MD/多物理场模拟数据为锚点，构建"共享骨干 + 多任务头"的 PINN 代理模型
- 探究对 Tvis、TNIR 及能量回收效率的**联合预测能力与可解释隐变量反演能力**
- 研究数据保真感知与迁移学习策略在机理域到器件域对齐中的作用规律

### 5.2 研究内容二：高性能全季候四模态变色储能器件制备技术

**(a) 稀土–钨双金属氧化物（RE-WO₃）电极制备**
- 稀土种类（Ce等）与掺杂浓度筛选，缺陷/空位调控
- 明确两类响应的电位边界：
  - 自由载流子吸收 → 近红外选择性调制（0.8–1.6 V）
  - 插层极化子反应（W⁶⁺/W⁵⁺转换）→ 可见变色/全谱抑制（0 V）
- 优化迁移通道连续性与插层/脱嵌势垒，提升能量回收效率

**(b) MoOHCF 界面能带工程与局域配位协同优化**
- 调控异质结内建电场，降低离子脱出活化能，抑制界面极化与离子滞留
- 通过**局域配位策略**（八面体高价连接原子），构建多步氧化还原位点，实现多色态分段输出

### 5.3 研究内容三："变色–储能–调温"三功能联动调控与耦合机理

**(a) 电极-电解质-界面兼容性研究**
- 碳酸丙烯酯（PC）基有机电解质体系优化
- 匹配双端功能层的可逆反应电位区间

**(b) 多功能耦合机理揭示**
- 原位 UV-Vis-NIR + GCD + 红外热成像（IRT）联用系统
- 实时监测 Tvis、TNIR、面电容、能量回收效率与热场调控的动态响应
- 结合 ToF-SIMS 表征离子深度分布与迁移

## 六、关键科学问题

### 问题一：AF-EESD 跨单元参数协同匹配与 PINN 反向设计模型构建

核心难点：
- "光-电-热-化学"多场强耦合，维度灾难
- 传统数据驱动容易落入"局部最优或物理不可行"

解决思路：
- PINN + MTL → 联合预测 Tvis、TNIR、库仑效率、能量回收效率、热响应
- 不确定性量化 + 主动学习 → 闭环更新
- NSGA-Ⅱ + CBO → 在物理可行域内反向输出最优解集

### 问题二：AF-EESD 制备及"色泽调控-能量存储-热场管理"协同调控机理

核心难点：
- WO₃/MoOHCF 双功能层的竞争/协同关系如何共同约束 Tvis、TNIR 及储能特性
- 离子迁移与界面电化学反应的微观物理图像

解决思路：
- 原位 UV-Vis-NIR + GCD + IRT 联用系统实时监测
- ToF-SIMS 分析离子分布与跨层迁移
- UPS 表征能级偏移，EIS 表征界面阻抗

## 十二、研究风险与应对

### 风险一：PINN 收敛性不足、跨域泛化能力有限

**应对**：
- 深度集成学习/MC Dropout 持续监测训练过程中方差异常区域
- 主动学习优先筛选高不确定性区域的关键工况，补充实验结果反馈
- 迁移学习/域自适应再校准，减弱跨体系分布差异带来的外推偏差

### 风险二：三项协同参数难以同时最优及非同步衰减

**应对**：
- 多种制备工艺并行优化（电化学沉积、电脉冲成膜、水热生长等）
- 多种稀土调控 WO₃体系与多种 PBA 体系并行筛选
- 器件结构中设置缓冲层/自修复界面层
- 原位光谱–电化学–热学联用测试持续跟踪

## 十四、阅读评论与批判性分析

### 亮点

1. **PINN 应用定位清晰**：将 PINN 定位为"物理可行性保证器"，而非单纯预测工具，从损失函数设计层面就规避了黑箱模型的根本缺陷。

2. **"三步走"逻辑完整**：从可行域裁剪→代理模型推演→约束反向设计，形成了从问题定义到工程输出的完整链条，具有较强的工程实践指导意义。

3. **多目标优化框架先进**：NSGA-II + CBO 的组合兼顾了全局探索（遗传算法）与贝叶斯局部高效利用，在受约束多目标问题上是当前较成熟的范式。

4. **前期基础扎实**：课题组已实际制备出四模态器件并验证了 PINN 预测能量回收效率的能力，不是"纸上谈兵"。

### 潜在弱点

1. **PINN 训练数据量问题**：AF-EESD 体系维度高，样本数量有限（尤其是 DFT/MD 计算成本极高），PINN 在高耦合区域的泛化能力能否保证仍有疑问——申请书中的"主动学习补充"方案是否足够？

2. **物理约束嵌入的具体化**：申请书提到"将离子迁移方程写入损失函数"，但 AF-EESD 涉及 WO₃（极化子机制）与 MoOHCF（配位网络多步氧化还原）两套截然不同的微观机制，如何在同一 PDE 框架下统一建模，文中未给出详细的方程形式，是需要攻关的难点。

3. **NequIP/NNP 的引入时机**：图神经网络势的训练通常需要大量 DFT 数据（数千到数万条轨迹），对于新体系（稀土掺杂 WO₃）其成本较高，是否会成为瓶颈？

4. **PINN 与实验的迭代周期**：主动学习闭环依赖快速实验反馈，而每轮材料制备+表征的实验周期可能需要数周，闭环迭代的实际效率需在 4 年研究周期内审慎规划。

5. **三端口器件的 PINN 建模**：三端口驱动（V_WO₃, V_MoOHCF, V_共同端口）的耦合 PDE 体系远比双电极更复杂，其数值稳定性与求解效率是 PINN 实现的关键挑战，申请书中未详细讨论。
