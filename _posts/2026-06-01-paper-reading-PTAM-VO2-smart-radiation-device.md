## 一、研究背景与问题

### 1.1 背景
- **VO₂ 热致变色材料**：在 ~68°C 附近发生半导体-金属相变（SMT），中红外反射率随之大幅变化，是智能辐射器件（Smart Radiation Device, SRD）的理想材料。
- **F-P 腔多层膜 SRD**：结构为 底镜（Al）/ 间隔层（HfO₂）/ VO₂ 热致变色层。低温时充当红外反射体，高温时转变为红外发射体。
- **痛点**：
  1. 薄膜厚度在实验中难以精确测量；
  2. VO₂ 的光学常数（n, k）无法原位（in situ）测试；
  3. 相变过程中光学常数动态变化，传统模拟方法无法有效捕捉；
  4. 传统仿真优化方法计算量大、易陷入局部最优。

### 1.2 核心问题
> **如何仅利用实验测量的光谱数据（无厚度标签、无原位光学常数），准确预测 VO₂ 基多层膜系统的红外辐射调控性能？**

---

## 二、创新点

### 创新点 1：Phase Transition Adaptation Model（PTAM）架构
- 提出**物理启发的分支神经网络架构**，核心包含三个模块：
  - **Encoder**：将光谱编码为 THI（Thickness Hidden Information，厚度隐信息，2×1 向量）
  - **Switch1**：由 THI 映射 → VO₂ 等效复折射率实部 nₑ
  - **Switch2**：由 THI 映射 → VO₂ 等效复折射率虚部 kₑ
  - **Decoder**：由 λ, THI, nₑ, kₑ 重建光谱
- 分支结构使得高低温"孪生光谱"（twin spectra）可共用编码器，但在 Switch 模块产生差异化输出，实现**相变自适应**。

### 创新点 2：半自监督学习策略（Semi-Self-Supervised Learning）
- **预训练阶段**：使用仿真数据（含厚度标签 + 固定光学常数 VO₂）进行监督学习，让模型获得数量级先验；
- **精调阶段**：仅使用实验测量的孪生光谱（高温 + 低温，无厚度标签、无光学常数真值），通过自监督损失 + 对比学习 + 物理先验正则化联合训练。

### 创新点 3：三合一的损失函数设计
- **L_rec（重建损失）**：MSE(重建光谱, 真实光谱)，保证编解码基础质量；
- **L_con（自监督对比损失）**：利用高低温孪生光谱的配对关系，约束同一 THI 在不同温度下的光谱一致性，实现相变自适应；
- **L_reg（经验正则化损失）**：KL 散度约束 THI 分布接近人工经验先验（由沉积时间估算的厚度范围），提供物理启发。

### 创新点 4：TMM 嵌入 + 代理模型加速
- 将**传递矩阵法（TMM）**的光学求解器嵌入训练流程中，开发了实部/虚部解耦的张量化 TMM（tTMM）；
- 进一步训练一个**神经网络代理模型（Surrogate Model）**替换 tTMM，训练速度提升 **两个数量级**。

## 三、研究方法

### 3.1 器件结构与光谱生成
```
器件结构（四相薄膜系统）：
    空气
  ────────────
   VO₂ 层     10-90 nm（热致变色，光学常数随 T 变化）
  ────────────
   HfO₂ 层    400-1200 nm（间隔层，光学常数恒定）
  ────────────
   Al 层      ~50 nm（底镜，近似全反射）
  ────────────
   基底
```
- 光谱范围：**2.5–25 μm（中红外）**，226 个波长点
- Al 层足够厚时近似为全反射镜 → 只需考虑 VO₂ 和 HfO₂ 两层厚度，输出 2×1 的 THI 向量

### 3.2 数据集
| 数据类型 | 用途 | 标签 | 光学常数 |
|---------|------|------|---------|
| 仿真数据集 | 预训练（监督学习） | 厚度 + 文献光学常数 | VO₂ 光学常数恒定 |
| 实验孪生数据 | 精调（半自监督） | 仅有高/低温光谱，无厚度/光学常数标签 | VO₂ 光学常数未知且随 T 变化 |

- 实验数据：5 个样品（不同 VO₂ 沉积时间），各测高温 + 低温光谱，共 10 条用于测试集重建验证
- 训练用孪生光谱对（同一 THI 的高温和低温光谱配对）

### 3.3 训练流程
```
预训练阶段（仿真数据，监督学习）:
  监督学习光谱→THI+光学常数 的映射，建立数量级先验

精调阶段（实验孪生数据，半自监督）:
  输入: 高温光谱 x 和低温光谱 y（同一器件的配对数据）
  Encoder → THI(共享)
  THI → Switch1 → nₑ (高温/低温各自独立)
  THI → Switch2 → kₑ (高温/低温各自独立)
  Decoder → 重建 x̂, ŷ
  
  损失: L = L_rec + L_con + L_reg
```

### 3.4 损失函数详解

#### L_rec（重建损失）
$$L_{\text{rec}} = L(\hat{x}, x) + L(\hat{y}, y) = \frac{1}{n}\sum_{i=1}^{n}\|\hat{x}^{(i)} - x^{(i)}\| + \frac{1}{n}\sum_{i=1}^{n}\|\hat{y}^{(i)} - y^{(i)}\|$$

#### L_con（对比损失）
- 利用孪生数据的配对关系，约束高温和低温光谱共享同一 THI
- 本质是将同一 THI 的不同温度光谱拉近，不同 THI 的光谱推远

#### L_reg（经验正则化损失）
- 假设 THI 服从由沉积时间经验估计的多元高斯先验分布
- 协方差矩阵：`[[100, 0], [0, 1000]]`（基于 VO₂ 沉积时间 ≤60s、HfO₂ 沉积时间 ≤45min 的经验估计）
- 使用 KL 散度：$$L_{\text{reg}} = KL(q_\theta(z+k \mid x+y) \parallel p(z+k))$$

### 3.5 代理模型（Surrogate Model）
- **输入**：5×1 向量 [波长, VO₂厚度, HfO₂厚度, nₑ, kₑ]
- **输出**：该波长处的反射率
- **训练数据**：随机采样厚度和光学常数，由 TMM 计算反射率作为标签
- **效果**：训练时间从 tTMM 的 9–46s/batch 降至 NN 的 ~0.002s/batch（**约 10⁻² 量级加速**）

### 3.6 性能评估与优化
- 训练完成后，通过 Switch1/Switch2 获得 nₑ(THI) 和 kₑ(THI) 的映射关系
- 在 THI 二维空间（d_VO₂, d_HfO₂）内扫描计算发射率等高线图
- 发射率计算基于基尔霍夫定律：ε = 1 − R（Al 底镜近似全反射时）
- 最终输出：ε_H (高温发射率), ε_L (低温发射率), Δε = ε_H − ε_L
- 用 Monte Carlo 采样（15000 实例）验证模型对数据集统计特征的复现能力

## 四、网络结构

### 4.1 整体架构

```
                    ┌─────────────────────────────────────────┐
                    │               PTAM 架构                  │
                    └─────────────────────────────────────────┘

    高温光谱 x (226) ──┐                    ┌── Switch1_H → nₑ_H (226)
                       ├── Encoder ── THI ──┤
    低温光谱 y (226) ──┘    (共享)    (2×1) └── Switch2_H → kₑ_H (226)

                                           ┌── Switch1_L → nₑ_L (226)
                                           │
                                           └── Switch2_L → kₑ_L (226)

    Decoder 输入: [λ(226), THI(2), nₑ(226), kₑ(226)] → 重建光谱 (226)
```

## 五、研究内容与结果

### 5.1 光谱重建
- 对 5 个样品共 10 条光谱（高/低温各 5 条）进行重建，MSE 较小
- THI 预测值与沉积时间呈线性相关（高温和低温模型预测的 THI 值接近），验证了 THI 表征厚度的有效性

### 5.2 光学常数反演
- nₑ 和 kₑ 值在 W 掺杂浓度下与文献报道一致
- 相变时 kₑ 显著增大（自由载流子吸收增强）
- 薄膜较薄时，等效光学常数出现超出常规范围的快速变化，但模型仍能准确匹配光谱

### 5.3 性能等高线分析
- 引入自适应校正模块后：
  - ε_L 等高线：中心位置 ε_L 从 0.053 → 0.249（与实验 ε_L > 0.2 一致）
  - ε_H 等高线：中心位置 ε_H 从 0.501 → 0.764
  - Δε 峰值坐标向 (48, 720) 移动，最大 Δε = **0.5380**
- 验证了 THI ≈ (50, 800) 附近 Δε 最大的先验假设

### 5.4 Monte Carlo 统计验证
- 15000 个虚拟样本在发射率等高线图上采样
- 内环（采样分布）与外环（数据集分布）比例相似
- 证明 PTAM 能有效复现数据集的发射率特征分布

## 六、结论

1. PTAM 能够仅通过实验光谱数据，**同时**推断薄膜厚度（THI）和 VO₂ 的等效光学常数（nₑ, kₑ）
2. 分支架构 + Switch 模块有效实现了相变过程中光学常数随温度的自适应调整
3. 半自监督学习策略解决了厚度难以精确测量、光学常数无法原位测试的实际工程难题
4. 代理模型加速策略使训练速度提升两个数量级
5. 方法可推广至其他热致变色多层膜系统的性能预测与结构优化
6. 为低成本、高效率开发 SRD 提供了可行的数据驱动路径

## 七、复现评估与方案

### 7.1 复现难度评估
| 方面 | 难度 | 说明 |
|------|------|------|
| 数据获取 | ★★★★★ | 需要制备 VO₂ 基 F-P 腔 SRD 样品并测量高/低温中红外反射光谱，这是最大瓶颈 |
| TMM 求解器 | ★★★☆☆ | TMM 实现较为成熟，但需开发张量化版本支持批次训练 |
| 网络架构 | ★★☆☆☆ | 多层 MLP + 分支结构，PyTorch 实现较直接 |
| 损失函数 | ★★★★☆ | 对比损失和 KL 正则化需仔细调参，论文未给出 λ 超参数 |
| 代理模型 | ★★★☆☆ | 需大量随机采样 + TMM 生成训练数据 |
| 训练调参 | ★★★★☆ | 半自监督学习收敛稳定性是关键挑战 |

### 7.2 复现步骤建议

#### Stage 0: 环境搭建
- PyTorch + CUDA（RTX 2060 或同等 GPU）
- Python 科学计算栈（numpy, scipy, matplotlib）
- 自定义 TMM 求解器

#### Stage 1: TMM 求解器开发
```
1. 实现标准 TMM：计算四层膜系（空气/VO₂/HfO₂/Al）的反射率
2. Al 层采用全反射近似，简化接口矩阵
3. 验证与文献光谱的一致性
4. 开发 tTMM（张量化版本）：解耦实部/虚部，支持 batch 并行
```

#### Stage 2: 仿真数据集构建
```
1. 确定波长范围：2.5–25 μm，226 个等间隔点
2. 确定厚度范围：VO₂ [10, 90] nm, HfO₂ [400, 1200] nm
3. VO₂ 光学常数（n, k）使用文献值（需确定温度依赖的来源文献）
4. HfO₂ 和 Al 光学常数使用文献值
5. 在参数空间随机采样，生成 ~10⁴–10⁵ 条光谱
6. 每条光谱附带 (d_VO₂, d_HfO₂, n, k) 作为标签
```

#### Stage 3: 代理模型训练
```
1. 构建 5→1 的 MLP 代理模型
2. 训练数据：随机采样 (λ, d_VO₂, d_HfO₂, nₑ, kₑ) → TMM 计算 R
3. 验证代理模型精度（MSE < 0.002）
4. 冻结权重，集成到 PTAM 中
```

#### Stage 4: PTAM 构建与训练
```
1. 实现 Encoder: 226→500→500→500→500→2
2. 实现 Switch1 (nₑ): 1→500→500→500→500→226
3. 实现 Switch2 (kₑ): 226→500→500→500→500→226
4. 实现 Decoder（含代理模型）
5. 预训练阶段：仿真数据监督学习
6. 精调阶段：实验孪生数据 + L_rec + L_con + L_reg
```

#### Stage 5: 如果没有实验数据（纯复现验证）
```
替代方案:
1. 用 TMM 生成虚拟"实验"数据：对 VO₂ 光学常数引入少量扰动
   模拟实际薄膜中光学常数的偏离
2. 用生成的虚拟数据作为"实验孪生数据"
3. 训练 PTAM 后，验证 Switch 模块是否恢复了预设的光学常数偏移
4. 对比 THI 预测与真实厚度
```

## 九、简评

### 优点
- 物理启发与数据驱动的深度融合（TMM + DNN 联合训练）
- 半自监督策略巧妙解决了"无标签"的工程痛点
- 代理模型加速方案具有工程实用价值
- 方法论可推广到其他相变材料（GST、SmNiO₃ 等）

### 不足与疑问
- Switch2 为何输入维度为 226 而非 Switch1 的 1？文中对此未做展开说明
- 对比损失 L_con 的具体公式文中未给出完整定义
- 损失函数各分量的权重系数未公开
- 实验数据规模极小（仅 5 个样品），模型的泛化能力存疑
- 仅适用于 F-P 腔结构，对其他多层膜几何的适用性未知
- 代码未开源
