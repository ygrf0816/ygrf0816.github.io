## 一、研究背景与动机

### 1.1 从"自然材料"到"人工超材料"的范式类比

文章开头建立了一个**跨尺度类比**（Fig. 1a）：

| 维度 | 自然材料（微观） | 信息超材料（宏观人工） |
|------|-----------------|----------------------|
| 基本单元 | 原子（atom） | 超原子（meta-atom） |
| 排列方式 | 晶格（periodic lattice） | 空间编码分布（inhomogeneous coding array） |
| 决定性质的机制 | 化学成分 + 原子排布 | 结构几何 + 空间编码序列 |
| 代表生成模型 | AlphaFold（非周期蛋白）、MatterGen（周期晶体，ref. 3） | **InfoMetaGen（本文）** |

**核心论点**：生成式 AI 已在微观材料发现（蛋白结构、无机晶体）取得突破，但**宏观人工材料**的生成式设计几乎空白。原因是工程难点不同：

- 微观材料只需预测**一种**结构（周期或非周期）；
- 信息超材料必须**同时**设计局部超原子 + 全局非均匀编码阵列，是"多尺度联合"问题。

### 1.2 信息超材料的设计困境

1. **组合爆炸**：结构参数空间极大（像素化单元 + N 元阵列的离散编码），传统设计严重依赖经验与试错。
2. **"结构决定功能"的双刃剑**：这一特性既是超材料强大之处，也带来了极高的设计复杂度。
3. **现有智能方法的问题**：
   - 大多为**任务专用**（task-specific），换个功能就要重新训练；
   - 大多绑定**特定比特深度**（1-bit / 2-bit / 3-bit）或特定场型；
   - 尚无**普适的生成式设计框架**能同时覆盖"超原子层级"与"阵列层级"。

### 1.3 本文思路

> 学一个**共享生成先验**（shared design prior），再通过**轻量适配器**把它迁移到不同电磁功能上。

即：**冻结基座 + 只训适配器**，同一模型族既生成单个超原子、也生成完整编码阵列，且跨比特深度、跨功能复用。

## 二、主要创新点

1. **首次将扩散生成范式系统迁移到宏观人工超材料**，从"逐任务优化"转向"**摊销式逆设计**"（amortized inverse design）。

2. **统一双层级设计**：同一架构同时处理超原子（meta-atom）与任意非均匀编码阵列（meta-array），无需为每个任务/比特位宽训练独立模型。

3. **"模拟比特"（analog bit）表示**：把离散编码数字先转二进制、再映射到 {−1, +1} 的连续量，从而让**离散组合优化问题可以直接套用标准连续扩散框架**——这是一个简洁且可复用的关键技巧。

4. **物理/工艺可行性通过"数据构造"而非"损失函数"嵌入**：几何连续性与对称性约束在训练样本上施加；阵列编码字符取自经过验证的超原子库。**训练期零电磁仿真开销**（implicit data-embedding strategy），避免了可微 EM 求解器的高昂代价。

5. **多比特、多任务的"一个适配器管一个功能"**：单个功能适配器即可覆盖不同比特设置，避免为不同比特分辨率先训练完整模型。

6. **实验闭环**：超原子 S 参数、远场波束、近场聚焦、全息成像四类任务均完成 PCB 加工与微波暗室实测验证。

7. **效率优势**：全息任务上达到 GS 算法同级的重建质量，**运行时间从 1.28×10² s 降至 5.40×10⁻² s（约 2.4×10³ 倍加速）**。

## 三、方法架构

### 3.1 两阶段训练范式（Fig. 1b, c）

```
┌───────────────── 阶段 1：预训练（无条件、功能无关） ─────────────────┐
│  大规模仿真编码图案（超原子 + 阵列，多比特/多功能混合）               │
│        ↓ 前向扩散（加噪）                                            │
│  干净编码图案 e0 → … → e_t → … → 纯高斯噪声 ε                        │
│        ↓ 反向过程（去噪）                                            │
│  U-Net 去噪网络 ε_θ(e_t, t) 学习"有效编码图案"的统计结构              │
│  损失：L_DM = E[ || ε − ε_θ(e_t, t) ||²₂ ]                          │
└──────────────────────────────────────────────────────────────────────┘
                              ↓  冻结基座
┌───────────────── 阶段 2：功能适配器微调 ─────────────────────────────┐
│  条件 c 注入：                                                       │
│    · 超原子   → (目标频率 f, 目标电磁响应：相位/幅度)                 │
│    · 远场波束 → (球坐标 θ, φ, 比特数)                                │
│    · 近场聚焦 → (焦点坐标 x, y, z, 比特数)                           │
│    · 全息成像 → (目标图像, 比特数)  ← 注意：成像距离未作为条件        │
│  损失：L_DM = E[ || ε − ε_θ(e_t, t, c) ||²₂ ]                        │
│  仅更新适配器参数，基座参数冻结                                       │
└──────────────────────────────────────────────────────────────────────┘
                              ↓
┌───────────────── 生成 ───────────────────────────────────────────────┐
│  随机高斯噪声 → 反向去噪（约 8 步）→ 模拟比特 ã → 阈值量化 → 编码图案 │
└──────────────────────────────────────────────────────────────────────┘
```

### 3.2 离散编码的"模拟比特"表示（Methods 核心）

这是让离散问题适配连续扩散的关键一步：

1. 离散编码数字 $d \in \{0, 1, \cdots, K-1\}$（K = 2ⁿ，n 为比特数）；
2. 写成二进制向量 $\mathbf{b} = (b_1, \cdots, b_n)$，$b_i \in \{0,1\}$，其中 $n = \lceil \log_2 K \rceil$；
3. 映射到模拟比特：$a_i = 2b_i - 1$，$a_i \in \{-1, +1\}$；
4. 于是 $d \mapsto \mathbf{a} = (a_1, \cdots, a_n) \in \{-1, +1\}^n$，可直接用标准连续扩散建模；
5. 采样后阈值量化回二值：$\hat{b}_i = \mathbb{1}(\tilde{a}_i > 0)$，再解码为离散编码数字 $\hat{d}$。

> **为什么不直接做离散扩散？** 用 {−1,+1} 的连续表示，可以直接复用成熟的 DDPM/U-Net 实现；代价是采样后必须量化，这也是"生成随机性 → 需要批量筛选后处理"的根源之一。

#### 3.2.1 "比特"的两层含义（高频混淆点，必须分清）

论文里 "bit" 出现在两个完全不同的层面，混起来会把整条数据流读错：

**第一层 —— 物理编码位：编码超材料每个单元的相位量化阶数**

| 术语 | 相位状态数 | 各状态相位 | 单元的物理自由度 |
|------|-----------|-----------|-----------------|
| **1-bit** | $2^1 = 2$ | 0°, 180° | 二值：每个单元只有"同相 / 反相"两种状态 |
| **3-bit** | $2^3 = 8$ | 0°, 45°, 90°, …, 315° | 八值：相位以 45° 为步长量化 |

这是"数字编码超材料／信息超材料"的经典概念，决定的是**波前调控的精细度**。文中直接体现了这个差别：1-bit 波束偏转出现 **4 个对称主瓣**，3-bit 在同样方向条件下只出现 **2 个主瓣**——作者称之 "the enhanced beamforming precision afforded by higher quantization"。

**第二层 —— 表示位：analog bit 的张量通道数 $n$**

- 一个 $n$-bit 编码数字 $d \in \{0, \dots, 2^n - 1\}$ 展开成 $n$ 位二进制 → **通道数就等于 $n$**；
- 单通道整数图 $\mathbf{s} \in \mathbb{R}^{H\times W}$ → 多通道二值图 $\mathbf{e} \in \mathbb{R}^{H\times W \times n}$ → 模拟比特 $\{-1, +1\}$ 张量；
- 3-bit 例（SI Table 1 → Table 2）：digit 5 → 二进制 `101` → 模拟比特 $(+1, -1, +1)$。

**关键点：1-bit 与 3-bit 共用同一个三通道张量格式。**

原文 "we uniformly represent coding patterns using the maximum bit number"（取 $n_{\max} = 3$），SI Note 14 又明确写 "both the 1-bit and 3-bit patterns are **mapped to three-channel maps**"。因此 1-bit 图案也是 3 通道——按 Table 1 的机械映射推断，1-bit 的 digit 0 / 1 会写成 `000` / `001`（高位置零），对应模拟比特 $(-1,-1,-1)$ / $(-1,-1,+1)$，即**第 1、2 通道恒为 $-1$，信息全在第 3 通道**，与 3-bit 图案（8 个 digit 都会用到）在统计上明显可分。

> ⚠️ 严格说，Table 1 只给了 0–7 的 3-bit 映射，**1-bit 具体采用"高位置零"还是"复制填充"SI 没有明写**；从"统一用最大位数"+"三通道"两条表述看，置零的说法最自洽。若需 100% 确认，只能去 Code Ocean 翻数据加载代码。

这个设计的连带含义值得记一笔：**1-bit 与 3-bit 数据落在同一个三通道模拟空间的两个不同子流形里**，而 bit-type embedding（1-bit 记 0，3-bit 记 1）就是告诉适配器"这次该去哪个子流形采样"。这是"一个适配器同时管两种位宽"能成立的技术前提。

### 3.3 关键设计选择

| 设计点 | 具体做法 | 用意 |
|--------|---------|------|
| 基座网络 | **U-Net** 扩散架构 | 作者称是在计算效率与任务性能间的"最优平衡"（Supplementary Note 12 有架构对比与可扩展性分析） |
| 适配器 | 轻量 functional adapter，只训适配器 | 免去每任务重训整个扩散模型 |
| 数据规模/构成 | 跨功能、跨比特深度的**大规模仿真编码图案** | 让基座学到"共享设计先验"（稳定排布、数字组成等） |
| 超原子物理约束 | 对训练样本施加**几何连续性 + 对称性**约束 | 让扩散模型学到"物理可实现"的结构分布 |
| 阵列物理约束 | 编码字符来自**已验证的超原子库** | 保证采样出的编码对应可行的电磁状态 |
| EM 损失 | **训练期不使用**（仅生成后做 EM 仿真/实验评估） | 避开可微 EM 求解器的高成本，靠"数据内嵌"保证物理有效性 |

#### (3) 数据是怎么造出来的：两条不同的路径

这是理解本工作"为什么不需要可微 EM 求解器"的关键。

**路径 A — 超原子（unit cell）：真跑 CST 全波仿真，但用 PIPG 算法"定向扩充"**

以经典 Jerusalem cross Huygens 单元为种子 → 二值像素化 → 用 **PIPG（path-insertion path generation）** 算法在若干"特征节点"之间随机构造离散金属路径（规避障碍区），得到**保留原拓扑但引入非直觉变异**的新结构 → 每个候选**逐个跑 CST F-solver** 评估 S 参数 → 筛出相位覆盖充分、彼此分离的一组 → 构成**"已验证超原子库"**。单次仿真约 2 分钟，只算 16 个等间隔频点后插值；CST + MATLAB 2023b 联合（MATLAB 负责生成与筛选）。

→ **算法细节见 (4)。**

**路径 B — 阵列图案：不逐阵列跑全波，靠"已验证超原子库 + 解析传播公式"**

由目标函数解析算出所需相位分布 → 每个单元**查库取最近相位**对应的 digit → 得到编码图案（= 训练样本）。远场方向图用**解析阵列因子**（SI Eq. 13）算而非 CST；近场聚焦的 focal metamaterial 用 CST F-solver 算；阵列整体只在最终验证时才跑全波。

这正是正文 "implicit data-embedding strategy" 的真实含义：**物理可行性在"建库"阶段就被固化了，阵列层面则完全被解析公式替代；训练期一次 EM 仿真都不跑，但建库期做了大量 CST。**

→ **四步细节见 (4) 末节。**

#### (4) PIPG 算法详解（SI Note 6 完整还原）

> SI 里其实有**两段**描述：一段是通用算法伪代码风格（Supplementary Fig. 26），一段是实际数据生成流程（Supplementary Fig. 28 的六步流程图）。**两者合起来才是完整方法**——前者给出"怎么长路径"，后者给出"往哪儿长、怎么筛"。

**本质**：PIPG 是一个**带障碍约束的 RRT（快速扩展随机树）变体**，用于在二值像素画布上"长"出金属走线。

**画布与像素定义（Supplementary Fig. 26）**

| 元素 | 含义 |
|------|------|
| 绿点 $P_{\text{start}}$ | 路径起点像素 |
| 红点 / 目标点 $G$ | 路径终点像素 |
| 黑线（obstacle） | 障碍区，路径禁止穿越（对应必须保留的非金属区、馈电/过孔区、或对称轴上不该走线的区域） |
| 固定步长 $\delta$ | 每次从搜索树向外扩展的固定距离 |
| 终止阈值 | 新节点与 $G$ 足够接近时直接连线收尾 |

**通用流程伪代码（Fig. 26）**

```
输入：起点 P_start、目标 G、障碍掩膜 O、固定步长 δ、终止阈值 ε
初始化搜索树 T = {P_start}
while dist(最近节点, G) > ε:
    P_rand ← 在画布上随机采样一点
    P_near ← T 中距 P_rand 最近的已有节点          # nearest
    P_new  ← P_near + δ · (P_rand − P_near)/‖P_rand − P_near‖   # steer，固定步长
    if 线段(P_near → P_new) 与障碍 O 相交:
        丢弃本次，回到 while 重新采样 P_rand        # 关键：不撞障碍才生长
    else:
        T ← T ∪ {P_new}                            # 扩展树
T ← T ∪ {G}                                        # 足够接近 → 直接连到目标点
输出：T 中 P_start → G 的节点链 → 映射回像素 → 路径像素置 1，其余置 0
```

**实际数据生成流程（Fig. 28 六步）**

| 步骤 | 内容 |
|------|------|
| **Step 1** | 选取**高性能经典单元**作为先验结构知识（Jerusalem cross Huygens 单元；文中另提到 arc-shaped double-layered Huygens' unit 也是种子） |
| **Step 2** | 把金属图案**离散成二值编码图案**（1 = 金属，0 = 非金属） |
| **Step 3** | 选定若干**特征节点 $P_i$（$i = 1, \dots, N$）**——结构骨架上的关键位置（谐振臂端点、拐角、对称轴交点等） |
| **Step 4** | 设定**障碍区**与**路径长度 $L$** |
| **Step 5** | 在相邻特征节点之间**逐段迭代生成金属路径**（$P_j \to P_{j+1}$，$j = 1, \dots, N-1$），共得到 **$M$ 个像素化候选图案** |
| **Step 6** | 对 $M$ 个候选**逐个建 unit cell 并跑 CST 全波仿真** |

**为什么这是"定向扩充"而非盲目随机——四个约束环环相扣**

1. **种子先验**：起点不是空白画布，而是已知高 Huygens 响应的经典单元；
2. **特征节点**：新路径必须落在预定义节点之间 → **强制保留原结构的拓扑骨架与对称性**，但**走法随机** → 产生作者所称"难以通过常规电磁设计方法获得的非直觉变异"；
3. **障碍区 + 路径长度 $L$**：把变异幅度限制在物理可实现范围内，避免断裂、孤立金属岛、无法加工的过细缝隙；
4. **闭环筛选（这一步才是"定向"的关键）**：$M$ 个候选跑完 CST 后，用 MATLAB 做**相位筛选**——挑出相位覆盖充分（1-bit：0°/180° 反相；3-bit：8 个态彼此分离、近似 45° 等间隔）且彼此分离的一组，构成**已验证超原子库**；pattern generation 与 selection **反复迭代**，逐步收敛到最优结构集合。

补充：除 PIPG 外，还叠加了**直接在种子结构上做局部像素增删**（金属块 / 过孔的 addition / removal），由结构约束与电磁相关性引导，进一步扩充候选多样性。

**仿真与筛选的工程参数（决定了这条路走不走得通）**

- CST 设置：x/y 向 unit-cell 边界条件、z 向 open、**±z 两个 Floquet 端口**；阵列级为 y 偏振平面波入射 + 全向 open；
- **单次仿真约 2 分钟**；**只算 16 个等间隔频点，其余频率由近似插值得到**——这是把 2 min/次压到可承受规模的关键；
- 硬件：AMD Ryzen Threadripper 3960X 24 核 @3.79 GHz；**CST + MATLAB 2023b 联合**（MATLAB 负责图案生成、数据分析与筛选）；
- 成本结构结论：**吃算力的是"建库"（单元级 CST），不是"阵列"**——因为阵列层面用"已验证库 + 解析公式"完全绕开了全波。

**路径 B 的算法细节（阵列级，四步）**

1. 由目标函数**解析计算所需相位分布**：远场波束偏转用阵列因子（SI Eq. 13）；近场聚焦/全息用 Fresnel 传播（SI Eq. 21–22，$E = W \cdot M$，$W = e^{-jkr}/r$，评价时 $r$ 固定为 10λ）；
2. 每个单元位置**查库**，取相位最接近所需值的那颗已验证超原子 → 得到整数 digit 图；
3. 1-bit / 3-bit 分别用 2 态 / 8 态库 → 得到 **64×64 的编码图案，这就是训练样本**；
4. 远场方向图用 Eq. 13 的 $N \times N$ 双重求和**解析算**（面板上的 radiation pattern 不是 CST）；近场聚焦的 focal metamaterial 则用 CST F-solver 算；
5. 阵列整体只在**最终验证**时跑 CST 全波（Fig. 3–5 里的 simulated 曲线）。

#### (5) 补充：尺寸-成本权衡（SI Note 10）

- CST 单次仿真时间随网格从 **51 s → 1,944 s**（约 38 倍），内存 **233 MB → 15,502 MB**（约 66 倍），呈指数增长；
- 单张 RTX 4090 (24 GB) 下，**统一预训练可支持的最大网格为 128×128**（显存约 19.6 GB）；本文取 64×64 是显存/耗时/性能的折中；
- 全息重建质量随阵列分辨率提升：低于 **28×28** 时 GS 算法无法收敛（PCC 记 0），28×28 → 64×64 时 PCC 升至 **> 0.8**。

### 3.6 条件注入机制与完整数据流（易误读点，务必对齐）

这一节把"到底什么是输入、什么是输出、适配器接在哪"彻底锁死，避免把整条流程读反。

**一句话：编码图案是输出，不是输入；扩散底座是信息主干，适配器是旁路控制支路。**

#### (1) 两个阶段的数据流

**阶段一｜预训练（无条件，functionality-agnostic）**

```
186,962 条编码图案（1-bit + 3-bit；3 类阵列 + 单超原子）
   ↓ 二进制展开（n = 3）
e0 ∈ R^{64×64×3}（模拟比特，值域 {−1,+1}）
   ↓ 前向加噪（T = 1000）
et
   ↓ 去噪 U-Net（唯一训练目标：预测噪声 ε）
εθ(et, t)        —— 损失 L_DM = E‖ε − εθ(et, t)‖²
```

此阶段**没有条件 c**，模型学到的只是"什么样的编码图案看起来是合法结构"——即结构分布与数字组成。**功能语义全然不在这里。**

**阶段二｜微调（有条件，每功能一个适配器，底座冻结）**

```
随机噪声 z（不是编码图案！）
   +
条件 c = [功能条件嵌入] ⊕ [bit-type 嵌入]
   ↓
适配器 encoder（每层仅 3×3 Conv + SiLU + 下采样）
   ↓ 多尺度条件特征
零初始化卷积（zero-conv，训练起点输出为 0，保证不破坏底座）
   ↓ 加到冻结底座 U-Net 对应尺度的特征图上
冻结底座 U-Net 反向去噪（10 步 DDIM 为默认设置）
   ↓
模拟比特 → 阈值量化 → 二值 → 解码 → 离散编码图案（64×64）
```

#### (2) 四类任务的条件到底是什么

| 任务 | 条件（原始形式） | 条件编码方式 | 条件的物理含义 |
|------|-------------|-------------|---------------|
| **超原子生成** | $(f,\ \angle S_{21})$ | **SI 未给独立公式**（推断复用坐标类管线） | **要哪个频点的哪个相位态** |
| 远场波束偏转 | $(\theta, \varphi)$ | 归一化 → MLP ×2 → reshape → Conv3×3 ×2（Eq. 14–17） | 波束指向的天顶角/方位角 |
| 近场聚焦 | $(x,y,z)$ | 归一化 → 同上的 MLP+Conv 管线（Eq. 23–27） | 焦点的三维空间坐标 |
| 近场全息 | MNIST 28×28 灰度图 | Conv3×3+SiLU → Flatten → MLP+SiLU → reshape → Conv3×3（Eq. 28–30） | 目标成像图样本身 |

四者最后都并入同一条管线：**条件嵌入 ⊕ bit-type 嵌入 → 通道拼接 → 两个 3×3 Conv 融合 → 统一条件 C → 送进适配器**。差别只在条件编码器：**坐标类走 MLP，图像类走 Conv+MLP+reshape+Conv**。全息因为像素值本就在 $[0,1]$、与预训练的噪声特征表示天然同尺度，所以**不需要额外归一化**。

##### (2b) 超原子任务的条件：唯一显式含"工作频率"的任务（易漏点）

**原文两处直接证据**

1. **Methods 正文**（唯一一处系统交代四类任务条件的地方）：
   > "The conditional information depends on the design task: **for meta-atom generation, the conditions include the target working frequency and EM response**; ..."
2. **Fig. 2 图注**直接标注条件格式：
   > "**Conditions: coding meta-atom (f, ∠S21)**"

**结论：条件 = $(f,\ \angle S_{21})$，即"目标工作频率 + 目标相位"。**

**为什么这条特别值得注意——它是四类任务里唯一的"频率可变"任务**：

- 波束 / 聚焦 / 全息三类阵列任务，**工作频点是固定的**（演示集中在 16–18 GHz 带内、17 GHz 中心，见 SI Fig. 44），频点不是条件、只是仿真设置；
- 超原子任务则把 $f$ 显式喂给适配器，因此**同一个适配器能跨频点生成**：Fig. 2b 在 **8 / 9 / 11 / 12 GHz** 各生成一对保持 180° 相位差的 1-bit 单元；Fig. 2e 演示 **8 GHz 与 10 GHz** 的外推生成；Fig. 2f 演示跨频点生成 3-bit 单元（相位误差 <10°、推理迭代 ≤3 次）。
- 换句话说：**频率是超原子任务的自由度之一，是阵列任务的固定背景**。这也解释了为什么 Fig. 2 是全文唯一出现 GHz 条件的图。

**条件语义的精确化（避免踩坑）**

| 容易误解 | 实际含义 |
|---|---|
| "入射光频率信息" | 严格说是**目标工作频率**，是设计目标量，不是对入射波的实时读入。仿真里等价于 Floquet/平面波端口的频扫点 |
| 相位条件是"相对相位差 0/180°" | Fig. 2 给的是**绝对目标相位 $\angle S_{21}$**（Fig. 2a 生成 1-bit 的 anti-phase 单元对，即两个绝对相位态；Fig. 2b 要求在整个目标频段内维持 180° 差） |

**⚠️ 一处正文与图示口径不一致（值得记录）**

- 正文（Introduction）称可调制的目标响应包括 "the **frequency, phase and amplitude**"（p.3），另一处写 "prescribed EM responses, including target **phase, amplitude** and working frequency"；

#### (3) 适配器到底吃什么？——多尺度条件特征是怎么出来的

这是最容易卡住的一步：**如果适配器不接受编码图案，那它凭什么能输出"多尺度"特征？**

答案：**适配器的输入是一张由条件"撑"出来的特征图 $\mathbf{C}$，多尺度性来自适配器自己的下采样金字塔。**

**Step 1｜条件 → 一张与编码图案同尺寸的特征图**

以远场波束偏转为例（SI Eq. 14–17）：

```
(θ, φ) 两个标量
  ↓ 归一化（除以数据集最大值）
(θ̃, φ̃) ∈ [0,1]²
  ↓ 两层全连接 + SiLU            Eq. 15–16
h²_coord（高维向量）
  ↓ reshape 成与编码图案同尺寸的 2D 张量   ← 关键一步
64×64×C 张量
  ↓ 两层 3×3 Conv + SiLU          Eq. 17
F_sph_coord   ← 条件嵌入特征
```

**注意 reshape 这一步的物理含义**：输入只是 2 个数字，输出却是一整张 64×64×C 的图。这不是复制编码图案，而是**学习的广播（learned broadcast）**——FC 层的输出维度本身就是 $H\times W\times C$，等价于把条件展开成一张"只由条件决定、与噪声无关"的固定特征图，再由 Conv3×3 赋予空间结构。

- 近场聚焦（$x,y,z$）：同一条管线，只是 3 个标量（Eq. 23–27）；
- 全息（MNIST 28×28 灰度图）：Conv3×3 + SiLU → Flatten → MLP + SiLU → reshape → Conv3×3（Eq. 28–30）。**图像条件反而更简单：先压成向量再铺回 64×64**，而不是直接把 28×28 图当空间条件用；
- bit-type（标量 $b$：1-bit 记 0，3-bit 记 1）：两层 FC → $\mathbf{h}^2_{bit}\in\mathbb{R}^{H\times W\times C}$ → **unflatten** 成 $H\times W\times C$ → 两层 3×3 Conv → $\mathbf{F}_{bit}$（Eq. 18–20）。

**Step 2｜拼接融合成统一条件**

$$\mathbf{C} = \mathrm{SiLU}\big(\mathrm{Conv}_{3\times3}(\mathrm{SiLU}(\mathrm{Conv}_{3\times3}(\mathrm{Cat}(\mathbf{F}_{cond}, \mathbf{F}_{bit}))))\big)$$

即：条件特征与 bit 特征**沿通道维拼接** → 两个 3×3 Conv 融合 → 统一条件 $\mathbf{C}$。所有四类任务共用这条融合管线。

**Step 3｜适配器 encoder 产生多尺度特征**

- 适配器 encoder 的每一层只有：**3×3 Conv + SiLU + 下采样**；
- 逐层下采样 → 得到 64×64 → 32×32 → 16×16 → 8×8 的特征金字塔，**这就是"多尺度条件特征"的来源**（而不是从底座网络里取）；
- 与标准 ControlNet 的差别：ControlNet 把主干 encoder **整套复制**过来（含残差块与注意力），本文的适配器被压到只剩 Conv + 下采样，可训参数大幅缩减。

**Step 4｜逐尺度注入**

每个尺度的条件特征经 **zero-initialized conv** 后，与冻结底座 U-Net 在**同一尺度**的特征图**相加**。

> **zero-init 的作用**：权重初始化为 0 → 微调起点时注入项恒为 0 → 底座行为与预训练时**完全一致**，训练从"预训练恒等映射"出发，逐步学会如何用条件去"推"生成方向。这就是 ControlNet 的经典技巧，保证不会在训练初期破坏预训练先验。

**一个尚未写明的点**：从描述看，适配器的每层只有 Conv + SiLU + 下采样，**没有提到时间步嵌入**；而底座 U-Net 的残差块明确用 time embedding $\mathbf{t}_{emb}$ 做 scale & shift 调制（$\mathbf{t}_{emb} = [\beta_t, \sin\beta_t, \cos\beta_t]$ 加到噪声特征图上）。若适配器确实不含时间步条件，则它在全部去噪步上**输出同一组条件特征**——这一点 SI 未明说，需要看代码确认。

#### (4) 三个常见误读（逐条纠正）

| 误读 | 事实 |
|------|------|
| ❌ 适配器把底座 U-Net 的**中间特征**当输入 | 方向相反。**适配器输出的多尺度条件特征，经 zero-conv 注入到底座对应尺度的特征图上（相加）**。底座是信息主干的承接方，适配器是旁路控制支路 |
| ❌ 条件里包含"阵列编码图案"，模型由它生成目标图样 | **编码图案是输出，不是输入**。采样从随机高斯噪声出发；输入只有"随机噪声 + 条件 c" |
| ❌ 会生成"不同尺寸"的目标图样 | **输出张量尺寸恒为 64×64×3**。meta-atom 是 20×20 **零填充**到 64×64。任务之间的差别在**条件类型与功能语义**，不在输出尺寸 |

#### (5) 一个适配器 = 一种功能，但覆盖两种位宽

- 微调目标是 $\mathcal{L}_{DM} = \mathbb{E}_{\mathbf{e}_0, c, \epsilon, t}\left[\|\epsilon - \epsilon_\theta(\mathbf{e}_t, t, c)\|_2^2\right]$，条件 $c$ 显式进入去噪网络；
- 每个功能一个适配器（4 个），**每个适配器同时覆盖 1-bit 与 3-bit**，靠 bit-type embedding 区分——不是每位宽各训一个；
- 微调时 1-bit / 3-bit 样本**联合训练**：每功能每位宽 **9,000 条**，超原子任务 **1,000 条**；300 epochs，全息任务约 5.5 小时；
- 与标准 ControlNet 的差别：ControlNet 通常**复制整个主干 encoder** 作为条件支路，本文的适配器 encoder **每层只有 3×3 Conv + SiLU + 下采样**，可训参数量大幅缩减。

| ③ **通用性**：同一架构同时适用于超原子与阵列设计 | （作者认为可通过改进数据治理、更先进生成架构和约束生成策略缓解） |

### 4.2 任务二：远场波束成形阵列（Fig. 3）

- 适配器条件：**球坐标 (θ, φ) + 比特类型**；
- 反向去噪约 **8 步**：早期随机噪声逐步组织为**条带状 motifs**，随后快速收敛为规整编码图案；
- **1-bit 与 3-bit** 均可生成，对应的 3D 远场方向图准确指向目标偏转方向；
- **100 次独立生成**：生成误差 **≤ 3°**（条件 θ = 14°, φ = 17°）；
- 编码数字统计：各次生成的数字计数虽有波动，但**始终围绕仿真参考值浮动**，说明既稳定复现目标数字组成、又保留生成多样性；
- **实验验证**（Far-field）：主波束偏转在 **θ = 8°**；在 **172°** 出现次要峰——原因是超原子透射系数非 100%，产生残余反射瓣。仿真与实测吻合良好。

### 4.3 任务三：近场聚焦阵列（Fig. 4）

- 采用**纯相位调制**（所有超原子保持高透射，设计空间可控）；
- 适配器条件：**3D 焦点坐标 (x, y, z) + 比特类型**；
- 去噪演化：无序噪声 → **环状结构（ring-like）** → 规整编码 + 明确焦斑；示例焦点如 (21, 30, 24)、(3, 43, 14)；
- **100 次独立生成**：聚焦位置偏差限制在 **x 向 2 个单元、y 向 1 个单元**以内；
- 数字计数同样围绕仿真参考值浮动；
- **实验验证**：近场平台实测三种条件下的场分布，与仿真一致性良好。

### 4.4 任务四：近场全息成像（Fig. 5）——本文的"高光"任务

- 适配器条件：**成像目标 + 比特类型**（**成像距离未作为条件参数**）；
- 成像平面位于超材料前方 **10 个波长**处；
- 1-bit **反射式**阵列重建字母 **'A'**；3-bit **透射式**阵列重建字母 **'C'**（实测 vs 仿真吻合良好）；
- **100 次独立生成**：**PSNR 全部 > 40 dB**，**SSIM 全部 > 0.99**；20 种不同条件（各 100 次平均）下同样保持高位；
- 编码数字分布：1-bit 波动小、均值贴近仿真参考值；**3-bit 分布明显更宽**（箱线图更宽、散点更分散）。作者强调这**不是生成失败**，而是模型"在相同约束下产生多样创新编码"的**内在特性**——这是相对传统优化的核心优势。但也因此**对训练数据质量提出严苛要求，单次生成 100% 正确不现实**，需通过改进网络架构与数据治理提高有效生成概率。

### 4.5 计算效率基准（Fig. 6）

对比 **5 种优化方法**（遗传算法 GA、粒子群 PSO、模拟退火 SA、模式搜索 pattern search、Gerchberg–Saxton GS），测试集为 **36 个全息目标（A–Z + 0–9）**。

| 方法 | 平均 PSNR | 平均 SSIM | 平均运行时间 |
|------|-----------|-----------|--------------|
| GA / PSO / SA / Pattern search | 有限（重建保真度低） | 低 | 极高 |
| **GS** | 高（与本文同级） | 高 | **1.28 × 10² s** |
| **InfoMetaGen（本文）** | **40.90 dB** | **0.9936** | **5.40 × 10⁻² s** |

> **加速比 ≈ 2.4 × 10³（相对 GS）**，相对启发式优化方法优势更大。作者把原因归结为生成框架的**摊销性质（amortized nature）**：预训练 + 轻量适配器微调后，一次快速推理即可产出全息编码图案，而不再需要"逐目标迭代搜索"。

## 五、结论（Discussion 要点）

1. **范式转变**：从"任务专用电磁优化"转向"**摊销式逆设计**"——设计空间中学到的知识可复用来生成不同功能条件下的新结构。
2. **为什么适合信息超材料**：其波函数由**数字状态**编码，这为电磁物理、AI 与可编程硬件之间提供了天然接口。
3. **设计哲学**：不再为每个目标寻找**单一**最优结构，而是**采样多个可行编码图案**以实现相近的宏观响应。
4. **明确的自认局限**：
   - 依赖训练数据的覆盖度与质量，**远超出采样分布的目标**可能需要额外数据或物理引导的自适应；
   - 生成具随机性，**仍需后选择**来挑出最满足指标的候选；
   - 当前演示限于微波段、有限比特深度、选定功能。扩展到**光频、色散/损耗介质、多物理场响应、动态调制、超大口径**仍需进一步验证。
5. **未来方向**：生成模型 + **物理信息约束** + **不确定性估计** + **可微电磁求解器** + **实验反馈闭环**，将信息超材料从"为预定功能优化的器件"推向"自适应设计平台"。

## 六、批判性分析

### 6.1 方法优势

- **"analog bit" 表示**极其简洁有效：把离散编码逆设计无痛接入成熟连续扩散生态，工程可复现性高。
- **物理约束走"数据内嵌"路线**（几何连续性/对称性约束 + 已验证超原子库），**训练期零 EM 求解开销**——相较 PINN 式在损失里塞 PDE/EM 残差，这是更务实的电磁工程取舍。
- **适配器范式**（一个功能一个轻量适配器，比特深度可泛化）显著优于"每任务/每比特一个模型"的做法。
- **四类任务 + 实测闭环 + 与 5 种经典优化器的定量基准**，证据链相当完整（这是能上 Nature Comput. Sci. 的关键）。
- **OOD 生成能力**被显式量化（new/unique/OOD/symmetric 四指标），呼应了超表面社区的前沿关切（ref. 42, 43）。

### 6.2 潜在不足 / 可质疑之处

| 问题 | 具体描述 |
|------|---------|
| **物理约束的"软性"边界** | 靠数据分布保证可行性，**没有显式物理损失**；对训练分布之外的目标（如极端角度、超大口径），物理有效性缺乏硬保证。 |
| **单次生成正确率不足** | 3-bit 全息分布明显变宽，作者承认单次生成 100% 正确不现实，**必须批量生成 + 电磁筛选**，这意味着"推理 5.40×10⁻² s"的效率优势在加上筛选后会被部分抵消（筛选本身需 EM 仿真）。 |
| **未报告筛选开销** | Fig. 6 的运行时对比只统计了"生成"时间，**未计入必要的后处理/EM 验证成本**，与 GS 的"一次优化即得可用解"并非完全同口径比较。 |
| **成像距离未作条件** | 全息任务的成像距离固定在 10λ。作者明确说"成像距离不作为条件参数"——这限制了平面外成像距离的任意定制能力，而列阵需要重新微调。 |
| **仅微波、仅无源静态** | 功能限于波束偏转/聚焦/全息，**未涉及动态可重构**（如 VO₂/PIN 二极管/液晶调谐）；也未验证光频段的色散与损耗影响。 |
| **数据集与训练细节披露有限** | 训练集规模、比特分布、U-Net 具体参数量等关键复现信息主要放在 Supplementary Note 12，正文的信息密度对复现不够友好。**已核实：预训练 186,962 条、阵列 64×64、超原子 20×20 零填充、全息目标用 MNIST 等核心信息只出现在 SI Note 2 / Note 6 中**（详见本笔记 §3.4）。 |
| **对比基线选择** | 启发式优化器（GA/PSO/SA/pattern search）在 36 目标上的配置（迭代预算、种群规模）未在正文交代；GS 作为相位恢复算法的强基线被公平对待，但对"其他生成式/深度学习方法"（如 ref. 32–35 的 GAN/迁移学习方案）缺乏同条件的定量对比。 |

## 七、与研究方向的关联思考

> 结合本人当前方向（超表面逆设计、VO₂ 相变可重构超材料 RMM、辐射制冷/热控、DiffMeta 类制造引导扩散生成、AI 辅助器件建模）逐条对照：

1. **"预训练基座 + 轻量适配器"直接可迁移到 VO₂/RMM 逆设计**。本人在 `VO2_reverse_project_20260815`（50/200 nm VO₂ 薄膜，0.28–25 μm）与 RMM（VO₂ + 多层堆栈，2–14 μm 双态）中存在天然的"两态（非晶/晶态）"与"多层堆栈参数"两类设计维度，恰好可套用"一个共享先验 + 两个相态适配器"的思路。**⚠️ 但这里有一处理解需要修正（详见 §7.3-2）：VO₂ 双态的本质是"同一个结构同时满足两个光谱目标"，不是"两个结构各对应一个态"。因此准确对应物是一个「双态联合适配器」（两态目标拼进同一条件向量），而不是两个独立的相态适配器。**

2. **"analog bit" 表示值得直接借鉴**。RMM/热超表面的多层堆栈厚度或编码层数本质上也是**离散多比特选择**（如 3-bit 对应 8 种厚度档）。文中 $a_i = 2b_i - 1$ + 阈值量化的做法，可用极低工程量把离散材料/厚度组合问题接入现有连续扩散管线。

3. **"物理约束走数据内嵌" vs "物理损失"的路线之争**。本人在薄膜 n/k 反演、TMM 建模上已有成熟物理前向模型；InfoMetaGen 的做法（把对称性/连续性/可行库约束在**数据构造阶段**施加，训练期不算 EM）在**计算成本**上明显优于 PINN 式嵌入。但其代价是没有分布外物理保证——对本人的热辐射设计（需要 Kirchhoff 定律、能量守恒等硬约束）而言，**混合路线（数据内嵌 + 轻量物理损失）可能更稳**。

4. **与 DiffMeta（xcrp-103174，Cell Rep. Phys. Sci. 2026）的对照**值得写成对比表：

| 维度 | InfoMetaGen（本文） | DiffMeta（热发射器） |
|------|--------------------|---------------------|
| 生成对象 | 离散数字编码超材料 | 连续 free-form 超材料几何（MIM Au/a-Si/Au） |
| 条件注入 | 轻量功能适配器（LoRA 式） | Cross-Attention 光谱注入 |
| 物理/工艺约束 | 数据构造阶段编码（对称性/连续性/可行库） | 数据集构建阶段编码（周期 3–8 μm、顶点 5–20、边缘平滑） |
| 训练期是否用 EM 求解器 | 否 | 否（代理/数据驱动） |
| 输出离散性 | 天然离散（比特） | 连续几何，需后处理 |
| 关键指标 | PSNR 40.90 dB / SSIM 0.9936；加速 2.4×10³ | 180 °C 热伪装降温 ~100 °C |

   **共同规律**：**"约束前移到数据构造阶段"是当前制造可行生成式逆设计的主流共识**，这正好印证本人在 DiffMeta 笔记中的判断。

5. **"摊销式逆设计"对本人的 KPI 叙事有启发**。本人正在写的苏州科技项目（阿特斯牵头）与 TOPCon 硼发射极论文都涉及"ML surrogate 替代 TCAD/仿真"——本文的"训练期零仿真、推理期一次前向"正是**代理模型的极致形态**，其 Fig. 6 的"精度–效率 Pareto 图"表达方式（PSNR vs runtime，log 轴）非常适合借用到工艺公式/器件性能的 ML surrogate 汇报中。

6. **多比特可扩展性的边界**。文中 3-bit 时分布显著变宽、单次成功率下降，提示**比特深度↑ → 生成不确定性↑**。若后续做 RMM 的"高比特/多档位厚度"设计，需预先规划批量生成 + EM 筛选的算力预算，或引入**约束解码 / 拒绝采样**来提升单次有效率。

7. **可复用的"评价指标语言"**：
   - 生成类工作：**new / unique / OOD / symmetric** 四指标；
   - 成像类工作：**PSNR / SSIM 统计分布**（不是单值，而是 100 次生成的箱线 + 正态拟合）；
   - 效率类工作：**精度–时间双对数 Pareto 散点**。
   这三套表达方式在本人的超表面/热辐射生成式工作中都能直接套用。

8. **潜在后续动作**：抓取 Code Ocean capsule（https://doi.org/10.24433/CO.0515873.v2）确认三件事——① 扩散实现细节与适配器结构；② **1-bit 在三通道统一格式下的具体填法**（置零 or 复制）；③ **已验证超原子库的规模与阵列数据的条数拆分**。这是判断"能否直接迁到光学/VO₂ 场景"的最后一块拼图。（SI 已补读，见 §九）

### 7.9 专题：能否迁移到 VO₂ 相变材料的热控辐射超表面逆设计？

> 这是本人最关心的迁移问题。结论：**范式层可搬、表征层选择性搬、收益层必须重估；真正的瓶颈不在模型架构，而在两态 n,k 与前向模型的保真度。**

#### (1) 先看作者自己划的红线（Discussion 原文，p.878）

> "the current demonstrations focus on representative microwave information metamaterials with finite bit depths and selected functions. Extension to **optical frequencies**, **dispersive or lossy media**, **multiphysics responses**, **dynamic modulation** and very-large-scale apertures **will require further validation**."

VO₂ 中红外热控辐射超表面**同时命中其中三项**：色散+损耗介质、多物理场（热–电磁耦合）、动态调制（相变）。若做到近红外/可见则再命中光频。**这说明：迁移不是"照搬成熟方案"，而是作者明确未验证的空白区——有依据，但没有先例可援。**

作者对"动态/可重构"给出的具体技术提示在 SI Note 12：

> "when the design tasks extend to more complex functional requirements, such as **space-time metamaterials** and large-scale meshes, migrating to architectures such as **DiT** will be a natural and promising choice."

即：**一旦引入"时间/状态"维度（VO₂ 的相态正是这一类），作者建议换掉 U-Net 基座。** 这是一个很实际的架构级提醒。

#### (2) 逐元素迁移对照

| 论文元素 | VO₂ 热控超表面的对应物 | 迁移评级 |
|---------|---------------------|---------|
| **共享先验 + 轻量适配器** | 一个「双态联合适配器」+ 若干单功能适配器（辐射制冷 / 红外隐身 / 热伪装 / 激光防护） | ★★★★★ 范式最直接可用 |
| **约束前移到数据构造** | 工艺约束：层厚上下限、厚度量子化步长、层数上限、材料互扩散与退火温度限制（BaF₂ 等软材料）、最小特征尺寸 | ★★★★☆ 概念可迁，但"已验证超原子库"在 VO₂ 场景**无对应物**，需用 TMM 自建可行堆栈库 |
| **训练期零 EM 仿真** | 成立，而且**成本远低于论文**（TMM 解析求解 ~ms 级，数据集可轻松到 10⁵–10⁶ 条） | ★★★★★ 这是相对论文的最大优势 |
| **analog bit 离散表征** | 多层堆栈的**离散厚度档/材料档**（8 档厚度 ≈ 3-bit）；VO₂ **晶化分数本身是连续量**，比 bit 更自然，无需量化 | ★★★☆☆ **按需使用**——若保持厚度连续则根本不需要 analog bit |
| **条件 = 低维坐标/图像** | 双态目标光谱 $\big(\varepsilon_A(\lambda),\ \varepsilon_C(\lambda)\big)$，或分段积分量（2–5 μm / 8–14 μm 平均发射率 + $\Delta\varepsilon$） | ★★☆☆☆ **条件维度暴涨至上千维**，且光谱不具备 MNIST 那种图像流形先验，条件编码器须重训 |
| **摊销式逆设计（推理一次前向）** | 若前向是 TMM，摊薄的收益几乎消失 | ★★☆☆☆ **收益缩水**，见 (3)-1 |
| **评价指标（PSNR/SSIM/加速比）** | 必须换：双态调制深度 $\Delta\varepsilon$、大气窗口选择性（8–13 μm 平均发射率）、太阳吸收 $\alpha_{solar}$、角度/偏振平均、相变循环稳定性 | 必须整体替换 |

#### (3) 三个硬性不匹配（不解决就无法落地）

**① "摊销省时间"这个核心卖点在 TMM 场景下失效**

- 论文的 2.4×10³ 加速对比对象是 GS 迭代相位恢复（1.28×10² s）；生成式之所以划算，是因为**每一次电磁评估都贵**（微波单元 CST 单次 2 min，阵列全波更贵）。
- VO₂ 多层堆栈用 TMM：单次光谱求解 ~ms，GPU 版更快。用 DE/PSO 或可微 TMM + Adam 直接优化，几百次迭代也就秒级到分钟级。**单目标优化上，生成式模型的速度优势基本不存在。**
- 生成式的价值转移到三处：**(a) 多解采样**（给工艺容差留候选集）；**(b) 工艺可行域约束**（避免生成不可制造的堆栈）；**(c) 多任务复用**（同一先验服务制冷/伪装/隐身多目标）。
- **第一道决策门槛**：结构是**准 1D 多层膜 → 不值得上扩散模型**；是 **2D 图案化超表面（需 RCWA/FDTD，单次秒级至分钟级）→ 摊销收益才回归**。

**② VO₂ 双态是"一个结构两个响应"，与论文"一个条件一个结构"不等价**

- 论文每个任务：一个条件 → 一个结构。VO₂ 热控的核心诉求是**同一结构在非晶/晶态下同时满足两个光谱目标**（双波段选择性 + 高 $\Delta\varepsilon$）——这是**多目标联合约束**，论文只验证了单条件。把两态光谱拼成一个大条件向量可行，但**收敛性与模态坍缩风险未经验证**，需引入条件 dropout / classifier-free guidance 保证两态都被满足。
- 更麻烦的是 VO₂ 相变有**滞后与中间态**：实际器件常工作在部分晶化（EMA 混合，参见本笔记 ome-13-12-3631 中 $E_a = 3.8$ eV、EMA 定量晶化分数）。这把问题从"两个离散态"变成**连续相变分数轴上的响应面**，条件空间多一维。
- 好消息：这个连续维度**天然适合扩散条件**（比离散 bit 更好接），不需要 analog bit。

**③ 前向模型的保真度成为新的性能天花板**

- 微波编码超材料的"数字 → 相位"映射近似单值（每颗单元在某频点的透射相位），所以"取自已验证超原子库"能保证可行。
- VO₂ 中红外：色散强、多材料界面、且必须处理**相干/非相干叠加**（本人经验：厚衬底 TMM 会带来 envelope 振荡，倾向 semi-infinite backscatter 模型）。**前向模型口径不一致会直接污染数据集**——生成式数据驱动方法的精度上限被前向模型与 n,k 数据质量锁死。
- 因此迁移的**第一步不是搭扩散模型，而是把两态 n,k 做扎实**（正是 `VO2_reverse_project_20260815` 在做的事）。n,k 不准，后面全是沙上建塔。

#### (4) 落地路线（三阶段）

| 阶段 | 内容 | 门槛/判据 |
|------|------|----------|
| **0｜地基（先决）** | 完成 50/200 nm VO₂ 两条反演路径（定厚度 / 双厚度包络）交叉验证；产出 0.28–25 μm 非晶+晶态标准 n,k 表；**统一前向模型口径**（相干性处理、衬底模型对齐实测 R/T） | n,k 与实测 R/T 残差收敛、两条路径互相印证 |
| **1｜低成本闭环** | TMM 批量生成 (堆栈 → 双态光谱) 数据集（10⁵–10⁶ 条，成本可忽略）→ ML surrogate 正/逆向（沿用本人 MNN+DEA 经验）→ 量化多解性 | **若单目标优化已足够好，就到此为止，不必上扩散** |
| **2｜上生成式** | 表征：多层堆栈 → (材料 one-hot × 层位, 厚度量化) 2D 张量；条件：双态光谱向量 → MLP → reshape → Conv 金字塔（即论文全息支路改造版）；适配器：双态联合 + 单功能；工艺约束在数据构造阶段编码；架构参考 Note 12 建议（涉状态维度可上 DiT 或 U-Net+full-attention bottleneck） | 双态同时收敛；单次成功率可接受；生成结构工艺自洽 |
| **3｜图案化（才是 InfoMetaGen 真正发挥的场景）** | MIM 图案化超表面（VO₂/BaF₂/Ag 那套）前向需 RCWA/FDTD → 摊销收益回归。**此时 DiffMeta 路线比 InfoMetaGen 更贴近**（本身就是 MIM + 制造约束 + 光谱条件 + 实验验证） | 若阶段 2 单体结构做不通，图案化更不必谈 |

#### (5) 一句话结论

**范式层（共享先验 + 适配器 + 约束前移）可直接搬；表征层（analog bit）按需搬；收益层必须重估——VO₂ + TMM 场景下生成式的核心价值从"省时间"转向"多解 + 工艺可行域 + 多任务复用"。** 而作者已把"光学频段 / 色散损耗介质 / 多物理场 / 动态调制"明确列为待验证项，所以这属于**"有依据的开创性尝试"，不是"稳妥的照搬"**。最该先做的不是模型，是两态 n,k 与前向模型口径的可靠性。

## 九、补充材料（SI）补读要点

> SI 共 76 页 / 19 个 Supplementary Notes（含 Supplementary Note 6「Simulation data collection and preparation」——正文完全未引用的数据集专章）。以下为正文未披露、但复现/迁移时必备的信息。

### 9.1 网络结构（SI Note 2 + Note 12）

**扩散基座 U-Net**（Supplementary Fig. 3, 41）：
- 对称 encoder–decoder + middle bottleneck；encoder/decoder 各含 **3 个 down block / up block**；
- 每个 down/up block = **2 个 base residual block + 1 个 linear attention + 下/上采样**；
- middle bottleneck = **2 个 base residual block + 中间夹 1 个 full-attention 模块**（用于建模全局依赖）；
- 每个 base residual block 内：Conv → LayerNorm → 由包含时间步信息的 time embedding $t_{emb}$ 做 **scale & shift 调制** → 激活 → Conv → LayerNorm → 激活 → 残差相加；
- Down block 空间减半/通道翻倍，Up block 反之；输出即该时间步要移除的噪声。
- **作者的设计理由**：DiT 等纯 Transformer 架构需大规模数据与算力才能发挥优势，**在 64×64 网格、186,962 样本这个量级上 U-Net 的"容量–成本"折中更优**；未来做时空超材料/大规模网格时再迁到 DiT。

**功能适配器**（Supplementary Fig. 4, 43）：
- 明确声明**沿用 ControlNet 范式**（零初始化卷积 + 条件注入到各尺度）；
- **但与标准 ControlNet 不同**：ControlNet 会完整复制去噪主干整个 encoder 作为条件分支，本文的 adapter encoder **每层只有 3×3 Conv + SiLU + 下采样**，可训练参数量大幅降低；
- 条件处理：属性标签 → embedding；比特类型 → **独立 embedding 支路**（标量 b：0 = 1-bit，1 = 3-bit → 两层 MLP → reshape 成 $H\times W\times C$ → 两层 3×3 Conv + SiLU）→ 沿通道维拼接 → 两层 3×3 Conv 融合 → 经 adapter 注入冻结基座各尺度；
- **作者观察：把比特类型显式做嵌入预处理，显著提升了 1-bit ↔ 3-bit 切换时的泛化能力**——这是"一个 adapter 管多种比特"能成立的技术前提。
- 各功能的差异只在**条件 embedding 支路**：波束用归一化 (θ, φ) → MLP → reshape → Conv；聚焦用归一化 (x, y, z)；全息用 **MNIST 28×28 灰度图**（值域天然落在 [0,1]，与预训练噪声表示一致，故**无需归一化**）→ Conv3×3 → Flatten → MLP → reshape → Conv3×3。比特支路三者复用同一套。

### 9.2 与既有生成式超表面工作的定位（SI Note 17, Supplementary Table 4）

作者对"直接阵列级生成"下了明确定义：**生成模型直接输出最终的空间编码图案**才算；先生成超原子/meta-cell 再拼装成阵列的，属于 unit-level / device-level。

按此标准梳理 10 篇代表工作：

| 代表工作 | 生成模型 | 生成 meta-array？ | 生成 meta-unit？ | 定位 |
|---------|---------|------------------|-----------------|------|
| Ma 2019、Naseri 2021、Liu 2022、Dai 2024、Wang 2025、Lyu 2025 | VAE / GAN | 否 | 是 | unit-level |
| **Liu 2021**（物理辅助无监督 GAN 编码超表面全息） | GAN | **是** | 否 | array-level |
| **Qian 2024** | VAE | **是** | 否 | array-level |
| Li 2024 | 物理感知扩散 | 否 | 是 | unit-level |
| **本文** | 预训练扩散基座 + 轻量 adapter | **是** | **是** | **Unified（unit + array）** |

> **关键结论**：10 篇里只有 2 篇做到了阵列级，且都做不到单元级；**"同一框架显式同时支持 unit-level 与 array-level"在既有文献中未见先例**——这是作者自认的核心区分点，也提醒我们：**"用了扩散模型"本身不是创新点，"可复用的跨尺度生成框架"才是**。

### 9.3 尺寸–成本权衡的量化（SI Note 10）

| 指标 | 数值 |
|------|------|
| CST 单次仿真时间（随网格） | **51 s → 1,944 s**（≈38×） |
| CST 内存占用（随网格） | **233 MB → 15,502 MB**（≈66×，指数增长） |
| 单卡 4090 (24 GB) 可支持最大预训练网格 | **128×128**（显存约 19.6 GB） |
| 阵列分辨率对全息质量（PCC） | < **28×28** 时 GS 无法收敛（PCC 记 0）；28×28 → 64×64 时 PCC 升至 **> 0.8** |

> 这组数据是判断"迁移到光学频段需要多少算力"的直接依据：**EM 单次仿真成本随网格近似指数增长**，而本文的路线恰恰是"把 EM 仿真花在超原子库构建上、阵列层面用解析/组合避免重复全波"——所以迁移到光学时，真正吃成本的是单元库，不是阵列。

### 9.4 SI 中的其他有用细节

- **采样步数**：统一用 **10 步 DDIM**（Note 13；正文 Fig. 3–5 的 step 标注只到 8）。
- **多解性（Note 11）**：同一目标生成的编码图案与仿真参考、以及彼此之间都有明确结构差异；作者强调这是"给用户多个功能等价候选"的实用价值，而非缺陷。
- **基线配置（Note 18/19）**：36 个目标（A–Z + 0–9），指标 PSNR / SSIM / runtime；运行时对比在 24 GB 显卡上以 **batch size 32** 测（一次前向生成 32 个设计样本），3-bit 全息指标对 10 个样本 × 每样本多次生成取平均。
- **Checkerboard 问题（Note 8）**：作者专门论证了密度法拓扑优化的棋盘格不稳定是**扩散类物理场（热传导、静力学）特有的数值缺陷**，而超材料受波动方程支配，**机制上天然回避**该问题——这是一个容易被审稿人追问的点，作者提前做了防守。
- **尚未明写的几点（复现时需要从代码里确认）**：
  1. ① **1-bit 图案在统一三通道格式下的具体填法**——Table 1 只给了 0–7 的 3-bit 映射，1-bit 的 digit 0/1 究竟是"高位置零"（000/001）还是"复制填充"（000/111），SI 没有明写；
  2. ② **"已验证超原子库"的具体规模**（多少次仿真筛出多少颗单元）以及阵列数据里三类功能各自的确切条数拆分；
  3. ③ **超原子任务条件的编码公式**——$(f, \angle S_{21})$ 的 embedding 管线 SI 未给（其余三类都给了公式）；需确认是否复用 Eq. 14–17 的 归一化→FC→reshape→Conv 模板，以及 $f$ 是连续量还是离散标签；
  4. ④ **目标幅度是否真的进入条件**——正文 claim 含 amplitude，但 Fig. 2 只标 $(f, \angle S_{21})$、SI 中 amplitude 仅作为被评估指标；
  5. ⑤ **超原子微调集的 1,000 条是否按位宽各算**——阵列任务明确写 "9,000 samples from each bit type per functionality"，超原子只写 "1,000 samples are used for the meta-atom generation task"，未写是否 per bit type；
  6. ⑥ **适配器是否接收时间步嵌入**（见 §3.6(3) 末尾）。
- **PIPG 的表述在两处并不完全一致**：Fig. 26 给的是 RRT 风格的通用伪代码（随机采样 + 最近节点 + 固定步长 + 障碍规避），Fig. 28 给的是实际生产流程（选特征节点 → 设障碍区与路径长度 L → 节点间逐段插路径 → 得 M 个候选 → 逐个 CST）。**只有把两者叠起来才是他们真正在做的事。**

## 十、一句话评价

**把"离散编码逆设计"精巧地还原成"连续生成"**——用一个共享扩散先验 + 若干轻量适配器，一次性打通了信息超材料从超原子到阵列、从 1-bit 到 3-bit、从波束到全息的全链路生成，并以 3 个数量级的加速刷新了全息编码的设计成本；其真正的方法论价值在于**"摊销式逆设计"**与**"约束前移到数据构造"**这两条可跨领域复制的主张。
